这道参数方程为什么不能直接消去 t？

我得到的笛卡尔方程包含了多余的点。是不是因为在消元时丢失了参数的取值范围？题目给的是：

x = 2t + 1,   y = t² − 4,   −1 ≤ t ≤ 2

如果直接写成 y = ((x − 1) / 2)² − 4，看起来 x 可以取任意实数。考试中怎样最稳妥地保留限制？

ESAT Mathematics 1 参数方程 浏览 126

12 条回复 · 按帮助度排序

SK Sean K. Cambridge Mathematics · 2 年答题者 高质量解答

你的判断是对的。消元只解决了“点满足什么方程”，没有自动保留“哪些参数被允许”。先由 −1 ≤ t ≤ 2 得到 −1 ≤ x ≤ 5，再把这个定义域和笛卡尔方程一起写出，轨迹才等价。

我会在草稿上固定写两行：① 消元后的关系式；② 参数范围映射后的 x 或 y 范围。这样限时状态下不容易漏。
