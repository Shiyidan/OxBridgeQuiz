## 详细评析

### 亮点

1. 三条整体评价均引用了真实的分数、总正确数和难度层表现，没有虚构知识点或能力原因。
2. 数学1能够把高难度1/3识别为小样本而非稳定优势，生物也能根据0/20形成不同于其他科目的判断。
3. 每个模块都指出中难度是当前最值得优先处理的层级，基本具备行动导向。

### 不足

1. 基线模拟文本质量尚可，但生产调用要求一次返回21个文本字段，240-token 上限极易截断 JSON；真实最新报告已验证为三个模块全部 `fallback`。
2. `positioningInsight` 与其他六个字段共同验收，导致其中任何字段缺失或超长时，合格的整体评价也会被丢弃；当前虽有整模块规则替换，但没有逐字段保留与补齐。
3. 输入缺少已计算正确率、平台表现等级、参考百分位和样本量提示，迫使模型承担不必要的计算与样本判断。
4. 提示词没有目标 JSON 示例，也没有明确“总体定位→证据关系→核心瓶颈→唯一优先方向”的判断顺序。
5. 数学1与化学的表达模板较为接近，仍需通过跨模块对比指令提升区分度。
