# 评价标准

**任务**：esat-module-positioning  
**创建日期**：2026-08-03  
**版本**：v1

## 评价维度与权重

| 维度 | 权重 | 启用 | 说明 |
|---|---:|:---:|---|
| 证据准确性 | 0.30 | ✅ | 所有分数、正确数、题量、正确率和难度结论均与输入一致，不虚构原因或事实 |
| 诊断价值 | 0.25 | ✅ | 从数据中形成明确的整体水平判断，并识别最主要瓶颈或真实相对优势 |
| 优先级与可行动性 | 0.20 | ✅ | 明确唯一首要提升方向，能指导后续复盘但不越界生成具体学习任务 |
| 模块区分度 | 0.15 | ✅ | 不同表现结构产生不同评价，不使用可替换模块名后通用的套话 |
| 格式与链路可靠性 | 0.10 | ✅ | JSON 合规、长度合规、模块可独立验收，失败时可安全降级且来源可追踪 |

> 权重总和为 1.0。

## 任务特定标准

### 必须包含的内容

- 模块当前预估分或表现等级。
- 至少两类量化证据；建议组合为“模块正确率 + 最弱/最强难度层”。
- 对证据关系的解释，而非数字堆叠。
- 一个最主要瓶颈、风险或相对优势。
- 一个与瓶颈直接对应的优先提升方向。

### 禁止出现的内容

- 单独使用“仍有提升空间”“继续努力”“加强练习”等无证据套话。
- 虚构知识点、错误类型、能力原因、心理状态、目标院校结论。
- 重算或修改后端确定的预估分、区间、百分位和表现等级。
- 把低样本下的偶然表现描述成稳定能力结论。
- 同一份报告内多个模块使用结构和含义完全相同的评价。

### 输出格式要求

```json
{
  "moduleAnalyses": [
    {
      "moduleId": "math1",
      "positioningInsight": "1–2句中文整体评价"
    }
  ]
}
```

整体评价应能被独立解析和校验；其他分析字段是否存在，不影响 `positioningInsight` 的接受。

### 分档标准

- **9–10 分**：证据完全准确，评价有明显模块特异性，能在一遍阅读中看出当前状态、核心瓶颈和优先方向。
- **7–8 分**：结论基本有价值且证据充分，但优先级或模块差异仍可更明确。
- **4–6 分**：引用了部分数据，但主要是复述或泛化总结，无法有效指导后续行动。
- **1–3 分**：主要使用套话，或结论与输入数据关系很弱。
- **0 分**：输出无效、无法解析、事实错误或包含明显虚构。
