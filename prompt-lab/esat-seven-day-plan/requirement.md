# 需求文档

**任务**：esat-seven-day-plan  
**整理日期**：2026-08-03

## 任务目标

将 ESAT 诊断报告中的“7 天启动计划”从知识点名称替换式模板，改造成一条专业、具体、可信的短周期学习路径。学生应在十秒内看懂：今天为什么学、具体做什么、需要多久、留下什么结果、什么情况下进入下一步。

本任务最终需要同时改进：

1. 后端学习路径的输入结构与生成约束；
2. 规则兜底计划，确保模型不可用时仍然不重复、不空泛；
3. 前端按日计划的信息层级与展示方式；
4. 对历史报告的兼容呈现和新报告的结构校验。

## 当前基线问题

用户截图中的计划存在以下可复现问题：

- Geometry、Algebra、Number 三项仅替换知识点名称，任务正文完全相同；
- `2–4 小时专项投入` 被逐项重复，三项合计可能超过默认每周 5 小时预算；
- 没有说明每项安排对应哪条作答证据、为什么排在当天；
- 没有“错因定位 → 方法重建 → 独立练习 → 混合迁移 → 周末复测”的递进关系；
- 没有明确学习材料类型、操作步骤、产出物和未达标后的处理；
- 阶段 `activities` 被再次渲染成“学习安排 1”，形成额外重复；
- “本周”重复出现，无法形成七天时间感。

## 输入描述

生成系统可使用且只能使用以下事实：

- 本次实际作答模块、知识点、难度、正确数、总题数和正确率；
- 低样本/中样本/高样本可信度；
- 错题题号；
- `Question.meta.learning_analysis` 白名单字段：考试重点、复习建议、可能错误模式；
- 第一优先行动和完成标准；
- 最多三个优先补弱项；
- 每周可投入时长；缺失时采用明确标注的保守预算；
- 可用的模块时间效率事实；
- 个人资料中已确认的考试日期、目标分数与专业方向。

不得把题库中的“可能错误模式”写成对学生个人成因的确定判断，也不得生成不存在的教材、课程、题号、知识依赖或院校门槛。

## 输出要求

- **格式**：结构化 JSON；固定包含 7 个自然日任务。
- **风格**：面向备考学生的专业教练式表达，直接、克制、可执行。
- **长度**：每个自然日保持可扫描；核心任务 1 个、执行步骤 2–4 个。
- **差异性**：七天必须承担不同学习职能，不得只替换知识点名称。

每个自然日最少包含：

1. `day` 与当天主题；
2. `focus`：知识点、难度或混合训练范围；
3. `diagnosticRationale`：引用真实作答证据说明为什么安排；
4. `durationMinutes`：当天预算；
5. `steps`：2–4 个可执行动作；
6. `deliverable`：学习后留下的可检查产出；
7. `successCriteria`：可量化完成标准；
8. `ifNotMet`：未达标时的下一步，而不是泛化鼓励。

## 专业学习路径

完整七天应形成以下功能递进，但允许根据缺口数量调整知识点分配：

1. **证据核对**：回到错题，区分知识缺口、方法选择与执行失误；可能错误模式只作为核对清单。
2. **方法重建**：先学习正确例题或核心方法，再做少量同构题，避免低基础学生直接堆题。
3. **单点检索练习**：不看答案独立作答，获得即时反馈并记录失败步骤。
4. **第二优先项迁移**：处理另一缺口，明确它与第一项的训练区别。
5. **第三优先项或深挖**：有第三缺口时进入第三项；否则提升第一项难度。
6. **交错限时训练**：混合多个知识点，训练识别方法和切换策略。
7. **周末复测与决策**：用新题验证，按照结果进入巩固、继续补弱或生成完整路线。

## 质量要求

- 每日任务必须能从输入事实追溯，避免模型自行创造诊断。
- 一周总时长与周预算一致，允许小幅取整但不得逐项复制投入区间。
- 计划必须体现学习机制差异，而非七张同构卡片。
- 模型不可用时，规则兜底也要生成完整的七日递进路径。
- 前端优先展示“日次、目的、时长、核心动作、完成证据”，详细理由可渐进展开。
- 历史旧结构仍能打开，但新结构不得再渲染额外的“学习安排 1”。

## 参考信息

- 数学错误分析可以支持更深入理解与延迟保持，但研究结果也提示不能把所有学生统一放入纯错误示例流程，应结合正确范例与先备水平：[Teaching and learning mathematics through error analysis](https://link.springer.com/article/10.1186/s40928-018-0009-y)。
- 让学生识别、解释并修正错误，在网络化数学学习中表现出延迟测验与正确性判断优势，支持“定位—解释—修正”的首日设计：[Using erroneous examples to improve mathematics learning](https://www.sciencedirect.com/science/article/pii/S0747563214001757)。
- 数学交错练习的随机对照研究支持在后段加入混合题型，而不是七天始终进行单一知识点块练习：[Interleaved Practice Improves Mathematics Learning](https://zenodo.org/records/4663897/files/HartwigRohrer.pdf)。
- 检索后的解释性反馈有助于迁移，因此每日完成标准不能只有“做完”，还应包含反馈、修正和复测证据：[Feedback and Transfer](https://pdf.retrievalpractice.org/transfer/Butler_etal_2013.pdf)。

## 验收标准

- [ ] 七天任务标题、目的、步骤和产出均有实质差异。
- [ ] 每天至少引用一条真实诊断事实或明确说明其学习职能。
- [ ] 总时长不超过周预算，且每天有具体分钟数。
- [ ] 至少包含错题证据核对、正确方法重建、独立练习、交错训练和周末复测。
- [ ] 每天都有完成证据和未达标分支。
- [ ] 低样本只触发校准，不写成确定性薄弱诊断。
- [ ] 无模型时的规则方案仍满足同一结构。
- [ ] 页面不再出现重复的“完成本格错题复盘与 2–4 小时专项投入”。
