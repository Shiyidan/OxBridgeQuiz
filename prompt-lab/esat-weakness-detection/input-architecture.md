# 输入架构设计

## 1. 任务分解

短板判断拆成四个线性子任务，统计结论先于模型文案生成：

1. **确定性证据计算**：先根据考试类型选择 ESAT 或 TMUA 策略，再从答卷构建模块、难度、知识点三个层级的指标和候选信号。
2. **短板归并与排序**：把重复信号归并为明确短板、相对短板和待校准方向，固定顺序与置信度。
3. **DeepSeek 解释**：模型只为程序已选信号生成定位、风险和训练理由。
4. **页面消费**：首页、矩阵、优先级、下一步和学习计划读取同一 `weaknessProfile`。

模型不参与正确率计算、候选新增、置信度升级和优先级排序。

## 2. 信息资产清单

### 主数据

- `modules`：科目 ID、正确数、实际题量、正确率、平台预估分、预估区间、是否归一化估分。
- `difficultyGroups`：科目内低/中/高难度的正确数、实际题量、错题数、正确率、占本科题量比例。
- `topicGroups`：科目内知识点跨难度汇总后的正确数、题量、错题数、正确率、占本科错题比例。
- `topicDifficultyCells`：知识点 × 难度的明细，用于展示和专项练习参数。
- `questionEvidence`：候选对应题号、知识点编码、叶子知识点编码、题库复习建议和可能错误模式。

### 上下文数据

- `examPolicy`：考试类型、模块数量、题量模式、配置的标准模块题量和记录是否完整。
- 试卷实际总题量和各科实际题量。
- ESAT 标准模块题量，仅用于标注是否归一化，不作为固定候选门槛。
- 备考科目、目标院校、目标专业、考试日期和每周时长。
- 逐题计时覆盖度和分析可靠性。

### 参考数据

- 平台估分曲线与模块分档。
- 当前 V2 提示词的安全限制。
- 当前报告 `0fd11788-0652-4bd3-9a38-eb2d3646b0b2`，作为基线用例。

### 元数据

- 输出语言：中文。
- 输出结构：严格 JSON。
- 模型职责：解释和改写，不执行统计判断。

## 3. 自适应证据计算

### 3.1 模块级信号

先按 `examPolicy` 选择策略：

- `ESAT_VARIABLE_MODULES`：三科或组合科目，允许实际题量不一致，以本次最大模块题量计算覆盖度和动态门槛。
- `TMUA_STANDARD_EQUAL`：两个模块均达到配置的标准题量且题量一致，直接比较模块正确率和分差，完整模块置信度为高。
- `GENERIC_DYNAMIC`：TMUA 记录不完整或结构不符合标准时的安全回退，使用动态题量并降低置信度。

对每个科目计算：

- `accuracy`：正确数 / 实际题量。
- `rank`：按正确率排序；预估分只作为补充证据。
- `gapToNext`：最低科目与第二低科目的正确率差。
- `coverageRatio`：ESAT 或非完整记录中，本模块实际题量 / 本次最大模块题量。
- `wrongShare`：本科错题数 / 全卷错题数。
- `confidence`：结合实际题量与 `coverageRatio`，不依赖标准 27 题。

建议基线规则：

- `absolute`：实际题量至少 8 且正确率不高于 60%。
- `relative`：实际题量至少 8、为最低科目，且与第二低科目相差至少 12 个百分点。
- `clear`：同时满足绝对与相对，或绝对表现极低（不高于 50%）。
- `relative-only`：只满足相对条件时标记“相对短板”，不得写成绝对能力不足。
- 三科均高且差距不足 8 个百分点时，不生成科目短板。

TMUA 标准等题量规则：

- 任一模块正确率不高于 60%时，形成高置信度绝对短板。
- 最低模块高于 60%，但比另一模块低至少 12 个百分点时，形成高置信度相对短板。
- 两个模块正确率均高于 80%且差距不足 8 个百分点时，不生成模块短板。
- 两个模块都不高于 60%时，`moduleSignals` 同时保留两项绝对短板，再按正确率、错题数排序；`primaryModule` 只是第一优先项，不是唯一短板。

这里的 8 题是科目级最低证据线，不是知识点固定门槛；后续实验将比较“固定最低题量”和“按本科题量比例”的表现。

### 3.2 难度级信号

难度层在科目内部判断：

- `coverageRatioInModule`：该难度题量 / 本科实际题量。
- `wrongCount`、`accuracy`、`wrongShareInModule`。
- 明确信号：题量至少 3、错题至少 2、正确率不高于 50%，且覆盖本科至少 15%。
- 待校准：题量 1—2，或只有 1 道错题。

这使当前化学中难度 3/10 能成为高置信度难度短板，而不会因为知识点被拆散而消失。

### 3.3 知识点级信号

先跨难度汇总同一知识点，再保留知识点 × 难度明细：

- 高置信度：题量至少 5、错题至少 3、正确率不高于 50%。
- 中置信度：题量至少 3、错题至少 2、正确率不高于 60%。
- 低置信度待校准：题量 1—2 且存在错误。
- 额外提升：某知识点错题数占本科错题至少 30%时，提高排序权重，但不能跨越样本置信度直接升级为明确短板。

知识点候选排序依次考虑：结论等级、置信度、错题数量、错题占比、正确率、难度权重。

### 3.4 统一短板画像

程序输出：

```json
{
  "weaknessProfile": {
    "primaryModule": {
      "moduleId": "chemistry",
      "label": "化学",
      "level": "clear",
      "confidence": "high",
      "evidence": {
        "correct": 9,
        "total": 18,
        "accuracyPercent": 50,
        "rank": 3,
        "gapToNextPercent": 22.2
      }
    },
    "difficultySignals": [],
    "topicSignals": [],
    "calibrationSignals": []
  }
}
```

其中：

- `level` 只能由程序产生：`clear | relative | calibration | none`。
- `confidence` 只能由程序产生：`high | medium | low`。
- DeepSeek 必须原样引用，不能新增或升级。

## 4. 依赖矩阵

| 子任务 | 必需输入 | 增强输入 | 输出 |
|---|---|---|---|
| 确定性证据计算 | modules、difficultyGroups、topicGroups | 估分区间、标准题量 | 原始信号 |
| 短板归并排序 | 原始信号、置信度 | 目标专业、计时可靠性 | weaknessProfile |
| 模型解释 | weaknessProfile、量化证据 | 题库复习建议 | 受控诊断文案 |
| 首页结论 | primaryModule、最高优先知识点 | 模块诊断摘要 | 核心结论与标签 |
| 提升优先级 | topicSignals、difficultySignals | 叶子知识点编码 | 专项练习候选 |
| 下一步行动 | 第一可执行候选 | 题号、复习建议 | 练习或校准行动 |
| 学习计划 | primaryModule、优先信号、时间资料 | 院校和专业背景 | 三阶段计划 |

## 5. DeepSeek 输入模板

### 必需字段

1. `examType`：ESAT 或 TMUA。
2. `examPolicy`：程序选定的考试结构策略，模型不得改写。
3. `moduleFacts`：各模块正确数、题量、正确率、预估分和难度汇总。
4. `weaknessProfile`：程序确定的等级、置信度、证据和顺序。
5. `allowedEvidence`：模型可以引用的数字与标签。
6. `outputSchema`：现有结构化字段。

### 可选增强字段

- `reviewGuidance`：仅候选错题已有题库分析。
- `timingFacts`：仅计时可靠时提供。
- `profileContext`：仅用于学习计划，不用于升级短板等级。

### 字段顺序

1. 不可改变的 `weaknessProfile`。
2. 原始 `moduleFacts`。
3. 可引用的 `questionEvidence`。
4. 输出格式与禁止项。

### 模板示例

```json
{
  "examType": "ESAT | TMUA",
  "examPolicy": "ESAT_VARIABLE_MODULES | TMUA_STANDARD_EQUAL | GENERIC_DYNAMIC",
  "task": "解释程序已判定的短板画像",
  "weaknessProfile": {},
  "moduleFacts": [],
  "questionEvidence": [],
  "constraints": {
    "mustPreserveLevel": true,
    "mustPreserveConfidence": true,
    "mustPreserveOrder": true,
    "forbidNewCandidates": true
  }
}
```

## 6. 压缩策略

- 使用结构化提取，不向模型发送完整题干和完整解析。
- 每个候选最多保留 8 个题号、3 条复习建议和 3 条可能错误模式。
- 首页定位只发送科目与难度证据，不发送全部知识点矩阵。
- ROI 文案只发送程序选出的前 5 个候选。
- 学习计划只发送前 3 个可执行信号和科目级主短板。

## 7. 跨页面消费规则

- 首页有 `primaryModule.level = clear | relative` 时，必须展示科目级短板；知识点不足只影响副标题和行动类型。
- `topicSignals` 中高/中置信度候选进入提升优先级；低置信度进入校准行动。
- 没有知识点候选但存在难度短板时，下一步按该科目的难度层组织复盘，不虚构具体知识点。
- 学习计划第一阶段必须承接 `primaryModule` 和最高优先可执行信号。
- 只有 `weaknessProfile` 全部为 `none` 时，首页才允许显示“没有明显短板”。

## 8. 基线与实验输入

Phase 2 使用当前测试答卷作为基线：

- 数学 1：16/18，88.9%。
- 化学：9/18，50%；中难度 3/10，30%。
- 生物：13/18，72.2%。
- 现状：模型识别化学偏弱，但 `highRoiGaps` 为空，首页显示无明确短板。

Phase 3 将保持其他条件不变，优先实验“自适应候选约束”这一单一变量，再实验模型约束措辞。

TMUA 补充验收使用两个标准等题量模块，覆盖均高、单模块偏低、双模块都低、知识点集中错误、单题错误和标准策略选择六种情况。
