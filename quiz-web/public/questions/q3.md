# Question 3

## 题干

Which of the following is a correct rearrangement of

$$y = p - \dfrac{q-r}{s-x}$$

to make $x$ the subject?

## 选项

**A** $x = s - \dfrac{q-r}{p+y}$

**B** $x = \dfrac{q-r}{p+y} - s$

**C** $x = s - \dfrac{q-r}{p-y}$

**D** $x = \dfrac{q-r}{p-y} - s$

**E** $x = s - \dfrac{q-r}{y-p}$

**F** $x = \dfrac{q-r}{y-p} - s$
