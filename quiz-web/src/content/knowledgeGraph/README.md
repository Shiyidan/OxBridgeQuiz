# 数学1知识图谱关系

本目录交付 ESAT 数学1的教学关系数据与节点导航。学习平台中“我的练习本”左侧的“知识图谱”入口打开 `/knowledge-graph`，默认以小圆点和细连线展示核心网络，放大逐层展开完整的76个知识点；可按章节筛选或聚焦局部关系，并提供搜索、缩放和学习/练习跳转。个人点亮状态由页面只读加载，不写入本目录的共享配置。

章节导航左侧提供五科下拉选择：数学1、生物、化学、物理、数学2，所选科目的章节按钮显示在右侧。数学1继续使用已验证的关系数据；其他四科只读取现有考纲章节，图谱区域保留空白占位，不展示数学1的统计、节点或搜索结果。切换科目清除旧章节和知识点选择，返回学习平台时保留当前科目范围。

## 内容范围与依据

- 7章、76个知识点，编号、标题和章节归属与现有 `esatUnits`、`esatNumber`、`esatRatioProportion`、`esatAlgebra`、`esatGeometry`、`esatStatistics`、`esatProbability` 讲义一致。
- 193条关系：前置基础42条、方法应用109条、关联理解42条，其中72条跨越章节边界。
- 关系是依据现有概念与方法整理的教学建议，不是考试机构公布的官方先修图，也不是由真题共现次数推断出的考频关系。
- 每条关系的 `explanation` 说明实际连接理由和必要条件。维护时应同时检查两端讲义的相关内容，而不只比较名称。
- 当前所有知识点均有明确关联。覆盖节点不要求强行连边，后续新增基础术语若没有有价值的关系，可以保持独立。

## 三种关系的含义

| 类型                    | 方向        | 含义                                                                            |
| ----------------------- | ----------- | ------------------------------------------------------------------------------- |
| `prerequisite` 前置基础 | 起点 → 终点 | 起点是终点所述内容的理解基础，不表示完成起点即可掌握终点，也不是访问门槛。      |
| `application` 方法应用  | 起点 → 终点 | 在说明限定的条件下，将起点方法用于终点；不暗示这是唯一解法。                    |
| `connection` 关联理解   | 无向        | 适合对照、转换或联系理解，没有强制学习先后；`source`、`target` 仅用于保存端点。 |

例如：

- 标准单位与复合单位 → 单位换算：前置基础。
- 勾股定理 → 坐标几何问题：方法应用，坐标差构成直角边。
- 二次图像、根与转折点 ↔ 二次方程：关联理解，实根对应横轴交点。
- 理论样本空间 → 加乘概率与条件概率：前置基础，已知条件改变可选结果范围。

章节归属由节点的 `chapterCode` 表达，不混入教学关系。关系不自动传递：A关联B、B关联C，不代表存在A与C的直接连线。前置关系不得形成有向环，其他类型的环不应被当作错误的学习顺序。

## 方法如何形成网络

关系逐条对照现有讲义中的具体方法、适用条件和常见误区整理；不自动按相似名称、章节相邻或路径可达生成边。除基础衔接外，重点保留以下交叉联系：

- **相似、勾股、三角比和坐标方法**：相似可先缩小勾股计算；坐标差给出直角边；三角比求高度后进入面积计算，正切还与直线斜率对应；坐标差与向量分量提供几何证明的另一种表示。
- **比例、方程和图像**：比值与占整体的分数用于分配；混合、总量或差量可转成联立方程；正反比例可在公式和图像之间转换，面积和体积则体现平方、立方比例。
- **代数、几何和数列**：因式分解和二次图像提供理解方程根的不同入口；坐标距离、面积条件可导出二次方程；二次数列的项是相应二次图像上的离散点。
- **统计、概率和扇形**：直方图面积还原频数，再得到相对频率；合并频率和合并均值都需要按样本数加权；条件概率更换分母；扇区角度比例可用于饼图和均匀方向转盘。

这些是交汇的方法网络，并非规定学生必须依次完成的单一路线。具体限制写在每条关系的说明中，例如条件概率只使用完整分组的频数、概率按角度计算要求转盘方向均匀、面积比例要求图形相似。

## 局部展示规则

- 科目总览按缩放分层显示真实节点和关系，默认只显示核心网络。
- 章节视图默认显示本章节点及其直接相连的跨章节点，并保留可见节点之间已有的关系；取消“跨章节关联”后仅显示本章。跨章扩展只进行一层，避免逐级扩展成全科图。
- 选中知识点后，显示它及其直接邻居，同时保留邻居之间已经确认的关系，避免把局部网络裁剪成星形。右侧保留直接关联的知识点导航，不展示关联说明；连线不显示悬停提示，也不触发高亮、关联聚焦或手形光标。仅悬浮知识点节点时展示学习进度并突出关联；离开节点移到连线后恢复普通显示。
- 类型筛选同时约束节点扩展和连线；不因两点共同关联某个中心而创建新边。画布下方显示当前范围的节点与关系数量。

## 总览分层与位置稳定

| 层级 | 节点/关系数量 | 展开条件 | 内容 |
| --- | --- | --- | --- |
| 核心网络 | 20 / 22 | 初始视图 | 覆盖七章的教学骨干与明确的关键联系 |
| 方法展开 | 39 / 70 | 放大至 1.55 倍 | 常用方法、图像、推理与应用情境 |
| 完整细节 | 76 / 193 | 放大至 2.5 倍 | 全部正式节点及真实关联 |

核心节点和连线由 `maths1Overview.ts` 显式维护，并非考试重点或考频排名，也不根据用户点亮状态变化。第二层包含核心网络，第三层包含全部数据；所有显示连线均来自原图，不用连接隐藏路径两端的方式制造新关系。收起阈值分别为 1.35 和 2.2 倍，避免临界缩放时闪烁。章节视图和点击/搜索后的局部图完整展示当前范围，不受总览层级限制。

每个范围预先布局并缓存全部坐标。总览先只用核心节点和关键连线排好骨干，再逐层安放方法与细节节点；后续层不移动已确定的节点。核心布局依据真实关系的最短距离和连接数量调整间距，从多个固定起点中选择交叉较少、邻点距离较均衡的结果；最短距离仅用于位置计算，不合成连线。中心约束与整体适配让节点自然分布，避免强制截到矩形边缘。

中英文完整名称通过 ECharts 的实际文字换行规则同时测量，使用较大的预留尺寸；细节按该层最小保留倍率预留空间。碰撞后仍受多个固定标签夹挤的节点会移至最近的空位。ECharts 按原始坐标比例绘制，隐藏节点不会把核心总览拉伸。布局排序、初始种子及候选选择均固定，数据重排和视图重置可复现；名称最大宽度为 132 像素，长名称完整换行。名称使用透明背景和轻微文字描边，不绘制整块白底，避免标签两侧的空白区域遮断连线。

总览中隐藏节点仍保留坐标以固定 ECharts 的数据边界，但使用 `symbol: none`，无图形、标签、提示或命中区域；连线按层级筛选。缩放时保留相同数据边界、视口中心和缩放倍率，只改变可见性，不重新运行布局。语言切换和个人进度更新也保留当前视口。节点位置固定，用户拖动画布浏览；缩放使用滚轮、双指或加减按钮，重置视图回到初始核心层。细线使用 ECharts 的不随缩放加粗绘制方式。

## 代码入口

- `maths1.ts`：导出 `maths1KnowledgeGraph`，包含图谱元数据与完整关系。
- `maths1Nodes.ts`：轻量节点与章节元数据，不导入整套讲义；自动校验防止标题或编号与讲义漂移。
- `maths1Overview.ts`：核心节点、关键连线、方法层节点以及带回滞的缩放层级规则。
- `labels.ts`：中英文名称选择与跨语言搜索；`titleEn` 沿用现有考纲的英文名称，切换不改变知识点编号。
- `layout.ts`：核心优先的确定性布局、细节安放和中英文标签空间避让；仅计算坐标。
- `types.ts`：数据契约、关系标签及是否有向。
- `navigation.ts`：`getKnowledgeGraphNeighbours` 返回直接相邻节点、说明和方向；`getKnowledgeGraphView` 统一控制章节跨章扩展与知识点局部网络，支持关系类型筛选。

数据只使用已有知识点编号。正式页面接入时，仍需与当前考试考纲匹配，并复用学习入口的权益检查；图谱关系本身不授予内容访问权。个人点亮状态应从现有账号接口叠加，不写入公共图谱配置。点亮仅代表用户自评已学完，不代表测评确认掌握。

总览展示真实知识点关系，每个节点下方常驻显示完整名称，长名称换行；名称支持中文与 English 切换，搜索同时匹配两种语言；选中节点后展示直接关联的知识点导航，并仅为有向关系显示小箭头。蓝色圆点表示尚未点亮，金黄色表示当前账号已点亮。尊重减少动态效果设置；总览采用带标签避让的确定性力导向排布，切换语言不打乱总览节点位置；窄屏保留可读字号，通过拖动和缩放浏览全图。图谱浏览与节点导航不新增操作日志，继续沿用现有“仅实际点亮记录日志”的规则。当前仅开放 ESAT 数学1，其他考试直达此路由时显示暂无图谱，不加载 ESAT 个人进度。

## 知识点悬停进度

悬停节点仅展示已学习/未学习、题库已完成题数；名称保留在节点下方，不在浮层重复。学习状态来自当前账号的点亮记录，仅代表自评；题数独立统计，不据此自动点亮。

- `GET /api/learning-completions/:examType/question-counts` 从认证会话确定账号，批量返回知识点编号到完成题数的映射，响应禁止缓存；不接受客户端指定其他账号。
- 只统计当前考试的独立试题库题目及题库练习答卷（包含练习本），要求已交卷且题目有非空的已作答答案。正确、错误均计入，跳过、未见、空答案、未交卷、诊断和模考不计入。
- 通过题目/知识点唯一关联和已作答记录的存在性过滤去重，同一道题重做多次仍计一题。一道题对应多个知识点时，各自计入一次；已归档题保留历史完成贡献，不把更新后的替代题自动视为已完成。
- 学习状态与题数并行加载，各自保留加载/失败状态；查询失败不显示成未学习或零题。切换账号或考试先清空旧数据，过期响应不得覆盖当前账号；未登录显示登录后查看。
- 自动回归命令：在 `api` 目录运行 `npm.cmd run test:learning-progress`，仅允许本地数据库，以隔离数据验证去重、账号与考试隔离、来源、交卷边界、鉴权及查询不写操作日志。

## 校验与维护

在 `api` 目录运行 `npm.cmd run test:maths1-knowledge-graph`。这是不访问数据库的正式回归检查，覆盖讲义节点一致性、悬空端点、自环、端点对去重、解释完整性、前置关系无环及导航方向；同时验证具体教学联系、邻居间已有连线、一层跨章范围、类型筛选和禁止生成传递关系，并校验核心层覆盖七章、骨干真实连通、逐层包含、可见端点完整和缩放回滞阈值。布局检查覆盖三种画布尺寸、后续层不挤动先前层、数据重排结果一致、输入不被修改，以及空图、单点与不连通图。浏览器验证还需核对中英文实际标签边界、跨层前后的屏幕坐标、隐藏节点无图形、语言/进度更新不重置视口，以及点击和搜索进入完整局部图。

自动检查不能证明教学关系正确。新增关系还需确认：是否确有学习用途、箭头方向是否合理、是否只是一种可选方法、限制条件是否写清。不因名称相似、同处一章或同一道题出现而自动添加关系。
