# 学科学习图谱关系

本目录交付 ESAT 数学1、数学2、物理、化学和生物五科的教学关系数据与节点导航。ESAT 的学习平台无上下文入口 /question-bank 默认显示“学习总览”，/knowledge-graph 保留为可直接访问的总览地址；旧的 mode=learning/practice、code 和难度链接继续进入对应任务。总览以小圆点和细连线展示当前科目的核心网络，放大当前区域展开细节，通过拖动浏览该科目的全部知识点。

ESAT 工作区提供“学习总览、知识点学习、题库练习、我的练习册”导航和练习记录入口。科目下拉与左侧考纲树共享真实考纲，顶部不再提供知识点搜索；选择节点同步考纲与地址，右侧提供点亮状态、去重完成题数、学习/练习入口及相关练习册。ESAT 五科均已有图谱数据。TMUA 仅展示“题库练习、我的练习册”两个 tab，默认进入题库；旧图谱或学习链接在恢复考试偏好后转到题库并保留范围与难度，不展示点亮进度或图谱引导，不增加课程授权。两种考试均保留练习记录及练习册新建、编辑入口。

stores/learningWorkspace.ts 按账号与考试管理个人状态，身份切换立即清空旧数据并丢弃过期响应。图谱与课程页面缓存，返回原范围时保留缩放和节点位置。一级练习册入口默认展示全部；只有 knowledgeCode 显式参数才筛选相关练习册，专题创建仅预填范围，不自动保存或开始答题。

学习平台由 `LearningWorkspaceView.vue` 统一分流：`KnowledgeLearningView.vue` 只管理讲义、学习权益和点亮入口，`QuestionBankView.vue` 只管理难度、题量、续答与练习权益。两页通过 `useLearningScope.ts` 复用考纲范围及路径，通过 `LearningScopeHeader.vue` 共用范围标题。`learningWorkspaceRoute.ts` 统一解释历史链接，隐藏的缓存页面不发起另一任务的请求或改写地址；原有 `/question-bank?mode=learning/practice&code=...` 链接继续有效。

“我的练习册”的列表、新建和编辑统一由 `PracticeNotebookView.vue` 管理，复杂配置表单收在内部组件 `components/practiceNotebook/PracticeNotebookEditor.vue`。列表切到表单时保留筛选和历史展开状态，保存或取消后恢复列表；从图谱、题库和诊断报告进入仍按原来源预填和返回。`/practice-notebook/new`、`/practice-notebook/:id/edit` 保留为可直接访问的状态地址，不再对应独立的页面文件。

## 内容范围与依据

- 数学1：7章、76个知识点，编号、标题和章节归属与现有 `esatUnits`、`esatNumber`、`esatRatioProportion`、`esatAlgebra`、`esatGeometry`、`esatStatistics`、`esatProbability` 讲义一致；193条关系，其中72条跨越章节边界。
- 数学2：8章、39个知识点，覆盖代数与函数、数列与级数、坐标几何、三角、指数与对数、微分、积分、函数图像，与八份 `esatMath2*` 讲义逐项校验；84条关系，使用当前考纲的中英文名称。
- 物理：7章、32个知识点，覆盖电学、磁学、力学、热学、物质、波与放射性；74条关系，其中33条跨章。图谱采用真实考纲的中英文短标题，讲义中“力与受力分析”“功、能量与效率”等展开标题通过相同编号对应，校验中显式维护这六处别名。
- 化学：17章、89个知识点、167条关系，其中97条跨章；覆盖原子结构、周期表、方程与计量、氧化还原、成键、族化学、分离、酸碱、速率、能量、电解、有机、金属、粒子模型、检验及空气与水。
- 生物：11章、34个知识点、80条关系，其中55条跨章；覆盖细胞、运输、分裂、遗传、DNA、基因技术、变异、酶、动物生理、生态系统与植物生理。
- 化学与生物节点保留真实考纲的中英文名称，讲义标题的扩展写法按相同编号对应；测试显式列出17处化学及16处生物标题差异，不据名称自动推测关系。
- 各科有独立节点、关系和核心层配置；科目切换同时替换这三部分，不混用不同科目的编号或层级，也不推断跨科关系。
- 关系是依据现有概念与方法整理的教学建议，不是考试机构公布的官方先修图，也不是由真题共现次数推断出的考频关系。
- 每条关系的 `explanation` 说明实际连接理由和必要条件。维护时应同时检查两端讲义的相关内容，而不只比较名称。
- 当前所有知识点均有明确关联。覆盖节点不要求强行连边，后续新增基础术语若没有有价值的关系，可以保持独立。

## 三种关系的含义

| 类型                    | 方向        | 含义                                                                            |
| ----------------------- | ----------- | ------------------------------------------------------------------------------- |
| `prerequisite` 前置基础 | 起点 → 终点 | 起点是终点所述内容的理解基础，不表示完成起点即可掌握终点，也不是访问门槛。      |
| `application` 方法应用  | 起点 → 终点 | 在说明限定的条件下，将起点方法用于终点；不暗示这是唯一解法。                    |
| `connection` 关联理解   | 无向        | 适合对照、转换或联系理解，没有强制学习先后；`source`、`target` 仅用于保存端点。 |

例如：

- 标准单位与复合单位 → 单位换算：前置基础。
- 勾股定理 → 坐标几何问题：方法应用，坐标差构成直角边。
- 二次图像、根与转折点 ↔ 二次方程：关联理解，实根对应横轴交点。
- 理论样本空间 → 加乘概率与条件概率：前置基础，已知条件改变可选结果范围。

章节归属由节点的 `chapterCode` 表达，不混入教学关系。关系不自动传递：A关联B、B关联C，不代表存在A与C的直接连线。前置关系不得形成有向环，其他类型的环不应被当作错误的学习顺序。

## 方法如何形成网络

关系逐条对照现有讲义中的具体方法、适用条件和常见误区整理；不自动按相似名称、章节相邻或路径可达生成边。除基础衔接外，重点保留以下交叉联系：

- **相似、勾股、三角比和坐标方法**：相似可先缩小勾股计算；坐标差给出直角边；三角比求高度后进入面积计算，正切还与直线斜率对应；坐标差与向量分量提供几何证明的另一种表示。
- **比例、方程和图像**：比值与占整体的分数用于分配；混合、总量或差量可转成联立方程；正反比例可在公式和图像之间转换，面积和体积则体现平方、立方比例。
- **代数、几何和数列**：因式分解和二次图像提供理解方程根的不同入口；坐标距离、面积条件可导出二次方程；二次数列的项是相应二次图像上的离散点。
- **统计、概率和扇形**：直方图面积还原频数，再得到相对频率；合并频率和合并均值都需要按样本数加权；条件概率更换分母；扇区角度比例可用于饼图和均匀方向转盘。

这些是交汇的方法网络，并非规定学生必须依次完成的单一路线。具体限制写在每条关系的说明中，例如条件概率只使用完整分组的频数、概率按角度计算要求转盘方向均匀、面积比例要求图形相似。

数学2着重连接以下方法：

- **二次方程、圆与图像交点**：代入法把直线与圆的交点转成二次方程，判别式区分相交、相切和不相交；交点还可确定积分面积的边界。
- **函数性质与图像变换**：定义域、单调性、关键点和渐近线共同约束指数、三角及其他常见图像；先检查复合函数的合法输入，再追踪变换。
- **数列、指数与对数**：正公比等比数列对应指数函数的离散取样，由目标值反求项号可用指数方程；负公比不套用正底数实指数图像。
- **代数与三角方程**：恒等式与换元把部分三角方程化成二次式，筛选正弦或余弦的值域后，结合周期和区间还原角度。
- **微分、图像与积分**：导数符号判断增减，零点、驻点及交点共同确定图形；微积分基本定理联系局部变化率与累计净变化，几何面积另按正负分段。

关系仍以现有讲义范围为准：例如微分方程只连接右侧为自变量函数时的直接积分，不把更高阶技巧当作已学内容。术语、根式等基础节点仅在具体方法需要时展开，不为了增加密度强行成为总览中心。

物理围绕具体模型和装置建立网络：

- **电路、机械能与热量**：电功率连接电动机效率、升温及相变；净吸收能量需要扣除容器与环境的影响，分开使用温升和潜热公式。
- **力、运动、动量与能量**：由运动判断加速度，由受力确定合力；碰撞先检查动量守恒条件，再核算动能，不能把两种守恒混为一谈。
- **密度、压强、气体与对流**：密度参与液体静压和浮力，活塞平衡提供气体压强；玻意耳定律使用固定气体量、恒温与绝对压强，受热密度差联系自然对流。
- **电磁与声波**：扬声器通过电动机效应驱动振膜，动圈式麦克风通过电磁感应输出信号；回声定位另以运动学核对往返时间和单程距离。
- **辐射、原子与动量**：区分电磁波段与α、β粒子辐射，计数先扣本底再分析半衰期；题给核反冲时使用外力冲量可忽略的系统动量守恒。

物理数据不按“都叫辐射”“公式都成比例”等表面相似自动连线。热辐射不直接连成核衰变半衰期；动量守恒不自动推出动能守恒。基础定义和专门装置按区域放大展示，核心网络只是导航骨干，不代表官方考频排名。

化学重点连接电子结构、守恒与实验方法：

- **电子排布、周期与成键**：由中性原子排布定位主族和周期，解释族反应趋势；区分离子、分子、金属和延伸网络后，再判断物性、导电及分离方法。
- **方程、摩尔与实验量**：配平系数连接质量、气体体积、浓度、滴定、限量和产率；矿石品位、金属质量占比和回收率分别处理。
- **氧化还原、电解与金属**：电子账本连接半方程、置换、电极过程和提取；水溶液与熔融体系分开，金属电镀与合金化也分开。
- **速率、能量与平衡**：活化能和碰撞解释快慢，累计量图的斜率与平台分别对应速率和最终量；催化剂不改变净反应焓或给定条件下的平衡组成。
- **有机、检验与环境**：官能团决定反应路径，燃烧连接气体计量及污染物；分离和检验按目标选择，含水阳性不能证明饮用安全。

生物重点连接过程机制与层级：

- **结构、运输与生理**：细胞结构解释交换和供能，跨膜机制用于肺泡、小肠、肾单位、根和叶；消化、吸收及植物整体液流保持不同含义。
- **DNA、分裂与遗传**：复制和分离连接染色体计数及杂交，基因表达连接蛋白质、酶、分化和基因工程；检测到目的DNA不等于功能表达成功。
- **变异与选择**：重组产生组合差异，突变可能产生新等位基因；耐药选择与育种依赖可遗传差异，不把环境影响或个体调整直接当作进化。
- **酶、代谢与调节**：专一性与条件影响连接消化、呼吸和光合，激素与效应器连接稳态；各过程仍需具体运输、反应或反馈依据。
- **植物与生态循环**：光合、呼吸和蒸腾解释净交换及碳水循环，群落取样与多样性联系环境影响；物质循环与能量流动不画成同一种闭环。

## 局部展示规则

- 科目和章节总览都按缩放层级与当前视野共同筛选，默认只显示核心网络。
- 章节范围包含本章及一层直接关联的跨章节点，但首屏只显示本章人工选定的骨干和至多三个直接关联的跨章核心；其余节点在放大对应区域时出现。各层只使用原有关系，不增加传递关系。
- 选中知识点后，显示它及其直接邻居，同时保留邻居之间已经确认的关系，避免把局部网络裁剪成星形。右侧保留直接关联的知识点导航，不展示关联说明；连线不显示悬停提示，也不触发高亮、关联聚焦或手形光标。仅悬浮知识点节点时展示学习进度并突出关联；离开节点移到连线后恢复普通显示。
- 类型筛选同时约束节点扩展和连线；不因两点共同关联某个中心而创建新边。画布下方显示圆点中心实际位于当前视野内的知识点数量，边缘缓冲区节点不计入。

## 总览分层与位置稳定

各数值为该层候选节点 / 关系上限；真正显示的范围还受当前视野限制。

| 科目 | 核心网络（初始） | 方法展开（1.55倍） | 区域细节（2.5倍） |
| --- | --- | --- | --- |
| 数学1 | 20 / 22 | 39 / 70 | 76 / 193 |
| 数学2 | 17 / 22 | 30 / 64 | 39 / 84 |
| 物理 | 16 / 22 | 26 / 56 | 32 / 74 |
| 化学 | 21 / 24 | 59 / 104 | 89 / 167 |
| 生物 | 17 / 22 | 28 / 58 | 34 / 80 |

核心节点和连线由各科的 `*Overview.ts` 分别显式维护，共用 `overview.ts` 的层级规则；它们并非考试重点或考频排名，也不根据用户点亮状态变化。第二层包含核心网络，第三层包含全部数据；所有显示连线均来自原图，不用连接隐藏路径两端的方式制造新关系。收起阈值分别为 1.35 和 2.2 倍，避免临界缩放时闪烁。表中数量是全科候选上限，不表示同时显示全部候选。章节视图采用各自的核心层并同样按视野展开；只有通过考纲或图谱选择具体知识点后的完整直接关联图不受缩放层级限制。

每个范围预先布局并缓存全部坐标。总览先只用核心节点和关键连线排好骨干，再逐层安放方法与细节节点；后续层不移动已确定的节点。核心布局依据真实关系的最短距离和连接数量调整间距，从多个固定起点中选择交叉较少、邻点距离较均衡的结果；最短距离仅用于位置计算，不合成连线。中心约束与整体适配让节点自然分布，避免强制截到矩形边缘。

中英文完整名称通过 ECharts 的实际文字换行规则同时测量，使用较大的预留尺寸；细节按该层最小保留倍率预留空间。碰撞后仍受多个固定标签夹挤的节点会移至最近的空位。ECharts 按原始坐标比例绘制，隐藏节点不会把核心总览拉伸。布局排序、初始种子及候选选择均固定，数据重排和视图重置可复现；名称最大宽度为 156 像素，长名称完整换行。普通名称使用 13 像素字号，选中名称为 14 像素，透明背景且无文字描边，兼顾清晰度和连线可读性。

总览中隐藏节点仍保留坐标以固定 ECharts 的数据边界，但使用 `symbol: none`，无图形、标签、提示或命中区域。`visibility.ts` 使用 ECharts 实际相机转换后的屏幕坐标，同时按层级和视野筛选；连线必须两端都处于渲染范围。缩放或平移都更新筛选，远处节点及连线不随局部放大而全局展开。进入视野使用 32 像素缓冲，已经显示的节点离开 64 像素后收起，减少边缘反复闪现。缩放时保留相同数据边界、视口中心和缩放倍率，只改变可见性，不重新运行布局。语言切换和个人进度更新也保留当前视口。节点位置固定，用户拖动画布浏览；缩放使用滚轮、双指或加减按钮，重置视图回到初始核心层。加减按钮在发送 `graphRoam` 后显式同步相机到画布，因为该指令本身不触发重绘；不能依赖节点集合变化才刷新图形。细线使用 ECharts 的不随缩放加粗绘制方式。

## 代码入口

- `registry.ts`：按考试和科目匹配已发布图谱及对应的分层配置。
- `maths1.ts`、`maths2.ts`、`physics.ts`、`chemistry.ts`、`biology.ts`：各科图谱元数据与完整教学关系。
- 对应的 `*Nodes.ts`：轻量节点与章节元数据，不导入整套讲义；自动校验防止标题或编号与讲义漂移。
- 对应的 `*Overview.ts`：各科总览和章节核心节点、关键连线与方法层节点。
- `overview.ts`：共用的章节骨干选择、关系层级及带回滞的缩放规则。
- `visibility.ts`：按当前视野筛选节点与真实连线，保留边缘缓冲并统计实际可见节点。
- `labels.ts`：中英文名称选择与跨语言搜索；`titleEn` 沿用现有考纲的英文名称，切换不改变知识点编号。
- `layout.ts`：核心优先的确定性布局、细节安放和中英文标签空间避让；仅计算坐标。
- `types.ts`：数据契约、关系标签及是否有向。
- `navigation.ts`：`getKnowledgeGraphNeighbours` 返回直接相邻节点、说明和方向；`getKnowledgeGraphView` 统一控制章节跨章扩展与知识点局部网络，支持关系类型筛选。

数据只使用已有知识点编号。正式页面接入时，仍需与当前考试考纲匹配，并复用学习入口的权益检查；图谱关系本身不授予内容访问权。个人点亮状态应从现有账号接口叠加，不写入公共图谱配置。点亮仅代表用户自评已学完，不代表测评确认掌握。

总览展示真实知识点关系，每个节点下方常驻显示完整名称，长名称换行；名称保留中文与 English 切换能力；选中节点后展示直接关联的知识点导航，并仅为有向关系显示小箭头。蓝色圆点表示尚未点亮，金黄色表示当前账号已点亮。尊重减少动态效果设置；总览采用带标签避让的确定性力导向排布，切换语言不打乱总览节点位置；窄屏保留可读字号，通过拖动和缩放浏览全图。图谱浏览与节点导航不新增操作日志，继续沿用现有“仅实际点亮记录日志”的规则。当前开放 ESAT 全部五科图谱，TMUA 直达图谱时转入当前考试的题库，不读取或展示 ESAT 图谱。

## 知识点悬停进度

悬停节点仅展示已学习/未学习、题库已完成题数；名称保留在节点下方，不在浮层重复。学习状态来自当前账号的点亮记录，仅代表自评；题数独立统计，不据此自动点亮。

- `GET /api/learning-completions/:examType/question-counts` 从认证会话确定账号，批量返回知识点编号到完成题数的映射，响应禁止缓存；不接受客户端指定其他账号。
- 只统计当前考试的独立试题库题目及题库练习答卷（包含练习本），要求已交卷且题目有非空的已作答答案。正确、错误均计入，跳过、未见、空答案、未交卷、诊断和模考不计入。
- 通过题目/知识点唯一关联和已作答记录的存在性过滤去重，同一道题重做多次仍计一题。一道题对应多个知识点时，各自计入一次；已归档题保留历史完成贡献，不把更新后的替代题自动视为已完成。
- 学习状态与题数并行加载，各自保留加载/失败状态；查询失败不显示成未学习或零题。切换账号或考试先清空旧数据，过期响应不得覆盖当前账号；未登录显示登录后查看。
- 自动回归命令：在 `api` 目录运行 `npm.cmd run test:learning-progress`，仅允许本地数据库，以隔离数据验证去重、账号与考试隔离、来源、交卷边界、鉴权及查询不写操作日志。

## 校验与维护

各科均需回归：在 `api` 目录运行 `npm.cmd run test:maths1-knowledge-graph`、`npm.cmd run test:maths2-knowledge-graph`、`npm.cmd run test:physics-knowledge-graph` 和 `npm.cmd run test:chemistry-biology-knowledge-graph`。检查覆盖各章讲义节点及显式别名、关系去重及有效端点、前置无环、具体跨章教学联系、核心网络连通、章节层级、缩放时位置稳定和科目注册边界；页面检查还需覆盖科目切换、考纲联动、个人进度叠加及学习/练习/练习册入口。

在 `api` 目录运行 `npm.cmd run test:maths1-knowledge-graph`。这是不访问数据库的正式回归检查，覆盖讲义节点一致性、悬空端点、自环、端点对去重、解释完整性、前置关系无环及导航方向；同时验证具体教学联系、邻居间已有连线、一层跨章范围、类型筛选和禁止生成传递关系，并校验核心层覆盖七章、骨干真实连通、逐层包含、可见端点完整和缩放回滞阈值；增加章节骨干范围、局部细节、平移切换区域、边缘缓冲计数和缩小收起的检查。布局检查覆盖三种画布尺寸、后续层不挤动先前层、数据重排结果一致、输入不被修改，以及空图、单点与不连通图。浏览器验证还需核对中英文实际标签边界、跨层前后的屏幕坐标、同一层内每次按钮点击后的实际图形坐标与相机转换一致（不能只检查倍率）、隐藏节点无图形、语言/进度更新不重置视口，以及通过考纲和图谱选择进入完整局部图。本次范围为核心筛选和视野展开，沿用现有确定性布局；局部自适应重排及展开动画未在本次新增。

自动检查不能证明教学关系正确。新增关系还需确认：是否确有学习用途、箭头方向是否合理、是否只是一种可选方法、限制条件是否写清。不因名称相似、同处一章或同一道题出现而自动添加关系。
