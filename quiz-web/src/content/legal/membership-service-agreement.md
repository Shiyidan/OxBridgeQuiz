## 一、定义与协议范围

1. **会员服务**：指您支付相应费用后，在约定有效期内获得特定考试类型的会员题库、会员试卷、解析、诊断报告及购买页面列明的其他增值服务。
2. **会员账号**：指完成购买并承载会员权益的云舟备考账号，是识别会员身份及发放权益的主要依据。
3. **考试类型会员**：本平台的会员权益按考试类型分别开通。当前学生购买流程开放 TMUA 和 ESAT，STEP 暂未开放购买，具体以购买页面为准。
4. **固定期限套餐**：当前提供月卡和季卡等由用户主动购买的固定期限服务。**当前没有自动续费或周期性自动扣款；会员到期后如需继续使用，您必须重新下单并主动付款。**
5. 本协议未约定的账号、内容使用、知识产权、个人信息保护和争议解决事项，适用《用户服务协议》和《隐私政策》。与会员购买直接相关的具体提示，以《会员购买须知与权益说明》和订单页面为准。

## 二、购买资格与未成年人购买

1. 购买人应具有与购买行为相适应的民事行为能力，并有权使用所选择的支付账户。
2. 未满十八周岁的未成年人应在监护人的指导和同意下购买会员，不得隐瞒年龄、未经允许使用监护人或他人的支付工具。
3. 不满十四周岁的儿童原则上不得自行注册或购买。确需使用的，应由监护人事先联系我们，并按照平台届时提供的儿童个人信息保护和监护人同意流程办理。
4. 对未经监护人同意实施的未成年人购买行为，我们将依据年龄、金额、权益使用情况、监护人证明及适用法律处理退款或其他请求，不以本协议排除未成年人及其监护人的法定权利。

1. 您必须先登录账号，再选择考试类型、套餐和支付渠道。当前每笔订单仅支持选择一个考试类型；不同考试类型的会员权益原则上需要分别购买。
2. 下单前请核对账号、考试类型、套餐、金额、服务期限和权益说明。账号或考试类型选错时，请在使用会员权益前立即联系客服；能否更换或退款将根据订单及权益使用情况依法处理。
3. 本平台通过银联商务提供聚合支付二维码，并支持支付页面当前列明的支付工具。支付工具可能适用其独立的服务协议和隐私政策。
4. **二维码页面、支付截图、浏览器回跳或用户端提示不能单独作为会员开通依据。只有第三方支付机构确认支付成功、订单金额校验一致且本平台完成履约后，会员权益才正式生效。**
5. 支付确认可能受到银行、支付机构、网络或系统处理时间影响。如已扣款但权益未及时到账，请勿重复支付，并通过订单号联系客服核查。

## 五、会员期限与续购叠加

1. 新购买账号在相应考试类型下没有有效会员时，会员期限自平台确认支付并完成权益发放时开始计算。
2. 相应考试类型已有未到期会员时，再次购买会从当前有效会员结束时间继续增加相应套餐期限，而不是从付款时间覆盖原有剩余期限。
3. 月卡按固定30天增加期限，季卡按固定90天增加期限。具体开始和结束时间以个人中心显示为准。
4. **当前续购需要您重新创建订单并扫码付款，不会自动续期、自动展期或自动扣款。**
5. 会员到期后，对应会员专属内容和不限量访问资格将停止，账号恢复为届时适用的免费权益标准。历史答题和订单数据不会仅因会员到期立即删除，但部分会员内容可能无法继续访问。

## 六、会员权益

在会员有效期内，您可以按所购买考试类型使用购买页面列明的会员权益。当前主要包括：

1. 解锁所购买考试类型中已上线并标记为会员可用的诊断试卷；
2. 在正常个人学习范围内，不限次生成相应功能提供的能力诊断报告与学习建议；
3. 在有效期内，不受普通用户免费练习题量额度限制，可以使用相应考试类型下已开放的专项题库、自由组卷与练习本功能；
4. 查看相应功能提供的完整题目解析、错题记录与历史学习数据；
5. 使用购买页面明确列明且已实际开放的其他会员功能。

请您注意：

1. 不同考试类型、试卷类型和产品版本的内容范围可能不同，会员仅解锁所购买考试类型下已上线且标记为会员可用的内容。
2. “不限量”是指在正常个人学习范围内不受普通用户免费额度限制，不代表允许爬虫、批量抓取、共享账号、商业培训或其他异常高频使用。
3. 题目、试卷和报告会持续更新。若购买页面对题量、套数或特定功能作出明确承诺，该说明属于本次交易的重要内容，我们将依法按承诺履行；具体可用目录以购买时页面及平台实际标记为准。
4. 会员不保证所有考试类型、所有年份、所有题目或所有报告功能同时具备，也不保证取得特定考试分数或录取结果。
5. 因题目数据修订、权利人要求、考试政策变化或安全原因确需下架个别内容时，我们会尽量提供合理替代；如导致会员主要权益无法实现，将依法提供补充履行、延长服务、退款等合理处理方案。

## 八、退款与售后

### 1. 退款申请方式

本平台目前没有用户自助退款入口。您可以通过微信公众号“acemock”联系客服，提供账号、业务订单号、支付时间、退款原因和必要的身份核验信息。客服核实后由有权限的管理员在后台发起退款。

### 2. 支持退款的主要情形

在符合法律规定或下列约定时，您可以申请全额退款：

1. 重复扣款、订单金额错误，或支付成功后平台未开通对应权益且无法在合理期限内补充履行；
2. 因平台原因导致购买的主要会员服务长期无法提供，且无法通过修复、替代服务或延长有效期合理解决；
3. 付款后七个自然日内提出申请，且尚未使用任何会员专属权益，经核验符合平台未使用退款条件；
4. 未成年人未经监护人同意购买，依法应予退款；
5. 法律法规规定或我们另行明确承诺应当退款的其他情形。

“已使用会员专属权益”通常包括开始或完成会员试卷、使用会员题库答题、查看会员专属解析或报告、生成会员诊断结果、批量访问或下载会员内容等。仅打开购买页面、查看会员目录或支付后尚未实际进入会员内容，不当然视为已经使用。

### 3. 通常不支持无理由退款的情形

会员权益已经实际使用后，除服务存在质量问题、平台违约、未成年人依法撤销或法律另有规定外，通常不支持仅因主观改变计划、考试安排变化、忘记使用、购买后未充分使用等原因退款。

账号、考试类型或套餐选错的，请在使用权益前立即联系我们。因用户自行选错产生的退款或调整不作无条件保证，但我们会结合是否使用、是否能够技术调整及消费者权益保护要求合理处理。

**上述约定不用于排除或限制消费者依法享有的退款、解除合同、损害赔偿或其他权利。是否适用七日无理由退货或退款，应根据交易性质和届时适用法律判断。**

### 4. 退款范围和权益回收

1. 当前系统仅支持按原订单全额退款，不支持部分退款、按考试类型拆分退款或仅退还部分剩余期限。
2. 退款申请获批后，款项原则上按原支付路径退回。实际到账时间取决于银联商务、具体支付工具和银行处理进度。
3. 退款成功后，系统将从相应考试类型的当前会员有效期中扣回该订单增加的30天或90天会员期限。
4. 扣回后仍有其他有效期限的，会员继续有效但结束时间相应提前；扣回后不再有有效期限的，会员将被取消。
5. 若原订单之后还有新的已支付或退款中订单，为避免错误回收后续购买的权益，退款可能需要进一步人工核对。
6. 退款请求提交后，在第三方支付机构返回最终结果前，订单可能显示“退款中”。退款失败时，订单恢复为已支付并保留相应会员权益。
