03

按钮分类

按钮分为 Primary、Secondary、Danger、Text、Link 五种类型。图标是适用于所有类型的可选内容配置，不单独作为第六种类型。

01 / PrimaryHIGH

主按钮

页面最重要的下一步操作。一个操作区域通常只出现一个。
type="primary"

02 / SecondaryMEDIUM

次按钮

取消、返回、重置或与主操作并列的次要动作。
type="secondary"

03 / DangerDESTRUCTIVE

危险按钮

只用于删除、清空、作废等不可逆操作，并配合二次确认。
type="danger"

04 / TextLOW

文字按钮

工具栏内的低强调辅助操作，有完整点击热区。
text

05 / LinkINLINE

链接按钮

用于表格行或正文中的轻量入口与操作。悬浮时颜色不变，向上浮起 2px，过渡 200ms。
link

06 / Icon optionsOPTIONAL

图标配置（所有类型通用）

图标是可选属性，不是独立按钮类型。icon 指定图标，iconPosition 选择左侧或右侧，图文间距 8px。iconOnly 仅显示图标，需提供 ariaLabel。解析页返回使用 Text 文字按钮搭配 Back 图标。

默认尺寸展示 520px 桌面宽度；窄屏适配展示 375px 视口下的效果。按真实 CSS 像素展示，空间不足时横向滚动。真实组件还会限制最大高度，保留标题和按钮，内容区单独滚动。

03

使用分类

以下是同一基础组件的组合方式，使用现有属性与插槽完成，不新增弹窗 type。所有示例标题左对齐，按钮默认 Small。

01 / Default确认操作

标准确认

说明操作影响，并提供取消和确认两个入口。图标可选，不单独区分弹窗类型；显示时为 24px，图文间距 12px，顶部对齐。

icon 可选 · iconColor 配置颜色

:icon="WarningFilled" icon-color="var(--color-warning)"

02 / Danger危险操作

危险确认

删除等不可逆操作使用危险色确认按钮，说明具体影响。

confirm-type="danger"
03 / Information单个操作

说明提示

只需用户知晓时隐藏取消按钮，保留一个明确的确认入口。

:show-cancel="false" · confirm-text="我知道了"
04

交互状态

切换查看可用、禁用、加载和失败状态。确认不会自动关闭，业务页面决定何时结束操作。

默认关闭策略：取消和关闭图标可用，Esc / 遮罩关闭默认关闭。loading 时上述退出入口均被锁定；父页面仍可在请求成功后主动关闭。
