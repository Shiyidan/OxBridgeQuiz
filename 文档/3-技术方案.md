# 技术方案

> 本文档为技术方案总览，各模块详细设计见对应子文档。

---

## 一、项目概述

G5 入学考试在线练习与学习平台，面向申请剑桥、帝国理工等英国高校的学生，提供 ESAT / TMUA / STEP 三种考试的诊断测试、试题库练习、错题本和学习报告。

核心技术目标：前后端分离（Vue 3 + Express）、多考试类型抽象、LaTeX 数学公式渲染、ESAT 模块化评分。

---

## 二、技术栈选型

| 层 | 选型 | 理由 |
|----|------|------|
| 前端框架 | Vue 3 + Composition API + TypeScript | 类型安全，组合式 API 适合复杂答题状态管理 |
| 构建工具 | Vite | HMR 快，ESBuild 预构建 |
| UI 组件库 | Element Plus | 中后台生态成熟，el-table / el-form 开箱即用 |
| 公式渲染 | KaTeX | 比 MathJax 快，支持服务端和浏览器端渲染 |
| CSS 方案 | SCSS + CSS 变量 | 全局 Design Token，无 Tailwind |
| 后端框架 | Express + TypeScript | 轻量，生态丰富，团队熟悉 |
| ORM | Prisma | 类型安全的数据库访问，SQLite 和 PostgreSQL 无缝切换 |
| 数据库（测试） | SQLite | 零配置，单文件便携 |
| 数据库（生产） | RDS PostgreSQL | 自动备份，内网隔离，JSONB 支持 |
| 认证 | 短期 Access Token + 7 天滑动 Refresh Session | 支持凭证轮换、设备会话和服务端撤销 |
| 进程管理 | PM2 | Node.js 进程守护，自动重启，日志管理 |
| AI 识别 | Qwen-VL-Max（DashScope） | 图片 → 结构化题目 JSON |
| 对象存储 | 阿里云 OSS | 试卷 PDF 存储和用户下载 |

## 四、数据模型

详见 [3.2 数据库构建.md](3.2%20数据库构建.md)。

```text
Paper ──1:N── Question
Paper ──1:N── ExamRecord ──1:N── AnswerRecord ──N:1── Question
User ──1:N── ExamRecord
User ──1:N── DiagnosticSession
User ──1:N── UserMembership
Syllabus ──1:N── SyllabusNode（自引用树）
```

核心设计原则：
- `Question` 是唯一正式数据源，`Paper.questions` 仅作历史兼容
- JSON 字段（`options`、`answer`、`knowledgePoints`）读写走 `JSON.stringify` / `JSON.parse`
- 关联查询用 Prisma `include`，禁止多次单表查询
- 枚举值（角色、考试类型、试卷来源）集中定义常量，不在业务代码硬编码

## 五、核心模块设计

### 5.1 题目渲染链

`QuestionCard.vue` → `LatexText.vue` → `FormulaBlock.vue`（KaTeX）

`LatexText.vue` 按 `$...$` / `$$...$$` 正则切分文本为段落/行内公式/块级公式，`FormulaBlock.vue` 调用 `katex.renderToString()` 并模块级缓存结果。段落用 `white-space: pre-line` 渲染 `\n` 换行。

详见 [3.1 技术实现方案详解](3.1%20技术实现方案详解.md)。

### 5.2 PDF 试卷解析

浏览器端 pdf.js 将 PDF 逐页渲染为 JPEG → 逐页 POST 后端 → Qwen-VL-Max AI 识别 → 协调器汇合去重排序 → 写入 Question 表。信号量限制 5 并发。

详见 [3.4 试卷上传解析技术方案](3.4%20试卷上传解析技术方案.md)。

### 5.3 诊断测试与评分

学生选择真题卷 → 开始答题 → 交卷 → ESAT 按模块独立评分 → 生成诊断报告。

ESAT 评分使用 raw→scaled 转换表（来自 UAT-UK 官方数据），5 个模块各有独立转换曲线，输出 1.0–9.0 标准分。

详见 [3.1 技术实现方案详解](3.1%20技术实现方案详解.md) 和 [4.8 诊断测试](4-需求文档/4.8%20诊断测试.md)。

### 5.4 会员权益

用户角色（admin/student）→ 会员订阅（按 examType 独立购买月度/年度）→ 免费额度（每种考试诊断 1 次 + 试题库 1 题）。

管理员不受限制。前端 store 做入口控制和展示，后端接口逐条做最终权限判定。

详见 [3.3 登录模块技术方案](3.3%20登录模块技术方案.md) 和 [4.2 会员权益](4-需求文档/4.2%20会员权益.md)。

### 5.5 错题本

按题目 ID 聚合所有错误记录，展示错误次数、历史错误答案、最近错误来源。支持按难度、来源、知识点、提交时间筛选，分页展示。

详见 [4.1 错题本](4-需求文档/4.1%20错题本.md)。

## 六、API 设计规范

### 6.1 统一响应格式

```ts
{
  success: boolean
  code: number | string    // 0=成功，1=通用失败，业务错误用可读字符串
  errMsg: string
  data: T
}
```

### 6.2 分页规范

请求参数 `page` + `pageSize`，响应 `data` 包含 `list` + `pagination`（page / pageSize / total / totalPages / hasPrev / hasNext）。

### 6.3 认证方案

- 登录时签发 15 分钟 Access Token，并通过 HttpOnly Cookie 保存 Refresh Token
- Access Token 仅保存在前端内存，Axios 拦截器自动注入 `Authorization: Bearer <token>`
- Refresh Session 按最近一次成功刷新时间续期 7 天，并在每次刷新时轮换凭证
- 401 时先尝试刷新会话，刷新失败后再跳转登录页
- 后端 `requireAuth` 同时校验 Access Token 和服务端会话状态
- 管理员接口额外经 `requireAdmin` 校验角色

详见 [3.3 登录模块技术方案](3.3%20登录模块技术方案.md)。

## 七、前端架构规范

### 7.1 API 层

所有后端调用通过 `src/api/` 模块函数发起，使用 `callApi<T>({ url, method, isAllData, params, body })` 统一封装。禁止在 `.vue` 文件中直接 `request.get/post`。

### 7.2 组件复用

| 组件 | 使用位置 |
|------|----------|
| `QuestionCard.vue` | 试题库浏览、在线答题、试卷预览 |
| `LatexText.vue` + `FormulaBlock.vue` | 所有含 LaTeX 的题目渲染 |
| `AppPagination.vue` | 所有分页列表 |
| `NavBar.vue` | 全局导航栏 |

### 7.3 路由守卫

- 需登录页面（`/profile`、`/practice`、`/assessment`、`/mistake-notebook`）→ 未登录跳 `/login`
- 管理后台（`/admin/*`）→ 非 admin 角色跳首页
- 已登录访问 `/login` 或 `/register` → 重定向首页

### 7.4 样式系统

全局 CSS 变量定义在 `base.css`（色板 / 间距 / 圆角 / 阴影 / 排版），禁止硬编码色值、禁止 `!important`、禁止行内 `style="..."`。

详见 [2-样式规范.md](2-样式规范.md)。

## 八、安全设计

| 层面 | 措施 |
|------|------|
| 传输 | 全站 HTTPS，TLS 1.2+ |
| 认证 | JWT 7 天有效，密码 bcrypt 哈希 |
| 鉴权 | 前端路由守卫 + 后端接口逐条校验（双重） |
| 网络 | 安全组仅开放 22 / 80 / 443；数据库仅内网访问 |
| OSS | 公共读 + Referer 防盗链白名单 |
| SSH | 禁用密码登录和 root 登录，仅密钥对 |
| 依赖 | 每月 `npm audit` |
| 系统 | 每月安全更新 |

## 九、部署架构

测试环境当前部署于阿里云 ECS（2核4G，Ubuntu 22.04，公网 IP `${QUIZ_TEST_SSH_HOST}`）。生产环境选型参见 [5.1 线上环境选型方案](5.1%20线上环境选型方案.md)。

```text
ECS（2核4G，Ubuntu 22.04）
  ├── Nginx    → 静态文件 + /api 反向代理
  ├── PM2      → Node.js 进程守护
  └── 本地日志 → logrotate 轮转

RDS PostgreSQL（基础版 1核2G，20G SSD）
  └── 自动备份 + 内网隔离

OSS
  └── 试卷 PDF + 导出文件
```
