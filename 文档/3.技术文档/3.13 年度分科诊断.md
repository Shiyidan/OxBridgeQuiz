# 年度分科诊断

2026-10-14：开发环境已完成年度分科改造。正式题目结构见 [统一题目数据结构](3.12%20统一题目数据结构.md)。

## 目录与选科

后台真题库使用 ESAT / TMUA 标签及年份入口。ESAT 每年保存 Mathematics 1、Mathematics 2、Physics、Chemistry、Biology 五科；TMUA 每年保存 Paper 1、Paper 2。科目卡片进入现有题目预览，按科目过滤。题目数量沿用原始数据，不强行补成统一题量。

学生选择年度及科目：ESAT 固定 Mathematics 1，再从其余四科选二；TMUA 使用两卷。前端摘要展示本次所选题量与时长。后端校验科目、发布状态与权限，按年度固定顺序组卷，将题目 ID、科目顺序和时长冻结在 `ExamRecord.structureSnapshot`。同一考试类型存在进行中记录时必须继续原答卷，不能换科目。

年度本身的五科总题量、总时长是管理信息；作答、结果、报告使用本次三科快照和连续题号。共享题目中的年度题号不会因学生选科而修改。

## 统一导入与版本

- `POST /api/papers/diagnostic/validate`：管理员校验年度标准文档。
- `POST /api/papers/diagnostic/import`：管理员导入为新的年度草稿。
- `GET /api/papers/:id/document`：管理员导出标准文档。
- 文档格式标识为 `paper-content-solution-meta-v1`，顶层为 `format/paper/questions`，单题为 `id/code/content/solution/meta`。不再使用 `questionRefs`。
- ESAT 必须完整包含五科；TMUA 必须完整包含两卷且每卷 20 题、75 分钟。校验科目内连续题号、题量、题型、答案选项、图片引用、知识点和解析类型，拒绝字符串化 JSON。
- 导入总是建立新 ID，文件中的题目 ID 不能覆盖数据库旧题。题目写入仍经过 `syncPaperQuestions`。
- 发布新版时，事务内将同考试同年份原已发布年度入口置为已归档并标记 `annual_subjects_retired`。原题目和历史关联继续保留；内容更新必须导入新版本，禁止原地替换年度题目。
- 旧 `/papers/import-json` 不再接受诊断真题导入；其他非诊断流程保留。

## 历史记录与归档失效

历史列表不受新目录过滤影响。最终确认的规则仅让**改造前已经归档的那批诊断卷**失效：通过迁移计划固定 ID，标记 `legacy_diagnostic_expired`，历史条目展示摘要并提示“当前试卷已失效，请查看最新版试卷”。不能使用所有 `archived` 状态作为失效判断，普通归档及年度版本退休仍允许查看正常历史。

迁移预检默认不标记任何失效卷。需要失效时，先核对同步/改造前的业务状态，再使用 `--expired-paper-ids-file=<JSON文件>` 显式提供试卷 ID 数组。为保留历史而技术归档的卷不得列入。旧版自动根据当前归档状态推断失效的 v1 计划禁止应用，须重新生成 v2 计划。

结果、报告摘要、报告状态、重试与重新生成接口先核验当前用户归属，再对显式失效标记返回 HTTP 410 / `DIAGNOSTIC_PAPER_EXPIRED`。直接访问旧链接同样显示失效，分析弹窗停止轮询和重试。归档模考不受影响。本轮不物理删除旧卷，不通过级联删除实现历史失效。

**原正常诊断卷的历史关联迁入年度新卷。** 科目代码和科目内题号只用于寻找候选；题干、图片、选项、正确答案、题型、考试和来源必须一致才可映射。段落 `inline` 仅为排版差异；解析、考点、复习建议及分类允许采用新版，不作为阻断关联的条件。历史逐题页面直接读取关联新题的解析。迁移更新 `ExamRecord.paperId`、`AnswerRecord.questionId`、模块快照题目 ID、报告和报告任务的 `paperId`、报告来源快照的 ID。答卷和答案自身 ID、作答、成绩、时间、阶段和已生成报告正文不变，不重新判分或生成报告。

`structureSnapshot.diagnosticHistory` 保存原卷摘要、原题号、原科目位置与旧题 ID 别名。原模块快照只换题目引用；连续旧考试仍按原时长与连续计时恢复。历史入口显示本次原三科，不能读取新版年度五科作为历史组合。结果和报告使用原题号/科目/时长，旧单题链接可按 `originalQuestionId` 定位到新题。

历史列表展示标题统一为“考试类型 年份 · 本次作答科目”，例如 `ESAT 2023 · 数学1 / 化学 / 数学2`、`TMUA 2022 · Paper 1 / Paper 2`。科目及其顺序只取答卷快照；缺少科目时显示“考试类型 年份 诊断测试”，不回退到年度题库全部科目。仅调整展示，不改写快照原始标题、答案、成绩或报告。

错题及收藏引用同步迁移：重复错题摘要汇总次数及时间范围，每条错误作答事件 ID 和内容保留；同分类重复收藏保留最早条目，分类不同则中止迁移，不能静默覆盖分类。源题被无关业务答卷引用、题目内容不等、缺少原分段快照等情况均中止。原题正文无需继续复制，旧原卷作为本次备份及追溯来源暂留，标记 `legacy_diagnostic_migrated`。

## 正常历史关联迁移

必须先完成统一题目结构及年度科目库创建。停止目标环境的作答写入与报告 worker 后生成固定计划；部署时需分别审计目标数据库，不能沿用开发环境计划。

```bash
npm run migrate:diagnostic-history -- --dry-run --environment=local
npm run migrate:diagnostic-history -- --apply --environment=local --plan=<dry-run输出的计划路径> --confirm=RELINK_DIAGNOSTIC_HISTORY
```

计划保存在 `.private/diagnostic-history-migration/`，包含全部受影响行的前镜像；apply 再建立独立 gzip 备份。事务开始重新比较全量指纹，计划生成后数据有变化就停止并要求重新审计。整个计划在 Serializable 事务内执行，任何写后核验失败回滚；同一计划重复执行会跳过已完成迁移。报告正在生成时拒绝迁移。删旧题和删旧卷不属于该脚本。

本地执行结果：55 张从线上同步的正常旧卷中，2,812 道题精确映射到年度题，这批副本没有学生答卷，因此实际关联更新为 0 份。2026-10-14 纠正：另 3 张本地旧卷在同步前均为已发布；同步时为保留历史而被技术归档，并非业务归档。此前错误添加的失效标记已撤销。用户确认历史逐题解析采用新版后，核对这 3 张卷的 149 道题仅有解析、分类及段落排版差异，已完成 14 份答卷、742 条答案、12 份报告及任务的年度关联，失效数为 0。逐字段核验原作答、成绩、时间和报告正文未变；2023 数学 1 第 2 题的 11 条历史答案已指向新版详细解析。备份与计划位于 `.private/diagnostic-history-migration/`，验收记录为 `.private/diagnostic-sync-20261014/current-history-verified.json`。线上只读聚合查到 55 张正常卷、402 份答卷（335 已提交、67 进行中）、20,120 条答案、334 份报告，没有归档卷；本轮未部署或执行线上迁移，线上仍须完整 dry-run。

`npm run test:diagnostic-history-migration` 使用独立真实数据库夹具验证非零历史迁移：重排 ESAT 三科、TMUA、连续答卷、暂停和休息暂停恢复、引用更新、报告原文、错题合并、收藏冲突、旧单题链接、普通归档可读、原失效批次隔离、并发拒绝及幂等。

## 已迁移旧卷清理审计

在 `api/` 下运行 `.\node_modules\.bin\tsx.cmd scripts/audit-diagnostic-history-cleanup.ts --environment=local` 进行只读审计。脚本只检查 `legacy_diagnostic_migrated` 卷，枚举 Prisma 当前全部卷/题外键，补充无外键的错题事件引用，并扫描答卷、报告及组卷 JSON 中的旧 ID；不会删除数据。

2026-10-14 本地审计：58 张已迁移旧卷、2,961 道旧题无答卷、答案、报告/任务、错题、收藏、模考、替换题或解析任务引用。JSON 中仅剩 14 份历史快照的原卷 ID 和 742 个原题 ID 别名；这些用于追溯及旧链接定位，不查询旧卷/题行，必须保留在历史快照中。14 份答卷、742 条答案、12 份报告和任务均指向新年度数据。独立测试夹具实际删除源卷及级联旧题后，历史列表、ESAT/TMUA 结果、新解析、报告和续答接口仍通过，原用户事实数据逐字段未变。此次未删除真实业务旧卷/题，也未审计或修改线上清理范围。正式清理须按固定候选 ID 在备份后重检引用，不能直接沿用旧计数删除。

## 年度数据迁移

测试环境需要使用已整理的开发年度题库，且旧组合卷存在内容冲突时，可在用户明确确认后执行 `npm run sync:test-annual-diagnostics -- --dry-run`。确认预检结果后使用 `--apply --confirm=APPEND_DEVELOPMENT_ANNUAL_DIAGNOSTICS --backup-manifest=<测试部署前完整备份清单路径>`。该流程固定从本地开发库读取已发布年度卷，通过私有部署配置选择测试环境，仅在内存中传输数据和本地构建的维护代码，不在服务器编译。目标环境再次核对运行环境及数据库名称；只追加年度卷，不覆盖已有不同内容的年度、旧卷、独立题库或用户记录。源数据备份后在同一事务内逐题核验，并比对原卷、原题、模考、用户及答题历史保护集合，失败即回滚。相同年度与内容再次同步会跳过。

2026-10-14 清理执行补记：用户明确授权删除开发环境上述旧数据且不新增备份。已在事务内重检引用后删除固定清单中的 58 张旧卷及级联的 2,961 道旧题，未创建新备份；仅保存计数结果。其余 32 张试卷、3,168 道题目、37 份答卷、1,588 条答案、19 份报告及任务，以及错题、收藏、模考等数据逐表摘要完全一致。删除后再次核验已迁移的 14 份答卷、742 条答案、12 份报告及新版解析，通过历史/报告/续答 HTTP 回归，API 健康检查及前端返回正常。执行计数见 `.private/diagnostic-history-cleanup/deletion-result.json`。线上未操作。
