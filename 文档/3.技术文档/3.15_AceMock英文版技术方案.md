# AceMock 英文版技术方案

版本：V1.0｜日期：2026-11-21｜状态：设计方案，尚未实施

## 1. 建设目标与原则

在现有 Vue 3 + Express + Prisma 平台上增加英文版，保持一套代码、统一题库和业务逻辑，支持海外用户及中国国际生使用。

- 界面支持 `zh-CN`、`en`，英文术语按英国考试场景统一。
- 题干与选项默认保留英文原题；正确答案、评分规则、题目 ID 和学习记录共用。
- **解析接口同时返回中英文，解析区域独立切换语言，不随界面语言强制改变。**
- 中文界面可看英文解析，英文界面也可看中文解析。
- 管理后台首期保留中文；题干中文翻译、双语并排对照及自动续费不纳入首期。

## 2. 改造范围

| 模块 | 技术处理 |
| --- | --- |
| 首页、导航、账户、考试及会员页面 | Vue I18n 管理界面文案，Element Plus 同步语言 |
| API 错误提示 | 保持统一响应格式，以稳定错误码映射本地化提示，未知错误使用对应语言的通用提示 |
| 题目与解析 | 共用英文题目，`solution` 保存双语解析，查看解析时同时返回 |
| 学习中心 | 共用知识点编码、关联题目及交互组件，讲义正文按语言组织并按需加载 |
| 诊断报告 | 共用指标事实，规则文案和 AI 解读支持对应语言 |
| 邮件 | 验证码、找回密码及通知使用对应语言模板 |
| 搜索与分享 | 英文公开页拥有独立 URL、标题、摘要和分享信息 |
| 海外收款 | 在现有订单与会员权益体系上扩展渠道、市场价格和币种 |

语言、市场和币种分别配置。切换语言不改变价格、会员权益或账户归属。

## 3. 前端语言与交互

界面文案按模块组织至 `quiz-web/src/locales/zh-CN/`、`quiz-web/src/locales/en/`，使用统一语言状态控制导航、按钮、表单、弹窗、日期及数字格式。

公开页采用明确语言地址，首期新增 `/en/` 及对应英文路径，现有中文路径保持兼容；路由守卫、登录回跳和 SEO 同步适配。明确的语言路径优先，首次无语言入口可参考已保存偏好和浏览器语言。

解析语言独立保存为 `explanationLocale`：

1. 首次查看使用已保存的解析偏好；未设置时参考界面语言。
2. 解析区域提供 `English｜中文` 切换，一次切换整个解析区域，包括解题过程、选项分析、考点及复习建议。
3. 两种语言已随解析接口返回，切换时无需再次请求或实时翻译。
4. 切换不重置题目、答案、计时器或解析展开状态；后续题目沿用最近选择。
5. 首期在当前浏览器按用户隔离保存偏好，退出后不沿用前一账户的偏好；跨设备同步后续按需增加。
6. 缺少目标语言时明确提示，并展示可用语言；临时回退不覆盖用户保存的偏好。

练习、错题复习、收藏和交卷后逐题回顾复用同一解析组件。切换的是解析正文语言，按钮与区域标题仍使用界面语言。

## 4. 题目数据结构

保留现有统一文档 `id/code/content/solution/meta` 和 `Question` 唯一题目源，在 `Question.solution` JSON 内扩展语言版本。首期不新增独立翻译表。

目标结构示意如下，实际解析字段及其类型沿用现有规范；已有选项分析、图文块等扩展必须逐项映射，不得丢弃。

```json
{
  "solution": {
    "answer": ["A"],
    "explanations": {
      "en": {
        "correctSolution": "Divide both sides by 2 to obtain x = 2.",
        "examFocus": "Linear equations",
        "commonErrorCauses": ["Not applying the same operation to both sides"],
        "reviewGuidance": "Review the properties of equality."
      },
      "zh-CN": {
        "correctSolution": "等式两边同时除以 2，得到 x = 2。",
        "examFocus": "一元一次方程",
        "commonErrorCauses": ["等式两边未进行相同运算"],
        "reviewGuidance": "复习等式的基本性质。"
      }
    }
  }
}
```

- `answer` 只保存一份，继续由 `getQuestionAnswer` 读取；语言切换不影响判分。
- 题干、选项和原题图片继续放在 `content`，不复制成两道题。
- 无语言差异的公式、资源和业务编码共用；解析图片中的文字需提供相应语言版本。
- 译文提前生成、审核、保存，不在学生请求时临时调用 AI 翻译。
- 记录解析修订版本、译文对应的源版本和审核状态；一侧修订后将另一侧标记为待复核。学生接口只返回可发布版本。

## 5. 接口设计与访问边界

沿用 `{ success, code, errMsg, data }` 响应格式，前端调用继续集中在 `quiz-web/src/api/`。

| 场景 | 返回内容与规则 |
| --- | --- |
| 加载待作答题目 | 返回题干、选项等作答字段，不查询或返回 `solution` |
| 练习提交后查看解析 | 服务端验证该模式允许查看后，返回答案及双语解析 |
| 模考、诊断考试进行中 | 不返回答案或任一语言解析；直接请求解析接口也需拒绝 |
| 交卷回顾、错题复习 | 校验记录归属与权益后返回双语解析 |
| 管理编辑与预览 | 按管理权限返回双语内容、版本及审核信息 |

已有解析或结果接口扩展后的业务数据示意：

```json
{
  "questionId": "123",
  "answer": ["A"],
  "availableLocales": ["en", "zh-CN"],
  "explanations": {
    "en": { "correctSolution": "Divide both sides by 2." },
    "zh-CN": { "correctSolution": "等式两边同时除以 2。" }
  }
}
```

该示例放在统一响应的 `data` 中，其他解析字段同样按语言返回。接口根据实际可发布内容生成 `availableLocales`，不依赖前端隐藏答案来控制权限。

解析按当前题目或分页批量获取，避免一次下载整个题库。双语解析缓存按题目及内容版本区分；用户可访问性始终由服务端验证。

## 6. 导入、编辑与历史兼容

统一调整 `buildQuestionStorage`、`solutionToLearningAnalysis`、`canonicalQuestionToInput` 和题卡 DTO 映射，确保导入、保存、导出与展示不会丢失双语字段。写入继续通过 `syncPaperQuestions`。

实施顺序：

1. 盘点现有解析字段及真实语言，区分英文、中文和混合内容；不能把旧解析统一认定为中文。
2. 先部署支持新旧解析读取的适配层，再进行 JSON 数据回填。
3. 回填先备份和试运行；保留题目 ID、答案、来源、扩展及历史关联，逐项核验内容无损。
4. 对缺失语言生成译文并审核，按题目分批发布；保存某一语言时保留另一语言，并进行版本冲突校验。
5. 历史答卷快照按原版本读取，不改写成绩和报告；旧快照仅有单语时显示其真实可用语言。
6. 全部读写入口切换并完成回归后，再结束旧格式兼容，避免长期维护两份权威解析。

仅扩展现有 JSON 不涉及数据库加列；若实施中增加偏好字段或独立版本表，另走 Prisma schema 迁移流程。

## 7. 学习中心、报告与邮件

- **学习中心：**正文按知识点编码保存语言版本，共用教学结构、图表逻辑和题目关联；图表标签也需本地化。正文按界面语言加载，未完成英文审核的章节明确标注或暂不开放。
- **诊断报告：**同一答卷保留一份指标事实与原始分析结论，增加语言文案版本；切换语言不重新评分或覆盖原报告。固定文案通过规则映射，AI 文案以同一结论为依据生成等义表达；任务、缓存及结果记录语言和内容版本。
- **邮件：**注册与找回密码请求传入语言并进行白名单校验；后台通知保存收件语言快照。英文主题、正文、链接及落地页面保持一致，实际验证海外常用邮箱收信。

## 8. 海外上线配套

- 域名与 SEO：验证期使用现有站 `/en/`；正式海外域名通过配置接入同一代码，英文公开页配置自身 canonical、对应语言的 `hreflang`、站点地图和分享信息。优先为营销公开页提供预渲染内容。
- 部署：先实测目标地区加载、图片、保存答案和交卷表现，再决定 CDN 或海外应用部署；首期不建设跨区域数据库双向同步。
- 支付：将渠道创建、查询、回调和退款封装为服务商适配层，复用现有订单与会员权益。先确认收款主体与服务商准入，再接入一个主要渠道和币种。
- 定价：服务端确定套餐价格，订单保存金额与币种快照；回调验签、核验金额币种并保证权益发放幂等，收入按币种统计。
- 运营：准备英文服务说明、隐私说明、退款说明和客服入口；自动续费另行规划。

## 9. 实施步骤与验收

| 阶段 | 交付内容 | 核心验收 |
| --- | --- | --- |
| 1. 国际化基础 | 界面语言、路由、组件文案、错误提示、邮件 | 英文首页至注册登录可完整使用 |
| 2. 双语解析 | JSON 扩展、接口、统一解析组件、导入编辑和历史兼容 | 双语同时返回，局部即时切换，不影响作答与判分 |
| 3. 学习与报告 | 讲义、图表、报告语言及内容审核 | 已发布范围无中文误回退，指标与结论跨语言一致 |
| 4. 海外经营 | 支付、英文公开页、访问性能和客服流程 | 购买、权益到账、学习、订单查询及退款链路可用 |

首期选择一个考试类型跑通完整流程，再扩展其他科目和章节。正式验收至少覆盖：

- 中英文界面与中英文解析的四种组合，以及刷新、换题、退出换账户后的偏好行为。
- 未作答或未交卷时无法获取任一语言答案；交卷后权限与权益判断正确。
- 语言缺失、混合语言旧数据、历史快照、公式及图片展示正确。
- 双语导入—编辑—导出往返无损，单语言编辑不覆盖另一语言，修订后译文状态正确。
- 原中文功能、评分、作答保存、错题关联和报告数据回归通过。
- 执行前端类型检查及生产构建、后端构建，以及受影响的题目文档、作答和报告测试。

## 10. 首次实施：入口与首页（2026-11-21）

本轮已实现入口与首页，其他阶段继续按上述方案推进。

- **访问入口：**中文首页 `/`，英文首页 `/en/`（兼容 `/en`）。桌面及移动导航提供 `EN / 中文` 切换；切换保留查询参数和锚点，刷新及前进后退跟随 URL 的语言。
- **界面语言：**通过 `vue-i18n` 统一管理首页文案；首页显式路径优先，其他页面的公共导航沿用本地语言偏好。此偏好与后续题目解析语言独立。
- **首页范围：**访客介绍、产品功能、首页学习演示与精选题反馈、会员年卡、页脚，以及登录后学习概览和备考目标弹窗。接口业务编码、题目答案、会员价格与计费币种保持原值；英文价格标明 CNY。
- **入口衔接：**英文首页的登录入口与购买登录回跳保留 `/en/`，品牌入口返回当前语言首页。其他业务页继续使用原路由。
- **搜索与首屏：**构建生成独立 `dist/en/index.html`，包含英文预渲染正文、页面标题、摘要、canonical、hreflang 和分享信息；站点地图新增英文首页。
- **支付弹窗：**套餐、权益、期限、扫码说明、支付状态和操作提示跟随界面语言；英文价格标明 CNY，折扣使用百分比优惠表达。切换语言仅更新展示，保留当前订单和二维码；金额与支付渠道沿用原配置。协议链接注明正文为中文，国际支付渠道及英文协议另行实施。
- **账号入口：**登录、密码重置和注册页共用界面语言，覆盖表单、字段校验、验证码倒计时、认证错误、账号暂停说明及备考选项。切换语言保留已填信息，院校与科目仅翻译标签，提交原业务值；无指定目标时认证后返回当前语言首页。注册限流提示保留服务端重试时间并注明北京时间，协议链接明确标注正文为中文。
- **本轮边界：**正式学习中心、题库、邮件及法律文件正文尚未整体英文化；诊断界面的后续实施见第 11 节。现有中文产品截图明确标注预览语言；未提供译文的接口自由文本保留原文。首页静态示例翻译不替代正式题库双语解析接口。
- **交互验证：**已检查桌面与手机语言切换、刷新和历史导航、登录回跳、学习示例及作答反馈；登录后未选目标、首次诊断、进行中诊断使用本地模拟接口验证。本轮未修改数据库或部署线上环境。
- **工程验证：**按项目锁定版本完成前端类型检查及生产构建，修改文件的 ESLint 检查通过；核对中英文预渲染文件的语言、canonical、hreflang 与初始正文，18 道静态示例题的翻译及公式保真检查通过。

## 11. 诊断模块前端英文化（2026-11-22）

- **覆盖页面：**ESAT/TMUA 年度诊断入口、科目确认、历史记录、连续和分段答题、休息与交卷弹窗、报告分析进度与失败提示、V1/V2 报告、逐题解析的导航和操作。会员及试卷失效提示同步支持英文。
- **语言切换：**复用 `t` 与全站语言偏好，答题顶部增加同款语言入口。切换仅更新界面，保留当前题目、答案、计时和报告页内状态；业务 URL 不变，浏览器标题与文档语言同步更新。
- **翻译方式：**固定文案集中在 `src/locales/diagnostic.ts`；科目及状态只翻译展示标签。前端规则生成的统计说明保留原有计算与数值，通过已登记句式传参展示；相邻参数或多条说明拼接时显式传参，避免推断边界。图表标签、提示和日期格式随语言更新。
- **内容边界：**题干、选项、公式、解析正文以及未提供译文的接口报告自由文本保留原文。英文页在存在未翻译正文时提示原文语言；本次不实现题目解析的独立双语接口，也不重新生成或翻译存量报告。
- **业务边界：**不修改考试状态、答卷保存、判分、会员校验和报告生成规则；V1/V2 仍由服务端 `productVersion` 决定。接口错误在诊断页使用已配置英文提示，未知中文异常使用通用失败提示。
- **验证：**使用本地模拟接口检查 ESAT/TMUA 年度入口、确认与历史弹窗、新旧报告、V2 各分析标签、报告生成及失败、分段答题、科间休息和逐题解析。验证切换语言后保留答案、倒计时继续运行且不创建新答卷；检查桌面和手机布局无横向溢出。真实后台报告生成和线上部署不在本次验证范围。
