# 真题 JSON 导入技术方案

## 一、功能边界

管理后台真题库只接受 UTF-8 编码的标准 JSON 文件。

所有正式题目通过 `syncPaperQuestions` 写入 `Question` 表：

- `Question` 是上传预览、考试、报告、题库和错题本的唯一正式题目数据源。
- `Paper.questions` 仅保留为历史数据回填输入，新导入流程不得读写。
- 试卷交付方式、模块配置、休息策略和来源说明写入 `Paper`。
- `ParseTask` 仅保留既有数据库记录及外键关系，当前业务不创建或读取解析任务。

## 二、支持的数据结构

### 2.1 兼容扁平试卷

```json
{
  "metadata": {},
  "questions": []
}
```

扁平结构仅用于普通练习、题库或仍按整卷连续作答的历史兼容数据。ESAT 与 TMUA 的 `realPaper` 诊断卷发布前必须使用分段结构。

### 2.2 ESAT 三模块诊断卷

```json
{
  "metadata": {
    "code": "ESAT-EQUIV-2023-M1-PHY-M2",
    "title": "ESAT 2023 Equivalent Diagnostic",
    "examType": "ESAT",
    "year": 2023,
    "paperType": "realPaper",
    "accessTier": "member",
    "assemblyType": "legacy_equivalent",
    "deliveryMode": "section_sequence"
  },
  "sections": [
    {
      "code": "maths1",
      "sectionType": "subject",
      "order": 1,
      "questions": []
    }
  ]
}
```

正式文件必须提供恰好三个非空 section，包含 `maths1`，且每个 section 的 `sectionType` 为 `subject`。服务端按考试规则派生每科 40 分钟与 180 秒可跳过休息。

### 2.3 TMUA 两卷诊断卷

```json
{
  "metadata": {
    "code": "TMUA-2025",
    "title": "TMUA 2025 Diagnostic Paper",
    "examType": "TMUA",
    "year": 2025,
    "paperType": "realPaper",
    "accessTier": "member",
    "assemblyType": "original",
    "deliveryMode": "section_sequence"
  },
  "sections": [
    {
      "code": "paper1",
      "sectionType": "paper",
      "order": 1,
      "questions": []
    },
    {
      "code": "paper2",
      "sectionType": "paper",
      "order": 2,
      "questions": []
    }
  ]
}
```

正式文件必须依次提供 `paper1` 和 `paper2`，每卷 20 道完整单选题。服务端派生每卷 75 分钟、整卷 150 分钟；Paper 1 锁定后直接进入 Paper 2。

## 三、导入流程

```text
选择 .json 文件
  → 前端读取 metadata、sections 和 questions
  → 展示试卷元数据、模块与题目预览
  → POST /api/papers/import-json
  → validateStandardPaperDocument 校验并归一化
  → 创建 draft Paper
  → syncPaperQuestions 写入 Question
  → 返回 Paper ID、模块信息与 warnings
```

管理员可以在导入前调整页面允许编辑的元数据。新版分段文档的时长、题量和分段切换规则由服务端考试配置派生，不从客户端接受这些规则字段。

## 四、校验规则

服务端必须验证：

- 元数据类型、考试类型、试卷类型和访问级别。
- `metadata.code/title/year/examType/paperType/assemblyType/deliveryMode` 完整，且分段卷的 `deliveryMode` 为 `section_sequence`。
- ESAT 恰好三个不同科目 section 且包含 `maths1`。
- TMUA 恰好两个 paper section，并依次为 `paper1`、`paper2`，每卷 20 题。
- section 的 `code/sectionType/order/questions` 完整且标识唯一。
- 分段诊断题目只允许 `single_choice`，正确答案必须属于选项标签。
- 题目 `contentBlocks`、`classification`、`source`、`learningAnalysis` 和图片引用完整。
- section 内题号唯一，入库时另生成全卷连续 `Question.number`。

`syncPaperQuestions` 在事务内同步题目。试卷一旦存在 `ExamRecord`，不得覆盖题目或模块结构，应创建新的试卷版本以保证历史作答与报告可复现。

## 五、安全与渲染

- 位图地址只允许站内相对地址、HTTP(S)、临时 blob 和常见位图 base64，不接受 data:SVG/HTML。
- SVG 通过编码后的图片地址展示，不把上传内容直接注入 DOM。
- 作答接口只返回白名单字段，不下发答案、学习解析或嵌套正确标记。
- `contentBlocks` 决定题干与题图顺序，公式统一交给现有 KaTeX 渲染链处理。
