# 错题本 PRD

## 1. 功能边界与目的

### 1.1 目标

错题本面向已经登录的学生，长期收录其在诊断测试、真题练习和试题库练习中暴露的错误，帮助学生跨考试、跨科目回看薄弱知识点，并直接进入对应题目的解析完成复习。

错题本不是某一次考试的结果页，也不是试卷列表。它关注的是学生长期累积的错误资产：同一道题即使多次做错，也只占一个列表位置，但保留全历史错误次数和曾经选错的答案。

### 1.2 本次范围

本次覆盖：

- 自动收录已正式提交答卷中的错误题目和未作答题目。
- 按考试类型、来源、科目、知识点、难度和收录时间筛选。
- 按题目聚合全历史错误次数和历史错选答案。
- 展示题目的考试类型、科目、主要知识点及最近一次错误上下文。
- 从错题卡片进入单题解析，并返回原错题本筛选位置。
- 区分加载中、加载失败、无错题和筛选无结果。
- 支持分页，并在翻页时保留已应用的筛选条件。

### 1.3 核心业务概念

**正式收录**：只有学生已经正式提交的答卷才会产生错题。保存中的练习、尚未交卷的诊断测试和其他临时进度不得提前进入错题本。

**一条错题**：当前按题目唯一标识聚合。同一题目多次做错只展示一张卡片；题干相似但题目标识不同的记录仍视为不同错题。

**收录时间**：使用发生错误的整次答卷提交时间。它表示“这道错误在哪次提交中被系统确认”，不表示学生在答题过程中的精确点击时间。

**历史统计**：错误次数和曾选答案始终统计该题的全部正式错误记录。日期范围只决定“哪些题在该时段内曾经出错并进入结果”，不会把卡片上的历史次数截断为所选时段内次数。

**长期保留**：一道题只要曾被正式判错，就继续保留在错题本中。学生后来做对不会自动移除该题，也不会清除过去的错误次数和错选答案。

### 1.4 角色与权限边界

错题本只展示当前登录学生自己的答题历史。学生不能通过地址参数、筛选条件或解析入口查看其他学生的错题和作答结果。

管理员对试卷进行下线或归档，不影响学生已经形成的历史错题。对于已经产生答题记录的题目，应优先下线或归档，不应直接物理删除。

### 1.5 关键业务约束

- 已提交且判定错误的作答进入错题本；已提交但未作答的题目也可作为错误收录。
- 未交卷记录、保存进度和中途离开的临时答案不得进入错题本。
- 同一道题按题目标识聚合，不按题干文本相似度合并。
- 最近一次错误记录决定卡片展示的收录时间、单题耗时和解析上下文。
- 错误次数和历史错选答案来自全历史正式错误记录。
- 多个筛选条件同时存在时取交集。
- 后台修改题目内容不会改写历史判题结果，但解析页默认展示题目的当前版本。

## 2. 页面描述

### 2.1 页面由上到下的构成

学生进入错题本后，依次看到页面标题与用途说明、筛选区域、状态提示、错题列表和分页器。点击卡片右侧“查看解析”后进入单题解析页；从解析页返回时回到原来的错题本地址，并恢复已应用筛选和页码。

### 2.2 筛选区域

筛选区域按照业务依赖顺序排列：

1. 考试类型；
2. 来源；
3. 考试科目；
4. 知识点；
5. 难度；
6. 收录时间。

考试类型默认是“全部考试”。当学生选择 ESAT 或 TMUA 后，页面加载对应考试的科目和考纲；未选择考试类型时，科目和知识点不可选择，并提示学生先选择考试类型。切换考试类型会清空旧科目和旧知识点，防止不同考试体系的筛选条件混用。

来源支持真题、模考和试题库。面向学生统一使用“试题库”文案，不展示内部生成方式；历史数据缺少来源时，卡片展示“来源-未知”，不得默认显示为真题。

科目和知识点支持多选。学生选择科目后，知识点树只展示所选科目下的内容；改变科目会清空旧知识点。选择父级知识点时，界面应同步表现其子级被覆盖，筛选结果包含该父级下的所有后代知识点。

难度支持多选，包括低、中、高和复合；难度缺失的题目在卡片中显示“难度-未标注”。

收录时间使用日期范围。可选下限为该学生第一条正式错题的收录日期，上限为当天，未来日期不可选。筛选区域固定提示：日期只决定哪些题进入结果，卡片中的错误次数和曾选答案仍按全历史累计。

学生修改条件后，只有点击“搜索”才会应用。点击“重置”清空全部条件、回到第一页并恢复完整错题列表。加载期间搜索和重置按钮不可重复触发。

### 2.3 错题列表

每张错题卡片从上到下展示：

- 考试类型与考试科目；
- 最近一次错误的收录日期和时间；
- 最近一次错误的单题耗时；
- 难度和来源；
- 全历史错误次数和全历史曾选答案；
- 主要知识点摘要；
- 题目标题；
- “查看解析”入口。

知识点较多时只展示前两个名称和剩余数量，避免题目标题被大量标签挤压。未作答导致的错题没有历史选项时，不展示空的“历史曾选”标签。

列表默认按最近一次错误的收录时间倒序。同一题目多次做错只展示一次；最近一次做对不会让它消失。

### 2.4 分页

首次进入默认展示第一页。点击搜索或重置后回到第一页；切换每页数量也回到第一页。翻页和切换每页数量只读取已经应用的筛选条件，学生尚未点击搜索的草稿选择不能提前影响列表。

筛选和分页状态会保存在当前页面地址中。从单题解析返回、刷新页面或复制该地址重新进入时，页面恢复相同的已应用条件和页码。

### 2.5 单题解析页

点击“查看解析”进入该题最近一次错误答卷所对应的单题解析。页面只展示当前错题，不把学生带到整份试卷的题目导航，也不先跳到诊断总报告。

解析页展示题目、学生当次作答、正确答案、解析以及题目已有的学习分析。页面顶部提供“返回错题本”，返回后恢复原筛选条件和页码。

缺少有效答题记录时，“查看解析”不可点击；题目不属于指定答卷时，解析页明确提示无法加载该题，不得展示其他题目代替。

### 2.6 页面状态变化

首次加载时，列表区域显示“加载中”，筛选区域仍保持可读。加载成功后，根据结果进入正常列表、无错题或筛选无结果状态。

学生从未产生正式错题时，页面显示“暂无错题”；已应用筛选但没有命中时，显示“暂无匹配错题”，并提示调整条件。这两个状态不得混用。

首次加载失败时，页面显示“错题加载失败”、具体错误信息和“重新加载”入口，不得显示成“暂无错题”。如果学生此前已经成功看到列表，后续搜索或翻页失败时保留上一次成功结果，同时提示当前结果未更新。

考纲加载失败只影响科目和知识点选择。页面显示考纲加载失败提示，已有错题列表、来源、难度和日期筛选仍可使用。

## 3. 核心流程

### 3.1 主旅程

完成一次答题并正式提交 → 错题被收录 → 进入错题本 → 选择考试体系和复习范围 → 搜索并查看聚合错题 → 进入单题解析 → 返回原错题列表继续复习。

### 3.2 正式收录

学生在诊断测试、真题或试题库练习中答题。保存进度、离开页面或恢复练习只更新进行中任务，不产生错题。

当学生正式提交答卷后，系统根据最终提交内容确认错误题目。选错和未作答都可以收录；答对的题目不会新增错误次数。若同一道题此前已经存在于错题本，本次错误累加到该题的历史记录中，不新增重复卡片。

### 3.3 进入并识别当前状态

学生通过导航进入错题本。系统只读取当前学生已经正式提交的错误记录，并返回第一页结果及可选日期下限。

如果地址中带有之前保存的筛选和分页状态，页面先恢复这些条件，再请求对应结果。地址中的无效考试类型或不完整日期范围会被忽略，不得阻止页面进入。

### 3.4 选择复习范围

学生可以直接浏览全部考试，也可以先选择 ESAT 或 TMUA。选定考试类型后，页面加载该考试的科目和知识点，学生再按来源、科目、知识点、难度和收录时间缩小范围。

选择父知识点等价于选择该节点覆盖的全部后代知识点。多个知识点之间为“命中任意一个”，不同筛选维度之间为“同时满足”。

学生点击“搜索”后，新条件成为已应用条件，列表回到第一页。系统先判断哪些题在所选日期内曾经出错，再为这些题展示全历史错误次数、全历史错选答案和最近一次错误上下文。

如果请求失败，系统恢复搜索前的已应用条件和列表；学生的草稿选择继续保留，可修改后再次搜索。

### 3.5 浏览与分页

学生通过卡片判断题目所属考试、科目、知识点、来源及历史错误程度。翻页时保持已应用条件；如果学生只修改筛选项但没有点击搜索，翻页仍沿用上一次成功搜索条件。

快速连续触发的请求只允许最后一次请求更新页面。较早请求即使更晚返回，也不得覆盖学生刚刚得到的新结果。

### 3.6 查看解析并返回

学生点击某张卡片的“查看解析”，进入该题最近一次错误答卷中的单题解析。来自诊断真题和来自试题库的题目都走同一个单题复习体验，不需要先经过总报告或整卷解析。

学生点击“返回错题本”后，回到进入解析前的筛选结果和页码。浏览器刷新解析页后，返回入口仍然有效；非法返回地址被忽略并回到错题本首页。

### 3.7 贯穿全程的历史规则

- 后续做对不会自动移出错题，也不会减少历史错误次数。
- 日期筛选不会截断卡片的历史统计。
- 试卷下线或归档后，已有历史错题继续保留。
- 题目内容更新后，历史是否被判错仍按当时提交结果保留；解析内容读取当前题目版本。
- 同一题干如果对应不同题目标识，仍展示为不同错题。

### 3.8 完整旅程验收路径

**标准成功闭环**：学生完成并提交一份含错题的 ESAT 答卷，进入错题本选择 ESAT、对应科目和父级知识点，搜索后看到该题及其后代知识点命中结果；点击查看解析只看到当前题，返回后筛选和页码保持不变。

**跨考试边界**：学生同时拥有 ESAT 和 TMUA 错题。未选择考试类型时能看到两类错题；选择 ESAT 后只能选择 ESAT 科目和知识点，结果中不出现 TMUA 错题；切换到 TMUA 时旧 ESAT 科目和知识点被清空。

**历史统计口径**：同一道题在六月和七月各错一次。筛选六月时该题进入结果，卡片仍显示“历史错 2 次”并包含两次历史错选；最近一次错误上下文显示七月记录。

**未交卷边界**：学生在练习中答错并保存进度，但没有正式交卷。进入错题本后该题不得出现；正式交卷后再进入，题目才被收录。

**失败后恢复**：学生已经看到一页错题，修改条件并搜索时网络失败。页面保留原列表，提示未能更新；再次加载成功后才替换列表并更新地址。首次进入即失败时只显示失败和重试，不显示空态。

**并发请求**：学生快速执行两次不同搜索，第二次请求先返回、第一次后返回。页面最终必须保持第二次搜索结果，第一次结果不得覆盖。

## 4. 异常容错

### 4.1 错题列表无法加载

首次加载失败时，用户看到“错题加载失败”、可理解的原因和“重新加载”。页面不生成空列表结论，也不改写任何历史数据。

已有列表后的刷新、搜索或翻页失败时，保留上一次成功结果和分页信息，并说明当前列表未更新。重试仍使用上一次已应用条件；尚未搜索的草稿条件不会偷偷生效。

### 4.2 考纲无法加载

考试类型选择成功但考纲加载失败时，科目和知识点保持不可选，页面显示重新选择考试类型后重试的提示。其他筛选项和错题列表继续可用，系统不得回退加载另一考试的考纲冒充当前数据。

### 4.3 空数据与筛选无结果

当前学生没有任何正式错题时显示“暂无错题”。学生已有错题但当前条件未命中时显示“暂无匹配错题”。重置后重新查询完整列表，不保留隐藏的科目或知识点条件。

### 4.4 历史数据缺失

来源缺失时显示“来源-未知”，不能默认归为真题。难度缺失时显示“难度-未标注”；科目缺失时显示“科目未标注”；知识点缺失不影响题目在未筛选列表中展示，但该题无法命中知识点筛选。

如果最近一次错误答卷记录缺失，“查看解析”不可用。单张异常题目不得导致整页错题无法加载。

### 4.5 题目下线、删除或内容变更

试卷下线或归档不删除历史错题。若题目或试卷被物理删除，页面尽量显示现有历史信息，并禁用无法完成的解析入口，不得导致其他错题一起失败。

后台修改正确答案、题干、选项或解析后，历史判题结果不重算，解析页展示当前题目内容。若当前答案与作答时答案可能产生矛盾，本期不伪造历史答案说明，留待答案快照能力解决。

### 4.6 重复操作与请求竞态

加载期间搜索和重置不可重复点击。对于已经发出的并发查询，只允许最后一次请求更新列表、分页和错误状态；过期请求不得覆盖更新后的结果。

解析页只接受错题本自身的返回地址。任何不以错题本路径开头的地址都回退到错题本首页，避免跳转到站外或错误业务页面。

## 5. 后续与非目标说明

### 5.1 本次不做

- 不提供“重做此题”、批量重做或按筛选结果组卷。
- 不提供未复习、复习中、已掌握等掌握状态。
- 不支持自动移出、手动移出、收藏、备注或导出。
- 不按题干内容指纹合并不同题目标识。
- 不保存完整题目、选项和解析快照。
- 不因后来做对而自动降低历史错误次数。
- 不新增错题按知识点分组的第二种列表视图。

### 5.2 当前临时方案

单题解析复用现有答题结果能力，但对错题本入口只展示目标题目。未来即使替换为独立单题页面，也必须保持直接定位当前题、返回原筛选位置和不展示整卷导航的用户体验。

服务端当前仍会读取符合条件的错误记录并完成聚合后分页。该方案可以保证历史次数、历史错选和最近错误记录口径一致，但用户积累大量错题后可能增加响应时间。性能优化不得改变本 PRD 已确认的去重、筛选和全历史统计规则。

### 5.3 后续迭代

**错题重做**：需要先确认重做产生哪类练习记录、重做正确后是否改变掌握状态、是否自动移出错题以及是否影响历史错误次数，再设计单题或批量入口。

**掌握度管理**：可增加未复习、复习中和已掌握状态，并允许学生手动移出或恢复。掌握度必须与历史错误事实分离，标记已掌握不能删除过去的错误记录。

**答案快照**：可保存作答当时的正确答案。当后台答案发生变更时，解析页同时说明作答时答案和当前答案，解决历史判题与当前解析不一致的问题。

**内容指纹去重**：可评估跨试卷的同题识别，但必须避免把题干相似、条件不同或解析版本不同的题目误合并。

**聚合性能优化**：可维护用户与题目维度的错题摘要，或采用先确定分页题目再查询历史明细的方式。替换前必须使用大数据量验证筛选响应时间，并回归全历史错误次数、历史错选和最近收录上下文。

### 5.4 待确认事项

- 重做正确达到多少次后可以建议“已掌握”，以及是否允许自动移出。
- 答案变更提示只保存正确答案快照，还是还需要保存题目版本信息。
- 后续排序是否增加错误次数、难度和知识点顺序，同时如何与当前“最近收录时间倒序”共存。
