# 错题本 PRD

## 一、文档目标

本文档用于定义错题本功能的产品范围、展示规则、筛选规则、去重规则、异常情况与后续演进方向。

错题本的核心定位是：**长期沉淀学生在练习、诊断测试、真题套卷中做错过的题目，帮助学生回看错误历史、定位薄弱知识点，并进入题目解析进行复习。**

---

## 二、功能背景

学生在平台中会从多个入口完成答题：

- 试题库在线练习
- 诊断测试
- 真题套卷练习
- 后续可能增加的自由组卷或专项训练

这些答题行为会产生历史答题记录。错题本需要从历史记录中提取学生做错过的题目，并以适合复习的方式统一展示。

错题本不是一次练习结果页，也不是试卷列表页。它关注的是学生长期累积的错误资产。

---

## 三、用户目标

学生进入错题本后，应能够完成以下目标：

- 查看自己历史上做错过的题目。
- 看到每道错题最近一次错误对应的提交时间、来源、难度和题目标题。
- 看到同一道题历史上错过几次。
- 看到自己历史上曾经选错过哪些答案。
- 按题目难度、题目来源、所属知识点、提交时间范围筛选错题。
- 点击错题进入题目解析页，查看题目、答案、解析和自己的作答情况。

## 四、本期功能范围

### 4.1 错题列表

错题本首页展示当前登录学生的错题列表。

每条错题至少展示：

- 最近一次错误提交日期
- 最近一次错误提交时间
- 最近一次做错耗时
- 题目难度
- 题目来源
- 错误次数
- 历史错误答案
- 题目标题
- 查看解析入口

其中题目标题使用题目数据中的 `title` 字段。

### 4.2 错题聚合

错题本不直接展示每一次错误作答记录，而是按题目聚合。

本期聚合规则：

- 同一个题目 ID 下的多次错误记录，合并为一条错题。
- 错误次数展示该题历史错误次数。
- 历史错误答案展示学生曾经选错过的答案集合。
- 列表排序以最近一次错误记录所属答题会话的提交时间为准。
- 点击查看解析时，进入最近一次错误记录对应的解析页面。

示例：

学生历史作答：

| 时间 | 正确答案 | 学生选择 | 结果 |
|---|---|---|---|
| 第一天 | A | B | 错误 |
| 第二天 | A | C | 错误 |

错题本展示：

- 错误次数：2 次
- 曾选：B、C
- 解析入口：指向最近一次错误记录

### 4.2.1 最近一次错误时间口径

错题本中的“最近一次错误时间”统一使用该错误记录所属答题会话的提交时间，即 `ExamRecord.submittedAt`。

不使用单题明细的 `AnswerRecord.answeredAt` 作为错题本排序、筛选和展示时间。

原因：

- 当前答题记录主要在整次考试或练习提交时统一生成，逐题 `answeredAt` 与真实单题作答时刻并不完全等价。
- 单题耗时统计逻辑仍可能调整，用逐题时间作为错题排序依据容易造成口径不稳定。
- 错题本关注的是“在哪一次提交中暴露了错误”，因此以整次答题提交时间作为统一口径更清晰。

### 4.3 最近一次做对后的保留规则

只要一道题历史上曾经做错过，该题就保留在错题本中。

即使学生后续再次练习并做对，该题仍然属于错题本内容。

产品原因：

- 错题本用于记录历史薄弱点，不应因为一次做对就自动消失。
- 后续可以增加“已掌握”“移出错题本”“再次练习正确 N 次后淡化”等掌握度机制。

本期不做自动移除。

### 4.4 筛选功能

错题本顶部支持筛选。

筛选项包括：

- 题目难度
- 题目来源
- 所属知识点
- 提交时间范围

筛选项选择后，需要点击“搜索”才应用筛选。

点击“重置”后：

- 清空所有筛选条件
- 恢复未筛选的错题列表

### 4.5 题目难度筛选

题目难度支持多选。

难度值来自题目数据中的难度字段。

本期展示文案：

| 字段值 | 展示文案 |
|---|---|
| easy | 难度-低 |
| medium | 难度-中 |
| hard | 难度-高 |
| composite | 难度-复合 |

难度缺失的题目展示为“难度-未标注”。

### 4.6 题目来源筛选

题目来源支持多选。

题目来源来自试卷类型。

本期展示文案：

| 字段值 | 展示文案 |
|---|---|
| past | 来源-真题 |
| practice | 来源-题库 |
| mock | 来源-模考 |

来源缺失或未知时展示为“来源-未知”。

### 4.7 所属知识点筛选

所属知识点使用与试题库左侧大纲一致的组织树。

用户通过树形下拉选择知识点。

筛选规则：

- 支持多选。
- 选择父级知识点时，应覆盖该父级下的子级知识点。
- 题目命中任意已选知识点，即出现在筛选结果中。

题目数据中可能存在多套知识点字段，产品规则上统一理解为“题目关联的知识点 code”。

### 4.8 提交时间范围筛选

提交时间范围使用日期范围选择器。

筛选语义：

**筛选该时间范围内提交的答题会话中发生过错误的题目。**

示例：

- 某题 6 月做错。
- 7 月再次练习并做对。
- 当用户筛选 6 月提交时间范围时，该题仍然展示。

原因：

- 错题本关注历史错误行为。
- 时间筛选用于回看某个提交时间段内暴露的问题，而不是判断当前是否仍然错误。

### 4.9 分页

错题本列表支持后端分页。

分页规则：

- 首次进入页面默认展示第 1 页。
- 点击搜索后，按当前筛选条件重新查询，并回到第 1 页。
- 点击分页器切换页码时，保留当前已应用筛选条件。
- 切换每页数量时，保留当前已应用筛选条件，并回到第 1 页。
- 点击重置时清空筛选条件，保留当前每页数量，并回到第 1 页。

筛选项区分“草稿条件”和“已应用条件”：

- 用户修改筛选项但未点击搜索时，列表数据不变化。
- 此时点击分页器，应继续使用上一次已应用筛选条件查询。
- 只有点击搜索后，新的筛选项才生效。

## 五、查看解析流程

错题卡片右侧提供“查看解析”入口。

点击后进入题目解析页。

解析页应尽量定位到当前错题对应的题目。

本期规则：

- 如果该错题有最近一次错误记录，则进入该错误记录所在的答题报告。
- 通过题目 ID 定位具体题目。
- 如果缺少必要记录，则入口置灰或不允许进入。

后续可优化为独立的“单题解析页”，减少对某一次答题报告的依赖。

## 六、功能边界

### 6.1 本期包含

- 错题列表展示。
- 错题按题目 ID 聚合。
- 错误次数统计。
- 历史错误答案展示。
- 难度筛选。
- 来源筛选。
- 知识点树筛选。
- 提交时间范围筛选。
- 后端分页。
- 查看解析入口。

### 6.2 本期不包含

- 错题自动移出。
- 错题掌握状态。
- 错题重做入口。
- 错题导出。
- 错题收藏。
- 错题备注。
- 错题按知识点分组视图。
- 独立单题解析页。
- 完整题目快照。
- 答案快照字段落库。

## 七、异常情况与产品规则

### 7.1 同一道题出现多个题目 ID

可能出现同一道题被导入到不同试卷中，形成多个不同的题目 ID。

例如：

- 一次作为题库练习题导入。
- 一次作为真题套卷题导入。
- 两条题目记录题干完全一致，但题目 ID 不同。

本期规则：

- 只按题目 ID 聚合。
- 不同题目 ID 即使题干相同，也会显示为不同错题。

原因：

- 不同题目 ID 可能来自不同试卷、不同来源、不同解析版本,根据不同来源可做区分。
- 仅凭题干相同无法完全判断是否应合并。

### 7.2 试卷被下线

如果后台将试卷下线，但未删除试卷和题目数据：

- 错题本仍然展示该题。
- 该题仍可作为学生历史错题资产保留。

原因：

- 试卷下线只表示不再对新练习开放。
- 不应影响学生已经产生的历史学习记录。

### 7.3 试卷或题目被删除

如果后台物理删除试卷或题目，可能导致错题本无法完整展示该题。

可能表现：

- 题目标题缺失。
- 难度缺失。
- 知识点缺失。
- 解析页无法渲染完整题目。
- 查看解析入口不可用或跳转后缺少内容。

产品建议：

- 已产生答题记录的试卷和题目，不建议直接物理删除。
- 优先使用下线、隐藏、归档等软处理方式。
- 如必须删除，应接受对应历史错题无法完整追溯的结果。

### 7.4 正确答案被修改

如果后台修改了某道题的正确答案：

- 错题本是否展示，仍以历史作答结果为准。
- 题目内容、选项、解析会读取当前题目最新内容。
- 历史作答时的正确答案如果没有快照，可能无法还原。

可能出现的问题：

- 学生当时被判错。
- 后台后来修改正确答案。
- 解析页显示当前答案后，学生可能觉得历史判题结果与当前答案矛盾。

讨论结论：

- 本期暂不做完整题目快照。
- 后续可增加“答案快照”，只保留作答当时的正确答案。

建议后续规则：

- 作答时保存当时正确答案。
- 如果当前正确答案与作答时答案不同，在解析页提示：
  - 作答时答案
  - 当前答案
- 不保存完整题干、选项、解析快照。

这样可以解决答案变更导致的历史判题矛盾，同时避免引入完整题目版本系统。

### 7.5 题目内容发生大幅修改

如果题干、选项、解析发生大幅修改：

- 本期不追踪完整题目版本。
- 历史错题仍会指向当前题目内容。

产品建议：

- 如果题目只是修正答案，可通过答案快照解决。
- 如果题目内容大幅变化，应考虑新建题目或下线旧题。
- 不建议在原题上进行破坏性大改。

### 7.6 未作答也被判错

如果学生提交时某题未作答：

- 该题可计入错题。
- 历史错误答案可为空。
- 页面可只展示错误次数，不展示“曾选”。


### 7.7 题目来源缺失

如果题目来源缺失：

- 展示为“来源-未知”。
- 仍可保留在错题本中。

### 7.8 难度缺失

如果题目难度缺失：

- 展示为“难度-未标注”。
- 不影响错题展示。

### 7.9 知识点缺失

如果题目没有知识点：

- 不影响错题展示。
- 但按知识点筛选时，该题无法命中任何知识点筛选。

## 八、后续演进建议

### 8.1 排序

后续可支持以下排序：

- 最近错误提交时间
- 错误次数
- 难度
- 知识点顺序

本期默认按最近错误提交时间倒序。

### 8.2 掌握状态

后续可增加错题掌握状态：

- 未复习
- 复习中
- 已掌握

也可支持用户手动移出错题本。

### 8.3 错题重做

后续可支持从错题本直接进入错题重做。

重做模式可包括：

- 单题重做
- 选中多题重做
- 按筛选结果批量重做
- 按知识点重做

### 8.4 内容指纹去重

为解决同题多 ID 的问题，后续可引入题目内容指纹。

建议谨慎设计，避免误合并相似但不相同的题。

### 8.5 答案快照

后续可增加答案快照能力。

目标：

- 还原作答当时的正确答案。
- 避免后台修改答案后，历史错题解释出现矛盾。

不建议本阶段保存完整题目快照。

### 8.6 单题解析页

当前查看解析依赖历史答题报告。

后续可增加独立单题解析页：

- 直接通过题目进入解析。
- 展示该题历史错误次数。
- 展示历史错误答案。
- 展示最近一次作答记录。
- 展示当前答案与作答时答案差异。

## 九、验收标准

### 9.1 列表展示

- 用户进入错题本后，可以看到历史错题。
- 同一题目 ID 的多次错误只展示一条。
- 错题卡片展示错误次数。
- 错题卡片展示历史错误答案。
- 未作答错题不展示空的“曾选”标签。

### 9.2 筛选

- 可按难度筛选。
- 可按来源筛选。
- 可按知识点筛选。
- 可按提交时间范围筛选。
- 多个筛选条件同时存在时，结果取交集。
- 点击重置后恢复完整错题列表。

### 9.3 查看解析

- 有历史错误记录的错题可以进入解析。
- 解析页能定位到对应题目。
- 缺少必要数据时，不应出现页面崩溃。

### 9.4 异常场景

- 题目难度缺失时，显示“难度-未标注”。
- 题目来源缺失时，显示“来源-未知”。
- 题目知识点缺失时，仍可展示在未筛选列表中。
- 试卷下线后，历史错题仍保留。
- 题目或试卷删除后，系统应尽量兜底展示，不应导致错题本整体不可用。

---

## 十、当前决策摘要

- 错题本是长期学习资产，不因最近一次做对而自动移除。
- 本期按题目 ID 聚合，不按题干内容聚合。
- 本期支持历史错误答案集合展示。
- 本期支持错误次数展示。
- 本期时间筛选语义是“该提交时间段内发生过错误”。
- 本期不保存完整题目快照。
- 后续优先考虑答案快照，而不是完整题目版本系统。
- 已作答题目不建议物理删除，优先下线或归档。
