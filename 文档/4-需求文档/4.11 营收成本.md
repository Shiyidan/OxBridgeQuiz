# 4.11 营收成本

> 文档对象：产品经理、测试人员与运营管理员
>
> 文档性质：后台营收成本记录的功能边界、操作规则与测试验收依据
>
> 文档日期：2026-07-18

本文描述管理员在“营收与数据”页面维护公司成本记录的完整产品行为，包括成本分类、成本项、金额、经办信息、报销状态、备注和操作审计。

---

## 1. 功能边界与目的

### 1.1 功能目标

管理员可以把服务器、数据库、研发工具和运营推广等公司花销录入统一成本列表，并通过“成本分类 + 成本项”识别支出用途，避免将具体工具名称与成本类型混为一类。

### 1.2 角色与权限边界

| 角色 | 可见范围 | 可执行操作 |
|---|---|---|
| 未登录访客 | 不可查看后台营收成本页面和数据 | 无 |
| 普通学生及会员 | 不可查看后台营收成本页面和数据 | 无 |
| 管理员 | 可以查看全部成本记录和字段 | 新增成本、编辑成本 |

后台入口和数据接口都必须校验管理员身份。仅隐藏前端菜单不视为完成权限控制。

### 1.3 功能范围

营收成本功能包含：

1. 管理员查看、新增和编辑成本记录。
2. 成本分类固定为“技术基础设施服务、研发工具、运营推广”。
3. 成本项根据所选分类联动展示。
4. 新增和编辑成本时校验分类与成本项的对应关系。
5. 成本列表同时展示成本分类和成本项。
6. 研发工具分类使用 `deepseek`、`claude`、`codex` 三个具体成本项。
7. 新增和编辑动作进入操作日志，编辑时可查看成本分类等字段的前后变化。

### 1.4 分类与成本项定义

| 成本分类 | 可选成本项 | 适用示例 |
|---|---|---|
| 技术基础设施服务 | 服务器租赁、数据库租赁、域名及证书、第三方技术服务 | ECS、RDS、域名、SSL、OSS、CDN、邮件服务 |
| 研发工具 | `deepseek`、`claude`、`codex` | 对应研发过程中使用的三种具体工具 |
| 运营推广 | 市场推广、内容运营、行政及财税 | 广告投放、内容制作、代理记账和行政支出 |

成本项表示支出用途，具体品牌、服务商、月份和用途填写在备注中。

### 1.5 状态与数据来源

- 成本记录来源于后台管理员手动新增或编辑。
- 列表数据以已保存的成本记录为准，默认按业务发生时间倒序显示。
- 报销情况包含“未报销、报销中、已报销、不可报销”四种状态。
- `deepseek`、`claude`、`codex` 统一归入“研发工具”，并以具体工具名称作为成本项。

### 1.6 功能验收前提

- 管理员账号能够进入“营收与数据”页面。
- 成本列表、新增和编辑接口能够正常读写成本记录。
- 系统已经配置成本分类、成本项、操作人和报销状态选项。

## 2. 页面描述

### 2.1 页面入口

管理员从后台菜单进入“营收与数据”页面。进入页面后自动读取第一页成本记录；普通用户访问对应地址时应被权限控制拦截。

### 2.2 成本列表

每条成本记录展示：

| 字段 | 展示规则 |
|---|---|
| 序号 | 按当前分页位置连续计算 |
| 成本分类 | 显示三类成本的中文名称 |
| 成本项 | 显示当前分类下的中文成本项 |
| 金额 | 使用人民币符号并保留两位小数 |
| 时间 | 按日期展示业务发生时间 |
| 操作人 | 显示录入或经办人员 |
| 报销情况 | 显示现有四种中文状态 |
| 备注 | 超出单元格宽度时可查看完整内容 |
| 操作 | 支持编辑当前记录 |

列表为空时显示“暂无成本记录”，不显示错误数据或占位记录。列表使用统一分页组件。

### 2.3 新增与编辑表单

表单包含：

1. 成本分类。
2. 成本项。
3. 金额。
4. 操作人。
5. 时间。
6. 报销情况。
7. 备注。

新增时默认选中“技术基础设施服务”，成本项保持未选择，由管理员明确选择。编辑时回填该记录当前分类、成本项和其他字段。

### 2.4 分类与成本项联动

- 选择“技术基础设施服务”时，只显示服务器租赁、数据库租赁、域名及证书、第三方技术服务。
- 选择“研发工具”时，只显示 `deepseek`、`claude`、`codex`。
- 选择“运营推广”时，只显示市场推广、内容运营、行政及财税。
- 管理员切换成本分类后，已经选择的成本项必须清空，防止旧成本项错误归入新分类。

### 2.5 权限与可见性

所有成本字段只在管理后台展示。新增和编辑按钮只对管理员开放，普通用户不提供只读入口。

## 3. 核心流程

### 3.1 查看成本列表

```text
管理员进入营收与数据页面
  → 系统校验管理员身份
  → 读取当前页成本记录
  → 按业务发生时间倒序展示
  → 管理员可以翻页或编辑记录
```

列表读取失败时保留页面结构，显示失败提示，不把上一次成功读取的数据冒充为当前结果。

### 3.2 新增成本

```text
点击“成本导入”
  → 打开空白表单
  → 选择成本分类
  → 从该分类允许的成本项中选择一项
  → 填写金额、操作人、日期、报销情况和可选备注
  → 提交并执行前后端校验
  → 保存成功后关闭弹窗、返回第一页并刷新列表
```

保存成功后显示“成本导入成功”。新增记录产生一条“新增成本记录”操作日志。

### 3.3 编辑成本

```text
点击记录“编辑”
  → 回填当前成本数据
  → 管理员修改分类、成本项或其他字段
  → 如果切换分类则清空原成本项
  → 提交并执行前后端校验
  → 保存成功后关闭弹窗并刷新当前列表
```

保存成功后显示“成本记录更新成功”。编辑操作记录纳入审计范围的字段前后值，包括成本分类、成本项、金额、操作人、业务日期、报销状态和备注。

### 3.4 研发工具记录规则

- `deepseek`、`claude`、`codex` 都属于“研发工具”。
- 列表直接显示具体工具名称，不合并为通用研发工具名称。
- 编辑研发工具记录时，表单回填“研发工具”和对应的具体成本项。
- 除上述三个选项外，研发工具分类不接受其他成本项。

### 3.5 校验规则

| 字段 | 校验规则 |
|---|---|
| 成本分类 | 必选，并且只能是当前三类之一 |
| 成本项 | 必选，并且必须属于所选分类 |
| 金额 | 必填且不得小于 0，页面按两位小数录入和展示 |
| 操作人 | 必选 |
| 时间 | 必选且必须是有效日期 |
| 报销情况 | 必选，只能选择四种已定义状态之一 |
| 备注 | 可空，最多 500 个字符 |

前端联动不能代替后端校验。即使直接构造请求提交错误的“分类—成本项”组合，系统也必须拒绝保存。

### 3.6 核心验收点

1. 管理员可以看到三种成本分类，名称与本文一致。
2. 每种分类只显示对应的成本项。
3. 切换分类后旧成本项被清空，未重新选择时不能提交。
4. 新增服务器租赁和数据库租赁成本后，列表分类显示为“技术基础设施服务”。
5. 后端拒绝不属于所选分类的成本项组合，数据库不产生错误记录。
6. 编辑成本分类后，列表立即显示新分类，并在操作日志中看到分类前后值。
7. `deepseek`、`claude`、`codex` 记录显示并回填对应的具体成本项。
8. 报销情况包含“不可报销”，保存后列表显示相同文案。

## 4. 异常容错

### 4.1 输入异常

- 未选择成本分类或成本项时，表单阻止提交并提示对应字段必填。
- 金额为空、不是有效数字或小于 0 时，系统拒绝保存。
- 日期无效、操作人为空、报销状态为空或备注超过长度限制时，系统拒绝保存。
- 分类存在但成本项不属于该分类时，后端返回可识别的校验失败信息。

### 4.2 数据与接口异常

- 列表加载失败时显示“成本数据加载失败”，列表回到空态，管理员可以重新进入页面重试。
- 新增失败时保留弹窗和已填写内容，显示“成本记录新增失败”或服务端具体错误。
- 编辑失败时不关闭弹窗、不覆盖列表中的原记录，管理员可以修改后重试。
- 编辑的记录已不存在时，系统提示记录不存在，不创建替代记录。

### 4.3 重复提交与状态恢复

- 保存期间按钮进入加载状态，避免管理员连续点击产生重复请求。
- 保存成功后才关闭弹窗并刷新列表。
- 保存失败时恢复按钮可用状态，不把失败操作显示为成功。

### 4.4 权限异常

- 未登录或登录过期时，按全站认证规则返回登录页面。
- 普通用户调用成本接口时返回无权限，不得返回成本列表或记录详情。
- 管理员身份在操作期间失效时，保存失败且不落库。

### 4.5 异常验收点

1. 直接提交错误分类与成本项组合时，接口拒绝且数据库无新增记录。
2. 快速连续点击保存时，页面不会出现多条重复成功提示。
3. 新增或编辑接口失败后，弹窗内容仍可继续修改并重试。
4. 普通用户不能通过直接访问地址或调用接口读取成本数据。
5. 接口返回未定义成本项时，编辑保存前必须重新选择有效成本项。

## 5. 后续与非目标说明

### 5.1 功能范围

- 三类成本分类及其固定成本项。
- 新增和编辑表单的分类联动。
- 列表中的分类与成本项中文展示。
- 分类与成本项的前后端双重校验。
- 研发工具具体成本项的展示和编辑。
- 成本字段修改的操作审计。
- 报销状态、分页和备注能力。

### 5.2 非目标

- 不提供供应商、计费周期、使用环境、发票编号等结构化字段。
- 不提供成本分类筛选、搜索和排序功能。
- 不提供按月成本、分类占比或环比统计看板。
- 不提供批量导入、删除、附件上传或审批流程。
- 不管理工资、社保等独立人员成本。
- 不从云服务商、支付服务商或账单文件自动同步费用。

### 5.3 后续建议

当成本记录规模和运营分析需求明确后，可评估分类筛选、月份汇总、成本占比、账单附件和供应商维度。后续扩展应复用文档定义的三类成本分类，不改变已有记录语义。
