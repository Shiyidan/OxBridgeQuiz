# 4.14 试题库

> 本文档聚焦学生在试题库中的浏览、选题、专项练习、恢复、交卷和历史查看。后台管理只作为题目是否可用及内容状态变化的前置条件，不展开试题导入、审核和批次管理流程。

## 1. 功能边界与目的

### 1.1 功能目的

试题库帮助学生围绕当前考试的具体考点进行短时专项练习。学生不需要先选择一整张试卷，只需在考纲中定位知识范围、选择简单、中等或困难，即可生成一组最多 5 题的临时练习，并沿用统一答题页完成保存、恢复、交卷和解析。

试题库同时承接两种后续学习需求：学生可以在“练习记录”中回看过去完成的一次性专项练习，也可以进入“练习本”保存一套可重复使用的组卷规则。练习记录回答“我过去临时练过什么”，练习本回答“我以后想按什么规则继续练”，两类数据必须清楚区分。

### 1.2 本次范围

本次覆盖以下学生端闭环：

- 按顶部导航当前选择的 ESAT 或 TMUA 浏览对应考纲；
- 选择考点并查看当前范围内简单、中等、困难三档可用题量；
- 从难度卡片确认题库总量和本次练习题量；
- 在登录、进行中练习和会员额度校验通过后开始专项练习；
- 在统一答题页作答、保存、离开、恢复和正式交卷；
- 交卷后查看逐题解析，并同步更新练习记录、已练习题量和错题本；
- 从试题库进入练习记录或练习本，并保持当前考试类型；
- 在题目发布、归档或内容变化后，正确处理新练习、进行中练习和历史记录。

本次不描述后台导入页面、试题包列表、逐题审核和删除操作。后台只需要保证题目经过审核后才能发布，已发布题目可以进入学生端，草稿或归档题目不能进入新的学生练习。

### 1.3 核心业务概念

**当前考点范围**由顶部当前考试和学生在考纲中选择的节点共同决定。选择父级节点时，当前范围包含该节点及全部后代。页面显示的标题、题量和随后生成的练习都必须来自同一范围。

**临时专项练习**是学生从试题库某张难度卡片开始的一次练习。它不属于任何练习本，交卷后进入练习记录，并在练习册中归入“临时练习”系统分组。

**计划题量与实际题量**用于解释为什么页面看到的题库总量、预计练习题量和最终答卷题量可能不同。专项练习计划最多 5 题；当前范围不足 5 题时，实际题量等于全部可用题量；免费剩余额度不足时，经过学生再次确认后，实际题量可以缩减为剩余额度。练习记录必须同时保留原计划题量和实际题量。

**练习快照**保存本次练习开始时的考试、来源、学科、知识点名称与完整路径、难度、计划题量和实际题量。后续考纲改名、层级调整或题目归档不能改写已经开始或已经交卷记录的练习范围。

**进行中练习**是已经生成题目但尚未正式交卷的记录。同一学生在试题库专项练习、自由组卷和练习本入口中最多只能有一份进行中练习。再次进入时只能继续原记录，不能生成第二组题。

**正式交卷**是练习进入历史并产生学习统计的唯一节点。保存答案、关闭页面或继续练习不会提前增加已练习题量，也不会提前写入错题本。

### 1.4 角色与权限边界

- 游客可以浏览当前考试的考纲和已发布题量，点击“立即练习”后进入登录流程；登录成功后返回试题库重新确认练习。
- 已登录学生只能创建、继续和查看自己的练习及历史，不能通过地址参数读取其他学生的数据。
- 免费用户和会员使用相同题目与答题流程，区别只在新练习可使用的题量；会员到期不删除已开始练习和历史记录。
- 管理员负责让题目进入已发布或已归档状态。学生端只使用状态结果，不提供后台管理入口。

### 1.5 关键业务约束

- 题目只使用简单、中等、困难三档难度。`composite` 不作为学生可见难度，历史数据已统一归入困难。
- 只有已发布题目进入学生端题量统计和新练习。草稿与已归档题目不进入新选题。
- 专项练习每次最多 5 题。当前范围不足 5 题时使用全部可用题目；题量为 0 时不可开始。
- 当前范围多于 5 题时，页面同时说明题库总量和本次练习题量，不能把两者混为同一数字。
- 免费用户的专项练习、自由组卷和练习本在同一考试类型下共用免费题量。开始练习前显示当前可用题量，正式创建时再次确认资格。
- 免费剩余额度小于计划题量但大于 0 时，页面必须再次说明实际可练题量。取消不创建记录；确认后按剩余额度生成，并在历史中保留计划与实际题量。
- 剩余额度为 0 时禁止开始新练习并提供开通会员入口。另一考试的额度不受影响。
- 题目集合、顺序和练习快照在开始成功时固定。刷新、重新进入、切换考试或题目后来归档都不能重新抽题。
- 当前专项练习采用“随机起点加连续题目”的选题方式，保证单次不重复，但暂不承诺完全无放回随机或未做题优先。
- 只有正式交卷才更新练习记录、已练习题量和错题本。未作答题在交卷时按未作答保留，并按错题本规则收录。

## 2. 页面描述

### 2.1 试题库首页

页面从上到下依次展示全局导航、标题与快捷入口、考纲区域和难度练习区域。

标题区左侧展示“试题库”及用途说明。右侧先展示当前考试的已练习题量，再依次展示下划线形式的“练习记录”和按钮形式的“练习本”。练习记录位于练习本之前，帮助学生区分一次性历史和可重复规则。

页面主体左侧为“考点大纲”，内容跟随顶部当前考试。默认展开主要层级并选中一个有效节点。节点名称较长时必须允许学生查看完整名称，不能只以省略号隐藏关键信息；较长考纲可以继续向下滚动。

右侧先展示当前考点标题，以及“当前范围共 n 题，每次随机练习最多 5 题”。其下固定展示简单、中等、困难三张卡片。每张卡片展示中英文难度、当前范围题量、适用说明和操作按钮。题量为 0 时按钮显示“暂无题目”并禁用；题量大于 0 时显示“立即练习”。

如果存在未交卷练习，右侧在难度卡片上方显示当前考试、已答题量和“继续练习”。此时三张难度卡的开始操作同时禁用，避免创建第二份记录。

切换顶部考试或考纲节点时，页面先清空旧范围的题量和可点击状态，再加载新范围。只有最新选择的考试和节点可以更新标题、总题量和三张卡片；较早请求晚到时不得覆盖当前页面。

首次加载时显示明确加载反馈。考纲加载失败时不保留上一考试的考纲；题量加载失败时保留当前考点名称，但总题量和三档题量不可继续显示旧值，所有开始按钮保持不可用。只有请求成功且确实没有考纲或已发布题目时才展示真实空状态。

### 2.2 开始练习确认

学生点击有题目的难度卡后，页面打开“确认开始练习”弹窗。弹窗同时说明当前考点、题库总量和本次预计题量。例如当前范围有 7 道困难题时，应说明“题库共 7 题，本次随机练习 5 题”；只有 3 题时，应说明本次练习全部 3 题。

点击取消、关闭弹窗或按 Esc 只取消本次待开始操作，页面继续保留当前考试、考点、难度和题量。

游客确认开始时进入登录流程。登录成功后返回原考试和考点，由学生重新确认，登录前不得提前创建练习。

学生点击确认后，页面检查是否存在进行中练习和当前额度。存在进行中练习时不创建新记录，而是提示继续原练习。免费剩余额度不足但大于 0 时，再显示“免费练习题量不足”弹窗，明确实际可练题数；取消仍停留原范围，确认后按剩余额度开始。额度为 0 时提示开通会员并停留试题库。

开始请求处理中禁用重复确认。开始成功后直接进入答题页；失败时保留当前考试、考点和难度，并提供重新选择或重试入口，不能留下无题目答卷或错误占用额度。

### 2.3 答题页与完成弹窗

开始成功后进入统一答题页。页面显示当前题号与总题量、题目导航、题干、选项、上一题、下一题、计时和提交操作。文字、公式、根号、上下标和题目图片按照原数学语义展示，不能向学生暴露未渲染的公式源文本。

学生选择答案、改答或切题时保存当前进度。刷新、关闭页面、浏览器返回或从其他页面再次进入时，恢复同一组题、顺序、已保存答案、当前进度和用时。保存失败时保留页面当前选择并显示重试，返回或跳转不能无提示丢失最新更改。

学生点击提交时，页面说明未答题数量并进行二次确认。确认后答案和导航进入锁定状态，提交过程中不能继续改答或重复提交。提交失败时保留当前练习并允许重试；提交成功后旧页面不再接受进度修改。

正式交卷后页面展示不可忽略的完成弹窗，提供“返回试题库”“前往练习记录”和“查看解析”。查看解析进入本次全部题目的逐题详情；从完成弹窗进入解析后返回试题库，从练习记录进入解析后返回练习记录。

### 2.4 练习记录页

页面顶部展示“练习记录”、用途说明和“返回试题库”。记录范围始终跟随顶部当前考试，只展示当前学生未归属练习本的试题库练习。

如果存在进行中的临时练习，列表上方展示“进行中”、考试类型、已答题量、开始时间和“继续练习”。普通练习本的进行中任务不在此处重复展示。

已完成记录按交卷时间倒序展示。每条记录包含：

- 练习内容：交卷时的知识点名称，考试类型和父级路径作为辅助信息；
- 练习设置：试题库来源、难度、实际题量，额度缩量时同时展示原计划题量；
- 练习结果：正确数、总题量、正确率、学习提示、实际用时和交卷时间；
- 操作：“查看解析”。

正确率对应“掌握良好、继续巩固、建议复习”中的一个学习提示。记录按交卷时间倒序分页，可切换每页 5、10 或 20 条。查看解析后返回时继续停留在练习记录模块和当前考试。

首次加载显示“正在加载练习记录”；失败时显示明确原因和“重新加载”，不得展示空态。确认无记录时显示“暂无临时练习记录”和“前往试题库”。历史记录缺少必要快照时属于数据异常，页面应提示无法加载该记录并保留其他正常记录，不能临时拼接一个看似正常的标题。

### 2.5 练习本与错题本衔接

试题库首页的“练习本”进入同一考试下的练习册首页。学生可以创建、编辑或继续练习本；由练习本开始的练习复用同一答题、额度、交卷和解析流程，但历史归属对应练习本，不进入独立练习记录列表。

试题库练习中答错和未作答的题只有在正式交卷后进入错题本。错题按题目长期聚合；保存进度、关闭页面或提交失败均不得提前新增错题。

## 3. 核心流程

主旅程为：进入试题库并确认当前考试 → 选择考点 → 查看三档题量 → 确认题库总量与本次题量 → 校验登录、进行中练习和额度 → 生成固定练习 → 答题并保存 → 正式交卷 → 查看解析、练习记录和错题。

### 3.1 内容可用前提

后台完成题目审核并发布后，题目才进入对应考试、考点和难度的学生端题量。草稿或归档题目不可用于新的学生练习。后台发布失败时，学生端题量不得提前增加；归档只影响后续选题，不删除进行中练习和历史结果。

### 3.2 选择考试、考点与难度

学生进入试题库后先确认顶部当前考试，再从考纲选择目标节点。页面加载该节点及全部后代中的已发布题目，并同步刷新标题、总题量和三张难度卡。

学生根据卡片题量选择一个难度。题量为 0 的卡片不可点击；有题目的卡片先进入确认弹窗。当前范围超过 5 题时，弹窗明确区分题库总量与本次 5 题；不足 5 题时说明将使用全部题目。取消后仍停留当前范围。

### 3.3 校验资格并生成练习

游客确认开始后先完成登录，再返回原考试和考点重新确认。已登录学生确认后，系统先检查是否已有进行中练习；如果存在，学生只能继续该记录。

没有进行中练习时，再按当前考试检查会员和免费题量。有效会员可按本次计划题量开始。免费额度足够时，实际题量等于计划题量；额度不足但大于 0 时，学生必须再次确认实际题量；额度为 0 时不能开始。

资格确认、选定题目和创建进行中练习必须形成一个完整结果。成功后题目身份、顺序和练习快照立即固定。快速重复点击或多个页面同时确认时，最终最多只能产生一份可继续练习，不能出现已占用资格却没有可恢复记录的情况。

### 3.4 答题、保存与恢复

学生进入答题页后逐题选择或修改答案。保存只更新当前答卷，不改变题目集合和练习范围。页面刷新、关闭或返回试题库后，首页与练习记录页都能识别同一份进行中练习，并显示“继续练习”。

学生继续后恢复相同题目、顺序、答案、已答题量和用时。后台此时归档题目不影响本场完成；新的学生练习不再抽取已归档题目。

### 3.5 正式交卷与学习结果

学生确认提交后，答案被锁定并完成判分。提交成功时，进行中占用释放，本次练习进入练习记录，当前考试的已练习题量按实际题量增加，错误和未作答题进入错题本。

重复点击、网络重试或客户端没有收到成功响应时，最终仍只能形成一次交卷、一次题量统计、一条练习记录和一组错题事件。交卷成功后，旧页面的迟到保存不能覆盖最终答案。

学生可以从完成弹窗立即查看解析，也可以返回试题库或前往练习记录。练习记录使用开始时的快照展示练习范围，题目或考纲后续变化不能改写历史标题、路径、难度、计划与实际题量。

### 3.6 贯穿全程的共同规则

- 当前考试决定考纲、题量、额度、进行中练习和历史范围，ESAT 与 TMUA 不得混用。
- 所有开始入口共用唯一进行中练习限制；继续原记录不重新消耗开始资格或重新抽题。
- 页面上的题量提示用于帮助学生判断，最终实际题量以开始成功时冻结的结果为准。
- 进行中状态不更新已完成统计和错题；正式交卷是唯一统计节点。
- 会员到期、题目归档和考纲变化只限制新的开始，不删除已开始练习和历史记录。

### 3.7 完整旅程验收路径

- **标准闭环**：学生选择当前考试某个有 7 道困难题的考点，确认题库共 7 题、本次 5 题，完成并交卷后，练习记录新增一条 5 题记录，已练习题量增加 5，错误和未作答题进入错题本。
- **不足五题**：某考点中等题只有 3 道，页面和确认弹窗均说明本次 3 题，最终答卷、快照、练习记录和题量统计均使用 3。
- **额度缩量**：免费用户计划 5 题但只剩 2 题，取消第二次确认不创建记录；确认后生成 2 题，历史同时展示计划 5 题和实际 2 题，交卷后已用题量增加 2。
- **进行中恢复**：学生作答两题后关闭页面，再次进入试题库看到“继续练习”，恢复相同题目、答案、顺序和已答数量，其他难度卡不能开始第二份练习。
- **考试隔离**：学生从 ESAT 切换到 TMUA 后，考纲、题量、额度、进行中提示和练习记录全部切换为 TMUA，ESAT 数据保持不变。
- **内容归档**：管理员归档一组题目后，新练习不再抽到这些题；已有进行中练习仍可完成，历史记录、解析和错题继续可访问。
- **失败恢复**：考纲或题量加载失败时显示失败与重试；开始过程中范围变化时不产生半成品，返回原考点重新选择后可以正常开始。

## 4. 异常容错

### 4.1 考纲或题量无法加载

考纲加载失败时清空考纲、当前节点和三档题量，显示失败原因与重试入口，不能继续显示上一考试内容。题量加载失败时保留当前考点名称，但清空旧总量和三档题量，所有开始按钮不可用。重试成功后恢复当前考试和考点。

网络失败、无权限和真实无题必须使用不同反馈。只有成功加载且没有已发布题目时，才能显示“暂无题目”。

### 4.2 无法开始练习

存在进行中练习时提示继续原记录；额度为 0 时提示开通会员；额度部分不足时保留当前范围，等待学生确认缩量。确认期间题目归档、范围变化或资格失效时，提示返回试题库重新选择。

任何开始失败都不得消耗额度、创建历史、占用第二个进行中位置或留下无题目答卷。快速重复点击和多页面并发最终最多产生一份练习。

### 4.3 保存、离开或恢复失败

进度保存失败时保留当前页面答案并提示重试。学生点击返回或触发页面跳转时先保存最新更改；保存未成功前不能无提示离开。

恢复失败时页面说明无法恢复原练习并提供重试或返回试题库，不得自动创建另一组题。重试成功后继续原题目和已保存进度。

### 4.4 交卷或结果读取失败

交卷失败时答卷保持进行中，解除提交中的锁定后允许重试。服务端已经成功而页面未收到结果时，重试返回同一完成结果，不重复增加已练习题量、练习记录或错题。

解析读取失败不改变已交卷状态，页面提供重新加载以及返回试题库或练习记录。旧页面在交卷成功后再次保存必须被拒绝并刷新为最终结果。

### 4.5 练习记录异常

首次加载失败显示失败原因和“重新加载”，不能伪装成“暂无记录”。已有列表后的翻页失败时保留上一页数据、页码和分页器，并提示当前结果未更新。

单条历史缺少必要快照时，该条显示可理解的数据异常并不可进入错误解析；其他正常记录继续展示。系统不得用当前考纲临时拼装历史标题，也不能因单条异常导致整页白屏。

### 4.6 内容或权限变化

题目归档只影响未来选题，进行中练习和已完成历史保持。后台修改题目内容后，既有判题结果不得重新计算；当前尚未保存完整题目版本快照时，历史解析可能显示当前内容，页面不得伪造“作答时版本”。

会员到期只限制新的开始。已开始练习可以继续保存和交卷，历史、解析和错题继续可见。不同考试的会员和免费题量互不影响。

## 5. 后续与非目标说明

### 5.1 本次不做

- 不在学生端逐题浏览整个题库，学生必须从考点和难度开始专项练习；
- 不允许学生自定义 1 至 5 题，题量由可用题目、最多 5 题和剩余额度共同确定；
- 不在一次专项练习中混合考试类型、多个考点范围或多个难度；
- 不允许学生指定或替换某一道题；
- 不提供临时练习记录的编辑、改名或删除；
- 不新增第二套答题页、解析页、会员额度或错题统计口径；
- 不在本文描述后台导入、审核、试题包管理和物理删除流程。

### 5.2 当前实现待对齐

当前专项练习使用“随机起点加连续题目”的方式选取最多 5 题，具备随机起点和单次不重复，但还没有实现从全部候选题中完全无放回随机，也没有优先选择当前学生未做过的题。页面和其他需求不得把“未做题优先”描述为当前能力。

开始练习必须形成完整的考试、学科、知识点路径、难度、计划题量和实际题量快照。正常页面已经从考纲节点进入，异常请求仍需保证不会产生缺少范围的新记录。

练习记录遇到异常快照时应显示明确错误并保留其他正常记录。本期不兼容、不拼接旧格式，但不能让异常数据造成整页无提示白屏。

### 5.3 后续迭代方向

**未做题优先与完整随机**：后续可以优先从未做题中无放回随机；未做题不足时，再用距离上次作答最久的旧题补足。该优化不能改变最多 5 题、三档难度、额度校验和题目冻结规则。

**题目版本快照**：可以在练习开始时保存题干、选项、正确答案和解析版本，使历史页面能够区分作答时内容与当前内容。

**练习推荐**：可以根据错题、正确率和长期练习历史推荐考点或难度，但推荐不能绕过题目发布状态、当前考试、会员权益和唯一进行中练习限制。

### 5.4 待产品确认

- 完全随机和未做题优先上线后，是否需要向学生说明选题原则；
- 历史题目版本快照需要保留正确答案和解析，还是保存完整题干、选项、公式与图片；
- 单条练习记录发生快照异常时，是否允许用户隐藏该记录，或仅由后台完成数据修复。
