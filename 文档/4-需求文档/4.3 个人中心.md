# 4.3 个人中心 PRD

## 功能边界与目的

### 目的

让学生在同一页面查看个人资料、当前会员权益、按考试类型查看学习/诊断统计，并完成基础设置。后台管理员在顶部导航仅保留管理员入口，不与学生端个人中心主流程混淆。

### 使用对象与角色边界

- 学生：
  - 可进入个人中心。
  - 可查看三类考试类型（ESAT、TMUA、STEP）的权益、统计与订阅入口。
  - 可编辑用户名与邮箱。
  - 可触发“升级会员”引导。
  - 可退出登录。
- 管理员：
  - 顶部头像菜单默认展示“后台管理”入口。
  - 不将后台入口与学生端统计主流程混合为同一页面主动作项。

### 范围（包含/不包含）

本次包含：

- 个人中心基础入口与角色跳转规则。
- 左侧用户信息卡片与会员权益展示。
- 考试类型切换、权益依赖的数据展示策略。
- 已开通与未开通考试类型下的学习统计展示策略。
- 基础信息编辑（用户名、邮箱）与失败回滚。
- 订阅中心汇总与订阅记录展示、操作入口展示规则。

本次不包含：

- 正式支付和支付回调接入。
- 修改密码。
- 手机号绑定与头像上传。
- 报考目标完整编辑保存（如后续需求，当前仅保留展示/预留位）。

### 核心口径与术语

- 角色：学生、管理员。  
- 考试类型：ESAT、TMUA、STEP。  
- 用户权益只以后台 `UserMembership` 会员记录和会员接口计算结果为准。
- 会员状态：未开通 / 有效 / 到期。
- 流程状态：未开始、加载中、部分成功、失败、重试可用。

### 数据依赖（本节可用于验收前置）

个人中心的数据口径必须至少依赖以下接口与数据域：

- 当前登录用户信息（身份、昵称、邮箱、角色）。
- 用户会员记录（按考试类型的有效期与套餐）。
- 试题/试卷作答历史记录（用于统计）。
- 订阅记录（金额、周期、状态、支付方式）。

若接口返回为空且无严重错误，页面可继续展示“有权限可见的基础内容”，其缺失信息以兜底文案处理。

## 页面描述

### 页面入口与跳转

- 入口来源：顶部导航头像下拉菜单。
- 学生点击“个人中心”进入本页。
- 管理员点击“后台管理”跳转后台，不展示本页面主动作。
- 页面在每次打开时以“当前登录用户上下文”加载，不记忆上次退出时的考试类型。

### 页面区域与对象

页面包含四类核心区块：

1. 左侧用户信息区：头像、用户名、会员标签、退出登录。
2. 中间/上方考试类型区：展示 ESAT、TMUA、STEP 各自独立的诊断测试剩余/总额度；额度项同时作为考试类型 tab，并与下方状态联动。
3. 中间下方内容区：  
   - 已开通考试：学习统计（预估分数、累计做题、累计考试）。  
   - 未开通考试：会员开通引导（标题、说明、升级按钮）。
4. 下方信息区：基础信息、报考目标、订阅中心。

### 字段与按钮行为

- 用户名/邮箱：支持编辑，保存后更新到用户信息体系。  
- 密码：始终脱敏显示，禁止编辑。  
- 诊断测试额度：按考试类型分别展示，任一考试类型的使用记录不得扣减其他考试类型额度。
- 升级会员按钮：在未开通考试类型场景显示；点击后进入预留引导位（当前阶段不做真实支付）。
- 订阅记录按钮：按记录状态展示“续费/重新订阅”文案或按钮形态。
- 退出登录：清理前端登录状态并回到登录态安全页/首页默认入口。

### 页面状态

- 正常态：用户信息、权益、统计、订阅记录按来源返回值展示。  
- 空态：某模块无数据时展示明确空态文本，不阻塞其他模块。  
- 部分成功态：某接口成功、某接口失败时，仅失败区域以提示+可重试替代。

## 核心流程

### 1. 进入个人中心（页面初始化）

触发时机：用户从顶部菜单进入“个人中心”。

流程：

1. 读取当前用户身份与基本信息。
2. 并行读取用户会员数据、按考试类型聚合的诊断额度与考试统计数据、订阅数据。
3. 计算默认考试类型：
   - 有任一已开通考试类型时，默认选中任一已开通中的优先项（按固定顺序 ESAT > TMUA > STEP）。
   - 无任何开通时，默认展示系统默认考试类型（ESAT）。
4. 渲染左侧会员信息卡片和右侧考试内容区。

验收要点：

- 未开通任何会员时，左侧仍显示“免费版/未开通”，右侧以引导状态展示，页面不得空白。

### 2. 考试类型切换（已开通/未开通联动）

触发时机：学生点击 ESAT / TMUA / STEP tab。

流程：

1. 切换当前考试类型上下文。
2. 检查该考试类型是否有有效权益。
3. 有效则读取该考试类型统计；无效则展示会员引导。
4. 右侧内容区按该状态切换，不影响左侧用户卡片基础信息。

验收要点：

- 切换到已开通考试类型必须显示完整三项统计。
- 切换到未开通考试类型不得显示占位统计“--”，仅显示开通引导内容。

### 3. 用户信息编辑（用户名、邮箱）

触发时机：用户在基础信息区域点击“编辑”。

流程：

1. 用户名、邮箱进入可编辑态。
2. 点击保存时校验：
   - 用户名非空、长度合法。
   - 邮箱格式正确、未与其他用户冲突。
3. 校验通过则提交更新接口。
4. 成功后刷新页面信息展示；失败保持编辑态并给出错误提示。

验收要点：

- 用户名或邮箱校验失败时不发起提交。
- 密码始终不可编辑并保持脱敏。

### 4. 成就与订阅展示

触发时机：进入页面或切换考试类型后。

流程：

1. 从用户记录读取当前有效套餐与订阅记录列表。
2. 套餐信息按考试类型过滤，优先展示当前有效权益。
3. 订阅记录状态映射：
   - 有效且未到期：进行中
   - 到期：已过期
   - 后台手动取消：已取消
4. 操作按钮文案与状态联动（仅展示可执行动作）。

验收要点：

- 无有效权益时，订阅中心可展示“暂无有效订阅”，不影响上层页面继续可用。

### 5. 统计口径与更新

触发时机：切换考试类型或用户记录变化。

统计规则：

- 预估分数：按该考试类型已提交且完成的诊断/历年/模拟考试成绩计算平均（按 9 分制）。
- 累计做题：按题目唯一标识去重后汇总。
- 累计考试：按已完成考试记录计数（进行中、未提交不计）。

验收要点：

- 历史记录存在脏数据时，缺失字段需降级到可展示状态，不得因单条异常中断全量统计。

## 异常容错

### 接口失败与降级

- 用户信息成功、会员失败：仍展示基础信息，权益区域显示“加载失败，请重试”。
- 统计失败：显示该模块错误态或空值占位，不影响基础资料和登录状态展示。
- 订阅失败：订阅中心显示可重试提示，不影响用户可切换考试类型。
- 任一接口返回超时：前端应提供重试按钮或自动重试 1 次后进入失败提示。

### 鉴权与会话

- 登录态过期（401）：
  - 清理本地登录态，跳转到登录页。
  - 不保留可误导用户继续操作的交互按钮。
- 非法身份访问：
  - 管理员无法误入学生端统计核心操作；后台优先入口可见。

### 数据一致性

- 会员与统计存在不一致时，以会员记录作为主数据口径，统计模块按当前会员上下文过滤。
- 历史脏考试类型（如非 ESAT/TMUA/STEP）不参与当前页展示，记录在异常日志并以“不可识别类型”降级处理。
- 题目/考试记录 ID 缺失时，该记录不参与去重统计，避免报错。

### 并发与边界

- 编辑保存期间多次点击保存时，按钮应防抖，最后一次请求有效，避免重复提交导致闪烁或状态错乱。
- 用户频繁切换 Tab 时，界面应始终显示最近一次成功切换结果，旧请求返回不应覆盖新结果（以请求来源上下文校验）。

## 后续与非目标说明

### 本次交付包含

- 学生端个人中心完整入口、展示、Tab 切换、编辑、统计与订阅引导/展示。
- 管理员跳转行为在头像菜单中的角色隔离。
- 核心异常提示和降级。

### 当前非目标

- 正式会员支付与支付回调（保留入口文本）。
- 报考目标编辑保存的完整实现。
- 退款、发票、订单明细页、支付失败补偿链路。

### 后续建议（下一阶段）

- 接入支付流程并把“升级会员”从引导入口正式接到下单页。
- 订阅明细增加订单号、退款与发票能力。
- 报考目标支持多目标、科目动态联动与保存。
