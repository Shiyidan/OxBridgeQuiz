# 登录注册 PRD

> 描述登录、注册、忘记密码功能的用户侧定义。面向产品、前端、测试阅读，不涉及实现细节。

---

## 一、功能概述

用户通过用户名和邮箱注册账号，后续使用用户名和密码登录。登录后可使用全部学生功能（诊断测试、试题库练习、错题本）。未登录状态下只能浏览首页和试题库概览。

---

## 二、注册

### 2.1 功能描述

用户在注册页左侧填写用户名、邮箱、验证码、密码和确认密码；右侧选择备考类型和科目，并可填写目标院校、目标专业、考试日期、每周投入时长及 ESAT 目标分数。提交后创建账号并自动登录。

备考类型与科目的选择将在个人中心展示，用于后续个性化推荐和权限判断。

### 2.2 输入规则

| 字段 | 规则 |
|------|------|
| 用户名 | 必填，4-30 位；允许中文、英文字母、数字、下划线和连字符；必须以中文、英文字母或数字开头和结尾；不能为纯数字；全局唯一 |
| 邮箱 | 必填，合法邮箱格式，全局唯一 |
| 密码 | 必填，8-12 位，必须同时包含英文字母和数字；特殊字符可选且仅允许 `!@#$%` |
| 确认密码 | 必填，须与密码字段完全一致 |
| 备考类型 | 选填，可多选：ESAT / TMUA / STEP |
| 备考科目 | 选填，根据备考类型联动展示 |
| 目标院校 | 选填；按考试类型分别保存，通过多选下拉框最多选择 2 个；选项为剑桥大学、牛津大学、帝国理工学院、伦敦大学学院、伦敦政治经济学院 |
| 目标专业 | 选填；按考试类型分别保存 |
| ESAT 目标分数 | 选填，仅 ESAT 展示，范围 1.0-9.0 |
| 考试日期 | 选填；按考试类型分别保存 |
| 每周投入时长 | 选填；按考试类型分别保存，范围 1-80 小时 |

### 2.2.1 备考类型与科目联动

| 备考类型 | 可选科目 | 必选科目 |
|---------|---------|:---:|
| ESAT | 数学1、数学2、物理、化学、生物 | 数学1 |
| TMUA | 数学 | 数学 |
| STEP | 数学 | 数学 |

- 选中 ESAT 时数学1 默认勾选且不可取消
- 选中 TMUA 或 STEP 时数学默认勾选且不可取消
- 取消某备考类型时，对应已选科目一并清除

### 2.3 前端校验

注册按钮被激活前完成以下校验，不通过时按钮置灰：

1. 用户名满足 4-30 位字符集、首尾字符和非纯数字规则
2. 邮箱格式合法
3. 密码 8-12 位且含英文 + 数字，其他字符只能为 `!@#$%`
4. 确认密码与密码一致（实时比对，不一致时输入框标红）

### 2.4 异常处理

| 异常 | 用户看到的信息 |
|------|-------------|
| 用户名已被使用 | "该用户名已被使用" |
| 邮箱已注册 | "该邮箱已注册" |
| 校验不通过 | 按用户名、验证码或密码的具体格式规则提示；两次输入的密码不一致时单独提示 |
| 请求过于频繁 | "请求过于频繁，请稍后再试"（1 分钟内超过 5 次触发） |
| 服务器异常 | "服务器错误" |

### 2.5 注册后行为

- 自动登录（无需再输密码）
- 跳转至首页
- 导航栏显示用户头像和用户名

## 三、登录

### 3.1 功能描述

用户在登录页输入用户名和密码，校验通过后进入系统。登录态保持 7 天，关闭浏览器后 7 天内重新打开无需重新登录。

### 3.2 输入规则

| 字段 | 规则 |
|------|------|
| 用户名 | 必填，最多 50 字 |
| 密码 | 必填 |

### 3.3 异常处理

| 异常 | 用户看到的信息 |
|------|-------------|
| 用户名或密码错误 | "用户名或密码错误"（不区分是用户名不存在还是密码错） |
| 请求过于频繁 | "请求过于频繁，请稍后再试"（1 分钟内超过 5 次触发） |
| 服务器异常 | "服务器错误" |

### 3.4 登录后行为

- 跳转至首页
- 导航栏显示用户头像、用户名、当前角色标签
- 可正常使用诊断测试、做题、错题本等需登录功能

---

## 四、退出登录

### 4.1 功能描述

用户点击导航栏头像 → 下拉菜单 → "退出登录"，清除本地登录态并跳转至首页。

### 4.2 退出后行为

- 导航栏恢复为"登录 / 立即注册"
- 再次访问需登录页面时跳转至登录页

---

## 五、登录态管理

### 5.1 保持时长

登录态保持 **7 天**。7 天内关闭浏览器或关闭标签页后重新打开，自动恢复登录态，无需重新输入密码。超过 7 天未访问则登录过期，需重新登录。

### 5.2 登录态失效

| 场景 | 用户体验 |
|------|---------|
| 7 天到期 | 页面自动跳转至登录页，提示"登录已过期，请重新登录" |
| 手动退出 | 返回首页，可正常浏览公开内容 |
| 清除浏览器数据 | localStorage 被清空，等同于退出登录 |

### 5.3 多设备

同一账号可在多个设备/浏览器同时登录，互不影响。

## 六、忘记密码

### 6.1 当前状态

**暂未实现。** 登录页已预留"忘记密码"文案入口，点击后无交互。

### 6.2 计划功能

用户点击"忘记密码" → 输入注册邮箱 → 系统发送密码重置邮件（含有时效的一次性链接） → 用户点击链接进入重置页 → 输入新密码 → 完成重置。

## 七、会员与权限

### 7.1 权限层级

| 身份 | 可访问 |
|------|-------|
| 游客（未登录） | 首页、试题库浏览、登录、注册 |
| 学生（已登录） | 以上全部 + 诊断测试、在线答题、错题本、个人中心 |
| 管理员 | 以上全部 + 管理后台 |

### 7.2 诊断测试权限

已登录用户方可进入诊断测试。每个考试类型（TMUA / ESAT 等）的免费诊断次数由会员套餐决定，额度用完后提示"当前诊断测试额度不足，请开通会员后继续"。

### 7.3 路由权限

| 路由 | 游客 | 学生 | 管理员 |
|------|:---:|:---:|:---:|
| `/` 首页 | ✅ | ✅ | ✅ |
| `/login` `/register` | ✅ | → 跳首页 | → 跳首页 |
| `/question-bank` | ✅ | ✅ | ✅ |
| `/assessment`（诊断测试） | → 跳登录 | ✅ | ✅ |
| `/mistake-notebook` | → 跳登录 | ✅ | ✅ |
| `/practice`（在线答题） | → 跳登录 | ✅ | ✅ |
| `/profile` | → 跳登录 | ✅ | ✅ |
| `/admin/*` | → 跳首页 | → 跳首页 | ✅ |

## 八、安全策略

| 措施 | 说明 |
|------|------|
| 密码存储 | 加密存储，不可还原为明文 |
| 密码传输 | 生产环境强制 HTTPS 加密传输 |
| 登录限速 | 同一 IP 每分钟最多 5 次登录/注册请求 |
| 错误信息保护 | 登录失败不区分"用户名不存在"还是"密码错误"，统一提示"用户名或密码错误" |
| 角色校验 | 前端不可绕过——后端每个接口独立校验权限 |
