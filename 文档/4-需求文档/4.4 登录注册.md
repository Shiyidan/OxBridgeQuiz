# 登录注册 PRD

> 描述登录、注册、忘记密码功能的用户侧定义。面向产品、前端、测试阅读，不涉及实现细节。

---

## 一、功能概述

用户通过用户名和邮箱注册账号，后续使用用户名和密码登录。登录后可使用全部学生功能（诊断测试、试题库练习、错题本）。未登录状态下只能浏览首页和试题库概览。

---

## 二、注册

### 2.1 功能描述

用户在注册页左侧填写用户名、邮箱、验证码、密码和确认密码；右侧选择备考类型和科目，并可填写目标院校、目标专业、考试日期、每周投入时长及 ESAT 目标分数。提交后创建账号并自动登录。

备考类型与科目的选择将在个人中心展示，用于后续个性化诊断测试报告和权限判断。

### 2.2 输入规则

| 字段 | 规则 |
|------|------|
| 用户名 | 必填，4-30 位；允许中文、英文字母、数字、下划线和连字符；必须以中文、英文字母或数字开头和结尾；不能为纯数字；全局唯一 |
| 邮箱 | 必填，合法邮箱格式，全局唯一 |
| 密码 | 必填，8-12 位，必须同时包含英文字母和数字；特殊字符可选且仅允许 `!@#$%` |
| 确认密码 | 必填，须与密码字段完全一致 |
| 备考类型 | 选填，可多选：ESAT / TMUA / STEP |
| 备考科目 | 选填，根据备考类型联动展示 |
| 目标院校 | 选填；按考试类型分别保存，通过多选下拉框最多选择 2 个；选项为剑桥大学、牛津大学、帝国理工学院、伦敦大学学院、伦敦政治经济学院 |
| 目标专业 | 选填；按考试类型分别保存 |
| ESAT 目标分数 | 选填，仅 ESAT 展示，范围 1.0-9.0 |
| 考试日期 | 选填；按考试类型分别保存 |
| 每周投入时长 | 选填；按考试类型分别保存，范围 1-80 小时 |

### 2.2.1 备考类型与科目联动

| 备考类型 | 可选科目 | 必选科目 |
|---------|---------|:---:|
| ESAT | 数学1、数学2、物理、化学、生物 | 数学1 |
| TMUA | 数学 | 数学 |
| STEP | 数学 | 数学 |

- 选中 ESAT 时数学1 默认勾选且不可取消
- 选中 TMUA 或 STEP 时数学默认勾选且不可取消
- 取消某备考类型时，对应已选科目一并清除

### 2.3 前端校验

注册按钮被激活前完成以下校验，不通过时按钮置灰：

1. 用户名满足 4-30 位字符集、首尾字符和非纯数字规则
2. 邮箱格式合法
3. 密码 8-12 位且含英文 + 数字，其他字符只能为 `!@#$%`
4. 确认密码与密码一致（实时比对，不一致时输入框标红）

### 2.4 异常处理

| 异常 | 用户看到的信息 |
|------|-------------|
| 用户名已被使用 | "该用户名已被使用" |
| 邮箱已注册 | "该邮箱已注册" |
| 校验不通过 | 按用户名、验证码或密码的具体格式规则提示；两次输入的密码不一致时单独提示 |
| 请求过于频繁 | "请求过于频繁，请稍后再试"（1 分钟内超过 5 次触发） |
| 服务器异常 | "服务器错误" |

### 2.5 注册后行为

- 自动登录（无需再输密码）
- 跳转至首页
- 导航栏显示用户头像和用户名

## 三、登录

### 3.1 功能描述

用户在登录页输入用户名和密码，校验通过后进入系统。登录态保持 7 天，关闭浏览器后 7 天内重新打开无需重新登录。

### 3.2 输入规则

| 字段 | 规则 |
|------|------|
| 用户名 | 必填，最多 50 字 |
| 密码 | 必填 |

### 3.3 异常处理

| 异常 | 用户看到的信息 |
|------|-------------|
| 用户名或密码错误 | "用户名或密码错误"（不区分是用户名不存在还是密码错） |
| 请求过于频繁 | "请求过于频繁，请稍后再试"（1 分钟内超过 5 次触发） |
| 服务器异常 | "服务器错误" |

### 3.4 登录后行为

- 跳转至首页
- 导航栏显示用户头像、用户名、当前角色标签
- 可正常使用诊断测试、做题、错题本等需登录功能

---

## 四、退出登录

### 4.1 功能描述

用户点击导航栏头像 → 下拉菜单 → "退出登录"，清除本地登录态并跳转至首页。

### 4.2 退出后行为

- 导航栏恢复为"登录 / 立即注册"
- 再次访问需登录页面时跳转至登录页

## 五、登录态管理

### 5.1 保持时长

登录态采用 **7 天滑动有效期**，不设置额外的绝对最长登录期限。用户持续正常使用系统时可以继续保持登录；连续 7 天没有发生有效活动后，登录态失效并要求重新登录。

### 5.2 活动与续期规则

1. 用户登录成功时，系统从登录时间开始计算首个 7 天有效窗口。
2. 用户重新打开站点时，系统会尝试恢复已有登录状态；恢复成功视为一次有效活动。
3. 用户登录期间需要延续身份状态时，系统自动刷新会话；刷新成功视为一次有效活动。
4. 每次有效活动完成后，最近活动时间更新为当前时间，有效期重新顺延至“当前时间 + 7 天”。
5. 鼠标移动、键盘输入、页面保持打开、浏览公开页面以及刷新失败均不计为有效活动。
6. 系统不会因为每一次普通业务请求都刷新登录期限，避免无意义的频繁续期；续期由统一的登录状态恢复或会话刷新流程完成。

示例：用户在 7 月 1 日登录，原有效期截至 7 月 8 日；如果用户在 7 月 6 日成功恢复或刷新登录状态，则新的有效期顺延至 7 月 13 日。

### 5.3 登录态失效

| 场景 | 用户体验 |
|------|---------|
| 连续 7 天无活动 | 页面自动跳转至登录页，提示"登录已过期，请重新登录" |
| 当前设备退出 | 当前设备返回首页，其他设备不受影响 |
| 全部设备退出 | 所有设备的登录状态失效，后续访问需重新登录 |
| 修改或重置密码 | 所有既有设备会话失效，用户使用新密码重新登录 |
| 当前设备会话被撤销 | 当前设备在下次身份校验时跳转登录页 |
| 清除浏览器 Cookie 或站点数据 | 当前设备无法恢复会话，等同于退出登录 |

### 5.4 多设备

同一账号可在多个设备或浏览器同时登录。每个设备拥有独立的最近活动时间和 7 天滑动有效期：一个设备续期不会延长其他设备的会话；退出当前设备不会影响其他设备，只有“退出全部设备”、修改密码或重置密码会统一撤销所有设备会话。

## 六、忘记密码

### 6.1 功能描述

忘记密码功能已经完成。用户通过注册邮箱接收六位数字验证码，验证通过后设置新密码。密码重置成功后，账号在所有设备上的既有登录状态全部失效，用户使用新密码重新登录。

### 6.2 核心流程

```text
登录页点击“忘记密码”
→ 登录卡片切换为重置密码模块
→ 输入注册邮箱并获取验证码
→ 邮箱接收六位数字验证码
→ 输入验证码、新密码和确认密码
→ 系统校验验证码并更新密码
→ 撤销账号全部设备会话
→ 登录卡片切换回登录模块并使用新密码登录
```

### 6.3 输入与验证码规则

| 字段 | 规则 |
|------|------|
| 注册邮箱 | 必填，使用注册时绑定的邮箱；统一去除首尾空格并转换为小写 |
| 邮箱验证码 | 必填，只能输入六位数字；有效期 10 分钟；只能用于本次重置密码 |
| 新密码 | 必填，8-12 位，必须同时包含英文字母和数字；特殊字符可选且仅允许 `!@#$%` |
| 确认新密码 | 必填，必须与新密码完全一致 |

- 同一邮箱 60 秒内不能重复发送验证码。
- 同一已注册邮箱每小时最多发起 5 次同用途验证码发送请求。
- 同一验证码最多允许连续输错 5 次，超过后必须重新获取。
- 新验证码生成后，同邮箱、同用途的旧验证码立即失效。
- 验证码验证成功后立即失效，不能重复用于重置密码。

### 6.4 账号信息保护

发送验证码时，无论邮箱是否已经注册，页面均提示“如果该邮箱已注册，验证码邮件会很快送达”，不向外部暴露账号是否存在。未注册邮箱不会实际收到邮件，也不能通过返回的请求标识完成密码重置。

密码更新和验证码消费必须作为一次完整操作执行：验证码无效时不得修改密码，密码更新失败时验证码也不得被错误消费。

### 6.5 异常处理

| 异常 | 用户看到的信息或行为 |
|------|--------------------|
| 邮箱格式错误 | 提示输入有效的邮箱地址 |
| 请求发送过于频繁 | 提示稍后重新获取验证码 |
| 邮件服务暂时不可用 | 提示验证码邮件暂时无法发送，请稍后再试 |
| 验证码错误 | 提示验证码错误 |
| 验证码过期或已使用 | 提示重新获取验证码 |
| 验证码错误次数过多 | 当前验证码失效，提示重新获取 |
| 新密码不符合规则 | 展示对应密码格式提示 |
| 两次密码不一致 | 提示两次输入的密码不一致 |

### 6.6 重置后行为

- 当前浏览器中的登录凭证被清除。
- 账号在其他设备和浏览器中的会话全部撤销。
- 页面提示“密码已重置，请使用新密码登录”。
- 用户返回登录页，旧密码不能再用于登录。

## 七、会员与权限

### 7.1 身份与会员分离

用户身份和会员权益是两个独立概念：

- `role` 仅表示用户身份，当前包括学生和管理员。
- 会员资格按考试类型分别开通，不通过用户角色或旧付款状态推断。
- 注册时选择的备考类型只用于个性化展示和学习目标，不会自动获得会员资格或额外额度。
- 管理员拥有管理后台权限，并在各考试类型下享有不限次数的业务权益。

### 7.2 访问权限层级

| 身份 | 可访问 |
|------|-------|
| 游客（未登录） | 首页、考试介绍、登录（含忘记密码模块）和注册页面 |
| 学生（已登录） | 学生侧试题库、诊断测试、在线答题、结果与报告、错题本和个人中心 |
| 管理员 | 学生侧全部功能、管理后台，并拥有不限次数的业务权益 |

### 7.3 按考试类型计算权益

ESAT、TMUA 和 STEP 的会员状态与免费额度相互独立。例如，用户开通 ESAT 会员不会自动获得 TMUA 或 STEP 会员权益。

| 用户状态 | 诊断测试 | 试题库练习 |
|---------|---------|-----------|
| 免费用户 | 每个考试类型默认 1 次，可由后台权益配置调整 | 每个考试类型默认 25 题，试题库与练习本共用，可由后台权益配置调整 |
| 对应考试类型的有效会员 | 不限次数 | 不限题数 |
| 其他考试类型会员 | 仅对已开通类型生效，当前类型仍按免费额度计算 | 仅对已开通类型生效，当前类型仍按免费额度计算 |
| 管理员 | 所有考试类型不限次数 | 所有考试类型不限题数 |

有效会员必须同时满足会员状态有效、开始时间已到且结束时间未到。已过期或已取消的会员不再提供不限次数权益。

### 7.4 额度使用与展示

- 免费额度按考试类型分别累计使用，不同考试类型之间互不占用。
- 个人中心分别展示 ESAT、TMUA、STEP 的剩余次数或“会员不限次”。
- 免费额度耗尽时，不再开始新的受限业务，并提示用户获取更多额度或开通对应考试类型会员。
- 已有的会员、已过期会员和已取消会员分别展示对应状态，不把历史会员记录误判为当前有效权益。

## 八、安全策略

| 措施 | 说明 |
|------|------|
| 密码存储 | 加密存储，不可还原为明文 |
| 密码传输 | 生产环境强制 HTTPS 加密传输 |
| 登录限速 | 同一 IP 每分钟最多 5 次登录/注册请求 |
| 错误信息保护 | 登录失败不区分"用户名不存在"还是"密码错误"，统一提示"用户名或密码错误" |
| 角色校验 | 前端不可绕过——后端每个接口独立校验权限 |
