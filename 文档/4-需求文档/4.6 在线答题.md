# 4.6 在线答题

> 在线答题模块的产品功能说明。涵盖计时交互、答题操作、交卷与结果反馈。

---

## 一、答题计时

答题页顶部居中显示计时器，格式为 `MM:SS`，每秒刷新一次。计时模式根据答题入口自动切换：

### 1.1 诊断测试 — 倒计时

- 入口：诊断测试 → 选择套卷 → 开始测试。
- 倒计时初始值 = 该试卷的 `时长（分钟）× 60` 秒。
- 计时器从初始值开始递减。
- 剩余 ≤ 5 分钟时，计时器数字变为**红色**警示。

**倒计时归零**：

1. 计时器归零，弹出提示弹窗：
   - 标题：「答题时间到」
   - 内容：「考试时间已结束，系统将自动提交您的试卷。」
   - 仅一个「确定」按钮，居中显示。
   - 弹窗样式遵循全局 `app-confirm-box` 规范。
2. 用户点击「确定」后，**自动提交试卷**，跳转至结果页。
3. 弹窗不可通过点击遮罩关闭，不可通过关闭按钮关闭（`showClose: false`）。

### 1.2 试题库练习 — 正计时

- 入口：试题库 → 选择考点 / 难度 → 开始练习。
- 计时器从 `00:00` 开始递增。
- 无时间限制，归零不会触发任何行为。
- 用户自行决定何时交卷。

### 1.3 切 tab / 锁屏暂停

用户切换到其他浏览器标签页或锁屏时：

- 倒计时和正计时**暂停**，计时器不再走动。
- 当前题目的单题耗时**自动结算**，后台时间不计入。
- 切回页面时弹出确认弹窗：「是否开始继续答题」，仅一个「确定」按钮居中显示，弹窗不可关闭。
- 点击「确定」后计时器和单题耗时恢复。

### 1.4 单题耗时（自动后台记录）

无论哪种计时模式，系统还会自动记录每道题的停留时间：

- 进入某题时开始计时，离开时（切题 / 交卷）累加该题耗时。
- 同一道题多次回看，每次停留时间累加。
- 用户无需任何操作，全程无感知。

## 二、答题交互

### 2.1 选题方式

- **上一题 / 下一题按钮**：顺序切换题目。
- **左侧答题卡**：显示所有题号，区分已答 / 跳过 / 未答 / 当前四种状态，点击题号直接跳转。

### 2.2 作答状态

| 状态 | 答题卡样式 | 说明 |
|------|-----------|------|
| 已答 | 绿色背景 | 用户已选择过选项 |
| 跳过 | 橙色背景 | 浏览过但未作答 |
| 未答 | 白色背景 | 尚未浏览 |
| 当前 | 蓝色边框 | 正在浏览的题目 |

### 2.3 选项交互

- 点击选项即选中，高亮当前选项。
- 再次点击同一选项可取消选择。
- 单选题：选择新选项自动取消旧选项。

---

## 三、提交试卷

### 3.1 提前交卷

点击左侧「提前交卷」按钮 → 弹出确认弹窗：

- 如有未答题：提示 "未作答题目会计为未答，是否提前交卷？"
- 如全部已答：提示 "确认交卷？"
- 点击「确认交卷」提交，点击「继续答题」取消。

### 3.2 强制交卷

仅诊断测试倒计时归零时触发（见 1.1 节「倒计时归零」）。

### 3.3 返回试题库

点击左上角「返回试题库」→ 弹出确认弹窗 → 确认后离开答题页，**当前作答不会自动提交**。

---

## 四、结果与耗时展示

| 场景 | 展示的耗时 | 数据来源 |
|------|-----------|---------|
| 交卷结果页 | 整卷总耗时（`X分Y秒`） | 前端计算 `交卷时间 - 开始时间` |
| 详细诊断报告 | 每道题的平均用时、超时题标记 | 各题 `durationSeconds` 累加 |
| 错题本 | 每条错题的用时 | 该题 `durationSeconds` |
| 练习记录 | 每次练习的总耗时 | 服务端计算 `submittedAt - startedAt` |
