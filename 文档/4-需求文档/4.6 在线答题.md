# 4.6 在线答题

> 在线答题模块的行为与验收说明，覆盖试题库练习、诊断真题和仿真考试的计时、作答、恢复与交卷流程。

---

## 1. 功能边界与目的

### 1.1 目标

学生在不同答题场景中获得与业务目标一致的计时体验：试题库练习和可恢复的诊断真题按实际作答时间计时，仿真考试按正式考试截止时间连续计时；所有场景均准确保存单题活跃耗时和考试总耗时。

### 1.2 场景与计时边界

| 场景 | `paperType` | 计时方式 | 切出浏览器后的总计时 | 单题活跃耗时 |
| --- | --- | --- | --- | --- |
| 试题库练习 | `aiPaper` | 正计时 | 暂停 | 暂停 |
| 诊断真题 | `realPaper` | 分段倒计时 | 暂停并冻结剩余时间 | 暂停并结算到切出时刻 |
| 仿真考试 | `mockPaper` | 倒计时 | 继续 | 暂停并结算到切出时刻 |

本期保留两类耗时：

- 考试总耗时：试题库为实际活跃练习时间；分段诊断真题为各模块实际作答时间之和；仿真考试为服务端开始时间至提交或截止时间的连续时长。
- 单题耗时：题目实际可见、可作答期间的累计活跃时间，同一道题多次进入时累加。

本期不单独统计、不保存、不展示“中断耗时”或“离开页面次数”。

### 1.3 状态与数据来源

| 状态或字段 | 含义 | 数据来源 |
| --- | --- | --- |
| `in_progress` | 已开始、尚未交卷 | `ExamRecord.status` |
| `submitted` | 已完成交卷 | `ExamRecord.status` |
| `startedAt` | 服务端确认的考试开始时间 | `ExamRecord.startedAt` |
| `expiresAt` | 当前活跃模块或连续考试的服务端截止时间 | 诊断恢复时按冻结的剩余时间重新生成；仿真考试为 `startedAt + Paper.duration` |
| `durationSeconds` | 最终考试总耗时 | `ExamRecord.durationSeconds` |
| 单题耗时 | 每道题的累计活跃秒数 | `AnswerRecord.durationSeconds` |

`startedAt`、`expiresAt`、诊断暂停状态和最终总耗时均由后端确定。前端只能请求暂停或恢复，不得自行修改剩余时间。

### 1.4 本期验收边界

- 诊断真题切出页面、锁屏或确认返回诊断中心后，必须在服务端冻结剩余时间；重新进入时从冻结值恢复。
- 仿真考试切出页面后，倒计时不得暂停或重置。
- 试题库练习切出页面后，正计时必须暂停，确认继续后恢复。
- 所有场景切出页面期间不得增加当前题单题耗时。
- 诊断真题刷新或重新进入时，答案、单题耗时和剩余时间必须从后端恢复。
- 本期不提供中断耗时和中断次数报表。

## 2. 页面描述

### 2.1 顶部导航栏

顶部导航栏显示考试类型、当前题号、总题量、进度条和 `MM:SS` 计时器：

- 诊断真题和仿真考试显示剩余时间，剩余不超过 5 分钟时使用红色警示并只提醒一次。
- 试题库练习显示已用活跃时间，从 `00:00` 开始递增。
- 导航栏是页面可见性和总计时状态的唯一控制组件，答题页不得再独立维护另一套暂停状态。

### 2.2 切出与切回交互

试题库练习切出浏览器或锁屏：

1. 总计时和当前题单题耗时同时暂停。
2. 切回后弹出“是否开始继续答题”。
3. 弹窗不可关闭；点击“确定”后总计时和单题耗时同时恢复。

诊断真题切出浏览器、锁屏或确认返回诊断中心：

1. 当前题单题耗时结算到切出时刻并暂停。
2. 前端调用暂停接口提交当前模块完整答题快照。
3. 后端在作答时写入 `paused`、在休息时写入 `break_paused`，并冻结对应剩余秒数；暂停期间不累计模块耗时，也不在后台启动下一模块。
4. 切回或点击“继续测试”时调用恢复接口，由后端按冻结秒数生成新的 `expiresAt`。
5. 恢复成功后才重新开放选项并累计单题耗时；暂停或恢复请求期间所有答题入口保持禁用。

仿真考试切出浏览器或锁屏后，倒计时仍按照原服务端 `expiresAt` 推进；已超时时直接进入时间到交卷流程。

### 2.3 题目导航和状态

左侧答题卡展示全部题号，并区分：

| 状态 | 说明 |
| --- | --- |
| 已答 | 已选择答案，`answerState = answered` |
| 跳过 | 已查看但未作答，`answerState = skipped` |
| 未答 | 尚未查看，`answerState = unseen` |
| 当前 | 正在浏览的题目 |

上一题、下一题和题号导航使用同一切题逻辑；离开当前题前必须先结算该题活跃耗时。

### 2.4 交卷反馈

- 有未答题时提示“未作答题目会计为未答，是否提前交卷？”。
- 全部已答时提示“确认交卷？”。
- 倒计时到零时弹出“答题时间到”，用户确认后提交已保存和当前页面中的最终答案。
- 提交过程中禁用重复操作；提交失败时保留当前作答并允许重试。

## 3. 核心流程

### 3.1 开始或恢复考试

1. 前端调用 `POST /api/exams/start`。
2. 后端校验登录、权限、试卷类型和正式题目范围。
3. 新建分段诊断真题时，后端使用服务器时间写入 `startedAt`，并根据当前模块时长生成首个 `expiresAt`。
4. 存在同试卷 `in_progress` 记录时，返回原 `examRecordId`、已保存答案、状态和单题耗时。
5. 若记录处于 `paused`，后端根据暂停时冻结的剩余秒数生成新的 `expiresAt`，不得恢复完整模块时长。
6. 若记录仍处于 `answering` 且已经超过截止时间，后端先收敛过期模块、休息和待交卷状态，不得向前端返回可编辑的过期模块。

### 3.2 切题与增量保存

1. 选择答案时只更新前端状态并标记当前题待保存。
2. 切换题目时结算离开题目的单题活跃耗时。
3. 调用 `PUT /api/exams/:examRecordId/progress`，通常只提交离开的这一题。
4. 后端只更新请求中对应的 `AnswerRecord`，不覆盖其他题目。
5. 每 60 秒检查一次；只有答案尚未保存或当前题累计耗时比上次落库新增满 60 秒时才补交。
6. 逐题耗时传累计值，使重复请求保持幂等。

### 3.3 页面可见性联动

导航栏检测到页面隐藏时发出 `answering-paused`：

1. 答题页结算当前题到隐藏时刻的活跃耗时。
2. 诊断真题调用暂停接口保存当前模块完整快照并冻结剩余时间。
3. 单题计时进入暂停状态，隐藏期间的时间不再累计。
4. 诊断真题和试题库总计时保持暂停；仿真考试总倒计时仍由原 `expiresAt` 推进。

导航栏允许恢复作答时发出 `answering-resumed`。诊断真题必须先取得后端恢复后的新截止时间，再重新开放作答并累计当前题活跃耗时。

### 3.4 截止时间校验

- 真题和仿真考试的 `progress` 请求到达后端时，如果当前时间已经不早于 `expiresAt`，后端返回 `EXAM_EXPIRED`，不再接受普通进度更新。
- 前端切回页面或重新进入时，必须使用后端恢复后的 `expiresAt`；刷新期间若暂停请求未完成，后端仍按现存阶段进行截止校验。
- 到期后的交卷仍允许提交，后端总耗时最多计算到 `expiresAt`，不能因延迟请求而增加考试时长。

### 3.5 正式交卷和耗时落库

交卷接口 `POST /api/exams/:examRecordId/submit` 使用完整最终快照：

1. 后端读取正式题目和答案，重新计算每题正误与总正确数。
2. 保存全部 `AnswerRecord`。
3. 分段诊断真题总耗时为各作答阶段写入的 `activeDurationSeconds`；仿真考试总耗时为 `min(submittedAt, expiresAt) - startedAt`。
4. 试题库练习总耗时为所有单题活跃耗时之和。
5. 将结果写入 `ExamRecord.durationSeconds`，后续页面不得再次使用 `submittedAt - startedAt` 计算展示耗时。
6. 诊断真题交卷成功后创建诊断报告任务。

### 3.6 结果与耗时展示

| 场景 | 展示内容 | 唯一数据来源 |
| --- | --- | --- |
| 交卷结果页 | 考试总耗时 | `ExamRecord.durationSeconds` |
| 诊断报告 | 总耗时、平均用时、超时题 | `ExamRecord.durationSeconds` + `AnswerRecord.durationSeconds` |
| 错题本 | 对应错题单题耗时 | `AnswerRecord.durationSeconds` |
| 练习记录 | 每次考试总耗时 | `ExamRecord.durationSeconds` |

### 3.7 核心验收点

- 诊断真题切出 2 分钟再返回，剩余时间和当前题单题耗时均不得增加或减少这 2 分钟。
- 试题库切出 2 分钟再返回，正计时和当前题耗时均不得增加，确认后才恢复。
- 诊断真题暂停后刷新或重新进入不得恢复完整模块时长，必须按服务端冻结的剩余时间生成新截止时间。
- 超过截止时间后 `progress` 返回 `EXAM_EXPIRED`，交卷总耗时不得超过试卷规定时长。
- 结果页、练习记录和诊断报告中的总耗时必须读取同一个后端字段。

## 4. 异常容错

### 4.1 页面隐藏时保存失败

- 页面隐藏时的保存属于尽力执行，浏览器可能中止网络请求。
- 保存失败时保留脏题状态；切回、后续切题或 60 秒检查点继续重试。
- 暂停请求失败时不得离开答题页；后续切题、再次暂停或定时保存继续重试当前完整快照。

### 4.2 浏览器关闭或刷新

- 诊断真题重新进入时恢复数据库中最后成功保存的答案、单题耗时和服务端冻结的模块剩余时间。
- 已成功进入 `paused` 的记录不因关闭页面或长时间离开而减少剩余时间。
- 未成功暂停且已经到期的历史记录重新进入时，由服务端收敛到下一有效阶段或待交卷状态。

### 4.3 客户端时间异常

- 诊断真题以服务端保存的暂停阶段、冻结剩余时间和恢复后 `expiresAt` 为准；仿真考试以服务端创建的 `startedAt`、`expiresAt` 为准。
- 前端时间只用于页面逐秒刷新，不得修改后端截止时间。
- 后端在保存进度和交卷时再次校验截止时间。

### 4.4 重复交卷和多窗口

- 前端使用提交锁，后端按考试记录和 `submissionKey` 保持幂等。
- 同一考试记录只创建一个诊断分析任务。
- 已提交记录再次提交时返回原结果，不重复判分或扣减权益。

### 4.5 异常验收点

- 页面隐藏保存失败后，返回页面继续切题能够再次保存。
- 修改前端倒计时不得改变后端 `expiresAt`。
- 两个窗口重复交卷最终只能得到一条有效考试结果。
- 截止时间后延迟提交，数据库总耗时仍不得超过规定时长。

## 5. 后续与非目标说明

### 5.1 本次交付包含

- 诊断真题服务端暂停/恢复与模块截止时间，仿真考试连续截止时间。
- 试题库与真题分场景暂停规则。
- 导航栏与单题耗时统一暂停、恢复事件。
- 最终考试总耗时持久化及统一读取。
- 诊断真题切页、锁屏、刷新和确认退出后的进度及冻结剩余时间恢复。

### 5.2 本次不做

- 不统计或展示中断耗时、离开次数和离开原因。
- 不将切出浏览器直接判定为作弊。
- 不提供教师端考试中断行为报表。
- 暂不增加独立后台定时任务主动扫描并提交所有已过期考试；当前在学生重新进入、保存或提交时校验截止时间。

### 5.3 后续建议

- 仿真考试正式上线后，可增加服务端过期考试扫描任务。
- 如需要考试纪律分析，可在独立需求中增加中断次数和中断时长，不与当前单题耗时混用。
