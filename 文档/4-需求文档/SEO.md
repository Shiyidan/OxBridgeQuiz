## 一、背景与目的

当前搜索 `acemock.cn` 时，搜索结果主要存在以下问题：

- 网站名称显示为域名 `acemock.cn`，没有形成明确的品牌名称。
- 首页标题仍是通用的“在线答题系统”，不能说明产品服务对象和核心价值。
- 首页缺少稳定的搜索摘要，搜索引擎只能从页面正文中自行抽取内容。
- `/question-bank` 等登录后页面被搜索引擎发现，搜索结果出现“使用你的账号继续备考旅程”等登录文案。
- 公开页面与私有业务页面没有清晰的索引边界。
- 当前是 Vue 单页应用，初始 HTML 中缺少页面正文和路由级 SEO 信息，搜索引擎需要等待 JavaScript 渲染后才能完整理解页面。

本方案的目标是让搜索引擎清楚理解网站的品牌、产品定位、公开页面结构和索引边界，使品牌搜索结果更正式、准确和稳定。

## 二、目标搜索结果

希望首页搜索结果逐步接近以下表达：

```text
AceMock 云舟备考
https://acemock.cn

AceMock 云舟备考｜ESAT 与 TMUA 真题诊断
AceMock 云舟备考基于历年真题和考试大纲，提供 ESAT、TMUA 水平诊断、
知识点分析、专项练习与错题复习，帮助学生针对薄弱项高效备考。
```

推荐首页文案基线：

```html
<title>AceMock 云舟备考｜ESAT 与 TMUA 真题诊断</title>
<meta
  name="description"
  content="AceMock 云舟备考基于历年真题和考试大纲，提供 ESAT、TMUA 水平诊断、知识点分析、专项练习与错题复习，帮助学生针对薄弱项高效备考。"
/>
```

其中：

- `AceMock` 是英文主品牌。
- `云舟备考` 是中文品牌名。
- `AceMock 云舟备考` 是对外使用的完整品牌名称。
- “ESAT 与 TMUA 真题诊断”用于解释产品定位，不与品牌名称混在同一层级反复堆砌。

搜索引擎最终可能根据用户的搜索词调整标题和摘要，因此上述内容是明确的展示建议，不是对搜索结果样式的强制控制。

## 三、方案说明

### 1. 首页基础 SEO 信息

首页需要补充并保持一致的基础信息：

- 页面标题 `title`：影响浏览器标签页，也通常是搜索结果中的蓝色标题。
- 页面摘要 `meta description`：向搜索引擎提供首页内容概述。
- 规范网址 canonical：明确首页唯一规范地址为 `https://acemock.cn/`。
- Open Graph：控制网页被分享到支持该协议的平台时使用的站点名称、标题、摘要和图片。
- favicon：使用稳定、可公开访问、正方形且清晰的品牌图标。
- `WebSite` 结构化数据：告诉搜索引擎网站正式名称和可接受的品牌别名。

推荐站点名称结构化数据：

```html
<script type="application/ld+json">
  {
    "@context": "https://schema.org",
    "@type": "WebSite",
    "name": "AceMock 云舟备考",
    "alternateName": ["AceMock", "云舟备考", "acemock.cn"],
    "url": "https://acemock.cn/"
  }
</script>
```

这段结构化数据不会作为正文显示给用户，它用于帮助搜索引擎理解“AceMock”“云舟备考”和 `acemock.cn` 属于同一个网站品牌。

### 2. 路由级 SEO 管理

不能让所有页面继续共用同一个“在线答题系统”标题。公开页面应当有独立的标题、摘要和 canonical；私有页面应当明确退出索引。

第一阶段建议索引范围如下：

| 页面类型 | 代表路径 | 索引策略 | 说明 |
| --- | --- | --- | --- |
| 品牌首页 | `/` | `index` | 核心品牌与产品说明页 |
| ESAT 介绍 | `/exam-intro/esat` | `index` | 独立标题、摘要和正文 |
| TMUA 介绍 | `/exam-intro/tmua` | `index` | 独立标题、摘要和正文 |
| STEP 介绍 | `/exam-intro/step` | `index` | 独立标题、摘要和正文 |
| 登录注册 | `/login`、`/register` | `noindex` | 不应成为自然搜索入口 |
| 学习业务页 | `/question-bank`、`/practice*`、`/assessment*`、`/mistake-notebook*` | `noindex` | 当前需要登录，匿名抓取只会得到登录流程 |
| 用户与报告 | `/profile*`、`/exam-result*` | `noindex` | 包含个人状态或结果数据 |
| 管理后台 | `/admin*` | `noindex` | 内部页面，不参与公开搜索 |
| 协议页面 | `/legal*` | 默认 `noindex` | 保留直接访问能力，不占用主要品牌搜索结果 |

如果未来希望“免费诊断”或“试题库”出现在站点子链接中，应新增不要求登录的公开介绍页，再从介绍页引导用户登录或注册，而不是直接开放当前业务页面索引。

### 3. 错误收录治理

当前 `/question-bank` 被搜索引擎收录，但匿名用户实际会被引导到登录页，因此搜索引擎可能使用登录页标题或正文生成结果。

治理原则：

- 登录后页面返回或渲染明确的 `noindex` 信号。
- 不仅依赖 `robots.txt` 的 `Disallow`。如果完全禁止抓取，搜索引擎可能无法读取页面上的 `noindex`。
- 在 Search Console 中检查旧网址的索引状态。
- `noindex` 发布并可被抓取后，请求重新抓取；如需快速隐藏，可配合 Search Console 的临时移除功能。

### 4. 公开站点结构与站点子链接

搜索结果中首页下方的 ESAT、TMUA 等子链接由搜索引擎自动生成，网站不能直接指定必须显示哪些链接。

可以通过以下方式提高出现高质量站点子链接的概率：

- 首页导航和页脚使用真实的 `<a href>` 或 `<router-link>` 指向重要公开页面。
- 公开页面具有简洁、独立且能准确说明内容的标题和一级标题。
- 首页、ESAT、TMUA、STEP 页面之间建立清晰的内部链接关系。
- 不让登录、注册、后台等页面占据公开导航的主要层级。
- 页面正文避免只使用图片或按钮表达关键信息。

### 5. robots.txt 与 sitemap.xml

`robots.txt` 用于说明爬虫可以访问哪些资源，并提供 Sitemap 地址；`sitemap.xml` 用于列出希望搜索引擎发现和收录的规范网址。

第一阶段 Sitemap 只建议包含：

```text
https://acemock.cn/
https://acemock.cn/exam-intro/esat
https://acemock.cn/exam-intro/tmua
https://acemock.cn/exam-intro/step
```

登录页、注册页、用户业务页、报告页和后台页面不得加入 Sitemap。Sitemap 是发现提示，不代表其中的页面一定会被收录。

### 6. 公开页面预渲染

当前网站是 Vue 单页应用。浏览器执行 JavaScript 后可以显示完整内容，但服务器最初返回的 HTML 主要是应用容器。搜索引擎虽然可以执行 JavaScript，处理速度和结果仍可能不如直接返回完整 HTML 稳定。

本项目不需要为了 SEO 把整个登录后系统改造成服务端渲染。建议只对以下公开页面进行构建期预渲染：

- 首页 `/`
- ESAT 介绍 `/exam-intro/esat`
- TMUA 介绍 `/exam-intro/tmua`
- STEP 介绍 `/exam-intro/step`

预渲染后的页面在不执行 JavaScript 时也应包含页面标题、摘要、canonical、主要标题、核心正文和内部链接。

### 7. Search Console

Google Search Console 是 Google 提供的网站搜索管理工具，用于查看网站收录、抓取、关键词曝光和错误情况。它不能直接编辑搜索结果，也不能保证排名。

发布 SEO 改造后，需要完成：

1. 在 Search Console 添加 `acemock.cn` 网域资源。
2. 通过 DNS TXT 记录验证域名所有权。
3. 提交 `https://acemock.cn/sitemap.xml`。
4. 使用“网址检查”测试首页及三个考试介绍页。
5. 确认 Google 读取到正确的标题、正文、canonical 和索引状态。
6. 请求重新编入索引。
7. 检查 `/question-bank` 等旧页面是否逐步退出索引。
8. 后续查看搜索词、曝光、点击率和平均排名。

域名验证需要域名 DNS 管理权限，生产发布需要对应部署权限，这两部分需要网站负责人配合完成。

## 五、时间与非保证项

- 代码发布后，搜索引擎通常需要数天至数周重新抓取和处理页面。
- Search Console 的“请求编入索引”只能提交请求，不能保证立即更新。
- 标题、摘要、网站名称和站点子链接均由搜索引擎最终决定，方案只能提供清晰、一致且高质量的信号。
- 站点子链接与网站结构、品牌搜索量、内容质量和搜索引擎对网站的长期理解有关，不属于单次代码发布即可保证的结果。
