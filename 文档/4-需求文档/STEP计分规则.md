# STEP（Sixth Term Examination Paper）计分规则详解

> **适用院校**：剑桥大学、华威大学、帝国理工学院（部分专业）
> **考试管理机构**：Cambridge Assessment / OCR
> **数据来源**：OCR 官方成绩报告、剑桥大学招生页、maths.org/step、2019-2024 年分数线数据

---

## 一、考试结构

| 项目 | STEP 2 | STEP 3 |
|------|------|------|
| 时长 | 3 小时 | 3 小时 |
| 总题量 | 12 题 | 12 题 |
| 题目分布 | 8 Pure + 2 Mechanics + 2 Probability/Statistics | 同 |
| 每题分值 | 20 分 | 20 分 |
| 满分 | **120**（取最高 6 题） | **120**（取最高 6 题） |
| 计算器 | ❌ 不允许 | ❌ 不允许 |
| 数学基础 | A-Level 数学 + AS 进阶数学 | A-Level 数学 + A-Level 进阶数学 |
| 考试日期 | 6 月中旬 | 6 月中旬 |
| 出分日期 | 8 月中旬（与 A-Level 同一天） | 同 |

> ⚠️ **STEP 1 已于 2020 年停考**，目前仅剩 STEP 2 和 STEP 3。剑桥数学专业通常要求两卷都考。

## 二、评分体系

### 2.1 等级制度

| 等级 | 含义 | 约百分位 |
|:--:|------|:--:|
| **S**（Outstanding） | 卓越 | 前 ~5-10% |
| **1**（Very Good） | 优秀 | 前 ~15-30% |
| **2**（Good） | 良好 | 前 ~35-50% |
| **3**（Satisfactory） | 合格 | 前 ~50-75% |
| **U**（Unclassified） | 未达标 | 后 ~25% |

> ⚠️ **STEP 没有 "T" 等级**。只有 S, 1, 2, 3, U 五个等级。

### 2.2 分数线设定机制

| 特征 | 说明 |
|------|------|
| 考前预判 | 考官出题时会对每道题预期难度做评估 |
| 考后校准 | 根据**考生实际表现**和**历史标准**设定等级阈值 |
| 年度比较 | 确保今年 S 代表的水平与往年 S 大致可比 |
| 不预先公布 | 分数线在出分日（8 月中旬）与成绩一同公布 |

**核心原则**：分数线反映的是**题目难度 + 考生总体表现**的平衡。困难年份分数线下移，简单年份上移——确保 S 永远代表"卓越"。

## 三、逐题评分细则

### 3.1 每题 20 分的评分哲学

STEP 不是"按点给分"的机器评分——每个 20 分题目的评分遵循以下原则：

| 原则 | 说明 |
|------|------|
| **正确解 = 满分** | 无论用什么方法，只要完整正确就是 20 分 |
| **鼓励进展** | 即使最终答案错误，**展示出实质性进展**可获得对应部分分数 |
| **非线性给分** | 1/2 的进展 ≠ 10 分；可能只给 6-7 分 |
| **完整度溢价** | 3/4 完成 → 通常 ≈ 3/4 的分数（~15/20） |
| **小题拆分** | 每道题内部有隐含的分段给分（非公开），各段完成得好就能拿对应该段的分数 |

### 3.2 扣分情形

| 情形 | 影响 |
|------|------|
| 小计算错误（不影响后续逻辑） | 扣 1-2 分 → 仍可拿 18-19/20 |
| 遗漏一整段 | 按该段权重扣分 |
| 错过核心技巧/洞察 | 可能扣分较重，因为后续无法推进 |
| 碎片式尝试（只写了几行） | 几乎不给分——"fragmentary" 答案不鼓励 |

### 3.3 为什么 "6 个半完成" 可能优于 "4 个全完成"

```
方案 A：6 题各完成 70%（≈ 14/20 每题）→ 总分 ≈ 84 → 有望 Grade 1
方案 B：4 题完整 + 2 题空白      → 总分 80 + 0 → Grade 1 边缘
```

**结论**：做完 6 题不一定比 4 题完整更优，但凑满 6 题+拿够分确实是一个可行策略。

### 4.3 趋势分析

| 观察 | 分析 |
|------|------|
| **S 线波动范围** | STEP 2: 81-97；STEP 3: 84-95——某些年份的卷子确实显著更难 |

| **2024 年 STEP 3 S 线反弹** | 回升 8 分至 93，表明考卷难度回调或考生整体水平回升 |

## 六、各大学要求

### 6.1 剑桥大学

| 专业 | STEP 要求 |
|------|------|
| **Mathematics** | 🔴 必须：**STEP 2 Grade 1 + STEP 3 Grade 1**（部分学院接受 1, 2） |
| **Mathematics with Physics** | 🔴 STEP 2 + STEP 3（通常 1, 1） |
| **Engineering** | 不使用 STEP（使用 ESAT） |
| **Computer Science** | 不使用 STEP（使用 TMUA） |

**A-Level 配套要求**：A\*A\*A（含数学和进阶数学），加上 STEP 条件作为 offer 的一部分。

> 各学院可能略有差异。Peterhouse 历史上 accepting "1, 2"；Trinity 传统上要求最高。

### 6.2 华威大学

| **Mathematics (BSc)** | 🟡 Grade 2 可降 A-Level 条件 |
| **MORSE** | 🟡 不强制但可加分 |

## 七、STEP 2 vs STEP 3 难度差异

| 维度 | STEP 2 | STEP 3 |
|------|------|------|
| **数学基础要求** | A-Level 数学 + AS 进阶数学 | A-Level 数学 + A-Level 进阶数学 |
| **核心知识** | 微积分、三角、向量、力学基础 | 进阶微积分、复数、双曲函数、微分方程、进阶力学 |
| **题目难度** | 高——但仍基于 AS 进阶数学范围 | 更高——需要全面掌握 A-Level 进阶数学 |
| **考生群体** | 混合群体（含试探性申请者） | 更同质（多为已录取的数学尖子） |
| **S 获得率** | 约 6% | 约 11% |
| **典型策略** | 优先保 4 题完整 + 2 题部分 | 类似但每题平均深度更深 |

## 八、备考策略

### 8.1 选题策略

| 原则 | 说明 |
|------|------|
| **3 小时 = 做 6 题 = 每题 30 分钟** | 不要在 1 题上超过 45 分钟 |
| **前 15 分钟通读所有 12 题** | 标记最容易入手的 6-7 题 |
| **Pure 题优先** | Pure 题目数量多（8 题），选择空间大 |
| **Mech/Stats 是 X 因素** | 如果力学或概率是你的强项，那 2 题可能是最稳的 40 分 |

### 8.2 答题策略

| 策略 | 说明 |
|------|------|
| **完整 > 广度** | 1 题完整解答（20 分）> 3 题碎片（各 5-6 分） |
| **展示过程** | 即使卡住，写出你已经做了什么——评估者可能给部分分 |
| **不要空着** | 即使只写了几行也交上去，可能拿到意想不到的分数 |
| **选题后不要轻易换** | 中途换题损失沉没时间，除非真的完全走不通 |
| **最后 15 分钟** | 不要再开新题，完善已有答案，检查计算错误 |

### 8.3 日常训练

| 方法 | 说明 |
|------|------|
| **做历史真题** | 从 2014 年起每一份 STEP 2/3 真题都做 |
| **限时训练** | 3 小时计时 + 真实考试条件（无计算器、无参考书） |
| **读评分报告** | 每年 OCR 会发布 Examiners' Report，揭示常见错误和评分细节 |
| **搭建"技巧库"** | 记录每种题目类型的"标准解法"和"关键技巧" |
| **不要依赖计算器** | 所有练题手算，熟悉心算和代数运算 |

### 8.4 常见陷阱

| 陷阱 | 对策 |
|------|------|
| 写到一半发现走错了仍硬写 | 承认错误，快速切换到正确方法 |
| 只做 Pure 题忽视 Mechanics/Stats | 那 4 题往往是拿 S 的关键（竞争较小） |
| 代数计算错误→全题作废 | 做完每段后**快速回检**该段的代数 |
| 以"思路懂了"代替"写出来" | 训练中必须写完整解答——思路对 ≠ 能拿分 |

## 九、计分规则核心总结

| 核心要点 | 详细说明 |
|------|------|
| **6 题取最高分** | 可做任意数量，取最高 6 题。不需要全做完 |
| **每题 20 分** | 分内部段落给分，完整 ≥ 碎片 |
| **S ≠ 固定 raw 线** | 每年波动：81-97（STEP 2）；84-95（STEP 3） |
| **非线性给分** | 后 25% 的进展给分很少，前 25% 给分慷慨 |
| **没有负分** | 空题 = 0 分，但写错不额外扣分 |
| **STEP 3 S 率约为 STEP 2 的 2 倍** | 不是因为题简单，是因为考生群体更强 |
| **答案被"progress"奖励** | 不完全正确 ≠ 全扣，展示了思考过程就有分 |
| **2020-2021 疫情年分数线偏低** | 不应作为备考目标（应瞄准正常年份 S 线 ~90+） |
| **剑桥数学 offer 条件** | 通常要求 STEP 2 + 3 均 Grade 1 |
| **8 月中旬出分** | 与 A-Level 同日，OCR 直接送 UCAS |
