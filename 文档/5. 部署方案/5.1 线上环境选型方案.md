# 线上环境部署方案

> **适用范围**：生产线上环境 | **最后更新**：2026-07-06

---

## 一、部署架构

```text
用户浏览器（HTTPS）
  │
  │ 443（TLS 1.2+）
  ▼
Nginx（反向代理 + 静态资源）
  ├── /                  → /opt/quiz/web/dist          Vue SPA 静态文件
  └── /api/              → 127.0.0.1:3001              Express API

PM2（进程守护）
  └── quiz-api           → /opt/quiz/api/dist/index.js    Node.js 20

RDS PostgreSQL（阿里云）
  └── quiz_prod           → 主数据库（内网访问）

OSS 对象存储（阿里云）
  └── quiz-files/        → 试卷 PDF + 用户导出文件（公共读）
```

**网络原则**：公网仅开放 `22`、`80`、`443`。数据库端口 `5432` 仅允许 ECS 内网访问，API 端口 `3001` 仅监听本地回环，二者均不对外暴露。

## 二、资源选型与容量规划

### 2.2 存储容量估算

**RDS 数据库**

| 数据项 | 计算方式 | 三年预估 |
|--------|----------|------:|
| Question 表 | 6,600 条 × 3KB | ~20 MB |
| Paper 表 | 40 条 × 500B | 忽略不计 |
| User 表 | 1,000 人 × 500B | ~0.5 MB |
| UserMembership 表 | 1,000 人 × 2 条 × 250B | ~0.5 MB |
| DiagnosticSession 表 | 1,000 人 × 10 次 × 500B | ~5 MB |
| ExamRecord 表 | 1,000 人 × 100 次 × 300B | ~30 MB |
| AnswerRecord 表 | 1,000 人 × 100 次 × 28 题 × 150B | ~420 MB |
| 组卷记录表 | 1,000 人 × 5 次 × 200B | ~1 MB |
| 组卷题目关联表 | 1,000 人 × 5 次 × 20 题 × 100B | ~10 MB |
| 会员 / 权益 / 大纲 / 营收成本等 | — | ~5 MB |
| **RDS 数据库总容量** | | **~500 MB** |

**ECS 磁盘**

| 数据项 | 三年预估 |
|--------|------:|
| 应用代码 + node_modules | ~500 MB |
| 系统 + Node.js + Nginx | ~5 GB |
| 日志（含轮转） | ~2 GB |
| **ECS 磁盘总需求** | **~8 GB** |

**OSS 存储**

| 数据项 | 计算方式 | 三年预估 |
|--------|----------|------:|
| 试卷 PDF 原文件 | 40 套 × 8MB | ~320 MB |
| 用户导出文件 | 1,000 人 × 10 次 × 500KB | ~5 GB |
| **OSS 存储总需求** | | **~6 GB** |

OSS 目录规划：

```text
quiz-files/
├── papers/{paperId}.pdf     # 永久保留
├── exports/{userId}/...      # 7 天后自动删除

```

### 2.3 ECS 服务器选型

| 配置项 | 规格 | 选型理由 |
|--------|------|----------|
| **实例类型** | ECS 经济型 e（ecs.e-c1m2.large）| CPU 突发特性匹配日常低负载 + 答题高峰短时突发的使用模式 |
| **vCPU** | 2 核 | Express + Nginx 均单线程模型，2 核覆盖 <50 并发；数据库已剥离到 RDS |
| **内存** | 4 GB | Node.js ~200MB + Nginx ~50MB + 系统 ~500MB + 缓存余量 |
| **系统盘** | ESSD Entry 40 GB | 实际用量 ~8GB × 5 倍余量 |
| **操作系统** | Ubuntu 22.04 LTS（64 位）| Node.js 生态兼容性最好 |
| **带宽** | 100 Mbps 按流量计费 | SPA 静态资源加载后缓存，API 响应体小 |
| **付费方式** | 包月 | 长期运行比按量付费节省约 30%；绑定弹性公网 IP |
| **地域** | 华东 2（上海）| 与 RDS、OSS 同 Region，内网互通免流量 |

| 配置项 | 规格 | 选型理由 |

## 三、域名与 HTTPS

### 3.1 域名

- 在阿里云万网购买 `.com` 或 `.cn` 域名，完成实名认证
- 解析 A 记录到 ECS 公网 IP

### 3.2 ICP 备案

中国大陆 Region 服务器必须先完成 ICP 备案：

```text
购买域名 → 实名认证（1-3天）
    ↓
提交备案（阿里云备案系统）
    ↓
阿里云初审（1-2天）→ 短信 / 人脸核验
    ↓
管局审核（10-15个工作日）
    ↓
备案通过 → 域名正常访问
```

备案期间使用 `http://<公网IP>` 内部测试，通过后切换到域名 + HTTPS。

### 3.3 SSL 证书

阿里云免费 DV 证书，单域名，有效期 1 年，到期前控制台续期。
