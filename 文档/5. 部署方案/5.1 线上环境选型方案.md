# 线上环境选型方案

> **适用范围**：生产线上环境 | **最后更新**：2026-07-09

---

## 一、部署架构

```text
用户浏览器（HTTPS）
  │
  │ 443（TLS 1.2+）
  ▼
Nginx（反向代理 + 静态资源）
  ├── /                  → /opt/quiz/web/dist          Vue SPA 静态文件
  └── /api/              → 127.0.0.1:3001              Express API

PM2（进程守护）
  └── quiz-api           → /opt/quiz/api/dist/index.js    Node.js 20

RDS PostgreSQL（阿里云）
  └── quiz_prod           → 主数据库（内网访问）

OSS 对象存储（阿里云）
  └── quiz-files/        → 试卷 PDF + 用户导出文件（私有 Bucket + 签名访问）
```

**网络原则**：公网仅开放 `22`、`80`、`443`。数据库端口 `5432` 仅允许 ECS 内网访问，API 端口 `3001` 仅监听本地回环，二者均不对外暴露。

### 2.3 ECS 服务器选型

#### 2.3.1 当前已选定配置（2026-07-09）

当前已确认用于正式线上起步环境的 ECS 配置如下：

| 配置项 | 已选值 | 说明 |
|--------|--------|------|
| **实例规格** | `ecs.u2a-c1m2.large` | 通用算力型 `u2a`，2 核 4 GB |
| **vCPU** | 2 核 | 满足当前单机 Nginx + PM2 + Node.js API 起步负载 |
| **内存** | 4 GB | 满足当前正式环境起步阶段，后续可视增长升级 |
| **系统盘** | ESSD Entry 40 GB | 代码、系统、日志、临时文件可满足当前需求 |
| **操作系统** | Ubuntu 22.04 LTS 64 位 | 与当前项目 Node.js 生态兼容性最好 |
| **带宽计费模式** | 按使用流量 | 适合当前正式站点起步阶段 |
| **带宽值** | 5 Mbps | 满足当前网站/API 起步流量 |
| **付费方式** | 包年包月（1 年） | 用于长期正式运行环境 |
| **地域** | 华东 2（上海） | 后续 RDS、OSS、域名解析需保持同 Region |
| **网络类型** | 专有网络 VPC | 生产环境标准配置 |
| **公网 IP** | 分配公网 IPv4 | 用于域名解析、Nginx 对外访问、HTTPS 接入 |

当前定位：

- 该配置可作为正式线上环境的**起步主机**。
- 当前方案不属于高可用架构，应用层仍为单 ECS 单节点。
- 当出现以下情况时，建议升级为 `4C8G` 或演进为 `双 ECS + ALB`：
  - 同时在线用户明显增长；
  - 后台导入、解析、考试高峰互相抢占资源；
  - CPU、内存、磁盘 IO 在业务高峰期持续接近瓶颈；
  - 需要更高等级的可用性保障。

## 三、域名与 HTTPS

### 3.1 域名

- 在阿里云万网购买 `.com` 或 `.cn` 域名，完成实名认证
- 解析 A 记录到 ECS 公网 IP

### 3.2 ICP 备案

中国大陆 Region 服务器必须先完成 ICP 备案：

```text
购买域名 → 实名认证（1-3天）
    ↓
提交备案（阿里云备案系统）
    ↓
阿里云初审（1-2天）→ 短信 / 人脸核验
    ↓
管局审核（10-15个工作日）
    ↓
备案通过 → 域名正常访问
```

备案期间使用 `http://<公网IP>` 内部测试，通过后切换到域名 + HTTPS。

### 3.3 SSL 证书

阿里云免费 DV 证书，单域名，有效期 1 年，到期前控制台续期。
