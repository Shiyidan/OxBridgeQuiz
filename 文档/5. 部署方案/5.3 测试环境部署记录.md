### 2026-06-15 部署前核对

本次按当前代码仓库重新核对部署方案，结论如下：

- 当前后端真实目录是 `api/`，前端真实目录是 `quiz-web/`。

- 当前没有 Redis 依赖和调用。
- 前端生产构建必须设置 `VITE_API_BASE`。
- 安全组不应开放 `3001`、`5432`、`6379`，API 统一通过 Nginx 反向代理访问。
- 备案和 HTTPS 完成前，可以先用公网 IP 做内部测试。

### ECS 选型决策

| 决策项 | 选择 | 理由 |
|--------|------|------|
| 实例规格 | 经济型 e（ecs.e-c1m2.large）2核4G | PDF 解析间歇突发、日常低负载 |
| 操作系统 | Ubuntu 22.04 LTS | Node.js/Nginx 生态最成熟 |

| 带宽 | 100Mbps 按流量计费 | 开发测试阶段突发快、空闲不花钱 |
| 预装应用 | 无（裸系统） | 避免面板/Docker 覆盖配置 |
