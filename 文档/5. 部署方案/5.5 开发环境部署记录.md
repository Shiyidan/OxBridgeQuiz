## 2026-07-09 MySQL schema 标准化

本次在开发环境完成了 MySQL schema 标准化，主要内容如下：

- 主 Prisma schema 已从 SQLite 切换为 MySQL：`api/prisma/schema.prisma`。
- 历史 SQLite migrations 已归档至：`api/prisma/migrations_sqlite_archive`。
- 新建 MySQL baseline migration：`api/prisma/migrations/20260709000000_mysql_baseline/migration.sql`。
- 本地开发库已执行并标记 baseline 已应用。
- `npx prisma migrate status --schema prisma/schema.prisma` 校验通过，当前数据库结构为 up to date。

字段标准化结果：

- `Question.title` 改为 `LongText`，用于承载较长题干、段落和公式内容。
- `Question.options`、`Question.answer`、`Question.knowledgePoints`、`Question.syllabusPoints`、`Question.meta` 改为 MySQL `JSON`。
- `User.examPreferences`、`DiagnosticSession.answers`、`Syllabus.sourceJson`、`ParseTask.result` 改为 MySQL `JSON`。
- `Paper.questions` 改为 `JSON`，仅作为历史兼容字段保留。
- `Paper.pdfUrl`、`ParseTask.error`、`User.avatar`、`RevenueCost.remark` 使用 `Text`。
