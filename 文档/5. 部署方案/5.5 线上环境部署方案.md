### 2.12 运维与安全 TODO

应用运行日志已按单行 JSON 输出，操作日志详情中的 Request ID 可直接用于检索 PM2 的标准输出与错误日志：

```bash
REQUEST_ID='<后台复制的 Request ID>'
pm2 describe quiz-api  # 先查看 out log path / error log path
grep -F "$REQUEST_ID" /var/log/quiz/api-out.log /var/log/quiz/api-error.log
```

`http.request.completed` 提供接口、状态码和耗时，具体异常事件保留完整错误堆栈。日志文件路径以 `pm2 describe quiz-api` 的实际输出为准，不能假定 PM2 使用默认目录；当前测试环境配置在 `/var/log/quiz/`。该查询链路不等同于日志保留策略；上线时仍需配置 `pm2-logrotate`、保留天数和磁盘告警。
